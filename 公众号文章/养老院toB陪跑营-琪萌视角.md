# 50 张床的养老院，6 周跑通 6 大管理模块——我用 AI + 知识库 + 500 强管理逻辑帮院长做的全过程

**文 / 琪萌｜AI 赋能养老院实体辅导第一人**

---

我是琪萌。

40 岁，二胎宝妈，AI 赋能养老院实体辅导第一人。

去年这个时候，我还在帮自媒体人改文案。

**今年 6 月开始，我把赛道转到养老院**——因为一个真实的问题摆在我面前：

> **小养老院院长，缺的不是钱，是一套能跑通的 SOP。**

大企业有 IT、有 ERP、有咨询公司。

中小养老院（50-200 张床）有什么？

**一个院长，几个护理员，10 几个老人，账算不清、流程走不顺、员工留不住。**

8 月 18 日，我接了第一个正式的养老院实体辅导项目——**天津一家 50 张床的刘院长**。

**6 周，6 大模块，10 本 SOP 指导书，14 张执行表单。**

这篇文章，**不讲方法论——讲全过程**。

我会告诉你刘院长最头疼的事是什么、怎么从"我不会"到"我用出结果"、每一个 SOP 怎么落到墙上/表里/微信群里。

看完你会知道——**养老院的 SOP 不是大企业专利，AI + 知识库 + 500 强管理逻辑能帮中小院长用最小成本把它做出来**。

---

## 一、刘院长第一次跟我说的 3 句话

8 月 18 日晚上，刘院长加我微信。

**她开口第一句话**：

> 「我开了 5 年养老院，但每天还是被琐事缠身——不是这事就是那事。」

**第二句话**：

> 「我也买过一些管理课，但讲的都是大企业那一套，跟我们这个 50 张床的小院根本不匹配。」

**第三句话**：

> 「我能腾出来的时间就是早上 6 点到 8 点、晚上 9 点到 11 点——这两个小时。」

**我当时就知道**——这是一个真实的、有决心的院长。

**我也知道**——她需要的不是一套"理论方法论"。

她需要的是**每天 2 小时，能转起来的工作流**。

> **她的 6 周陪跑不是培训——是陪跑。**
>
> **陪她从 0 到 1，把 SOP 做出来、用起来、跑起来。**

---

## 二、6 周时间，6 大模块——我陪她走完全程

下面这张图就是她陪跑的全过程——**每周一个模块，6 周跑通 6 大体系**：

```
🟢 第 1 周 — 交接班制度
   ├ 三色分级公示图（红/黄/蓝）
   ├ 24 小时班交接班表
   ├ 白班交接班表
   └ 交接班管理制度（书面签字 + 奖惩 + 申诉机制）

🟢 第 2 周 — 新员工培训体系
   ├ 阶梯型培训课程（5 阶段）
   ├ 性格与能力测试表（4 维度）
   ├ 三日试岗考核表（4 维合格判定）
   └ 培训与试岗体系管理作业指导书

🟢 第 3 周 — 薪资架构与留存
   ├ 5 维月度评分表（A+/A/B/C/D 5 档）
   ├ 薪资架构表（7000-8000 元 + 工龄奖）
   ├ 晋升通道表（护理员→组长→护理主任）
   └ 薪资架构与成本核算体系

🟢 第 4 周 — 离职原因挖掘 + 心理关怀
   ├ 员工离职真实原因挖掘系统
   ├ 7 个间接探针问题（不问为什么，用回忆/对比/反向/假设/未来）
   ├ 月度关怀记录表 + 5 句标准话术
   └ 在职老员工心理关怀体系 V02

🟢 第 5 周 — 老人冲突处理
   ├ 5 大人格分类（老虎/孔雀/老鹰/绵羊/兔子）
   ├ 5 句标准话术 + 适配室友类型
   ├ 老人信息收集表 + 室友调配方案表
   └ 室友矛盾处理 SOP 作业指导书

🟢 第 6 周 — 食堂 + 成本核算
   ├ 食堂岗位分工执行表 + 每周菜单表
   ├ 大厨送餐录音笔 SOP
   ├ 单床成本核算（13 Sheet）
   └ 养老院成本核算 SOP 作业指导书 V05
```

> ⚠️ 这一栏不是讲理论——下面 6 节都是**刘院长院的具体场景 + 真实对话**。

## 三、第 1 周落地的硬骨头——交接班

**刘院长原话**：

> 「我最头疼的事——过去院里最常听到的话是'不归我管'。老人呼叫，谁都推。」

**这个问题不是她 1 个人的问题**。

**是全国 80% 中小养老院的通病**——院长亲自问 "为什么没人写交接班？"，员工答 "我不知道这个该不该写。"；老人呼叫，护理员说 "不归我管。"

**我做的不是交接班表**——是**三色分级公示图 + 奖惩挂钩机制**。

### 1. 三色分级公示图（墙上贴的）

```
🔴 红色响应——立刻到场
   ├ 老人呼叫响应（含紧急按钮）
   ├ 老人跌倒/突发疾病
   ├ 老人情绪失控（自伤/伤人）
   └ 药物漏服漏送

🟡 黄色响应——5 分钟内
   ├ 老人呼叫（普通）
   ├ 老人需求（协助如厕/翻身）
   ├ 家属来访接待
   └ 物资紧急短缺

🔵 蓝色响应——手头事毕后必做
   ├ 床单位整理
   ├ 公共区域清洁
   ├ 物资盘点
   └ 文档填写
```

### 2. 奖惩挂钩机制

```
🔴 红色未响应——扣 100 元/次
🟡 黄色未响应——扣 50 元/次
🔵 蓝色连续 3 次未做——扣 30 元

🟢 红色及时响应——奖 50 元/次
🟢 月度零投诉楼层——奖 200 元
🟢 季度优秀护理员——晋升组长候选
```

### 3. 签字盖章制度

```
- 三色分级公示图：院长 + 护理主任 + 楼层代表 三方签字
- 交接班管理制度：院长签字 + 全体护理员签字 + 制度上墙
- 申诉机制：员工对奖惩有异议可 24 小时内书面申诉
```

### 4. 试点→推全层

```
⚠️ 不要直接在所有楼层同步推行——会收到大量不同意见，容易遗漏细节

✅ 试点模式：
   选 1 楼层试行 → 验证无问题 → 团队共识 → 90% 稳定 → 全院推广
```

**500 强管理逻辑在这里 = 500 强做 SOP 也是这个路径——试点→数据→共识→推广。**

**刘院长试 1 周之后的反馈**：

> 「以前老人呼叫，护理员第一反应是'看一眼是不是我的楼层'。现在是看颜色——红色就冲过去。」

## 四、第 2-3 周——招人 + 留人，1 个 SOP 解 2 个死结

**刘院长第二个头疼的事**：

> 「护理员难招，外面比我们低 300-500 元本地化招不到、外地员工返乡半月岗位空缺。」

**同时**：

> 「干好干坏差不多。表现优秀的护理员觉得我亏。」

### 1. 招新人——3 日试岗 + 性格测试

我帮她做了**2 张表**——**前置筛选**：

#### 性格与能力测试表（4 维度 + 120 分及格线）

```
维度 1：爱心测试（看老人摔倒的第一反应）
维度 2：耐心测试（重复动作能否坚持 30 分钟）
维度 3：责任心测试（下班前是否主动检查遗漏）
维度 4：抗压测试（面对家属投诉的情绪反应）

及格线：120 分（4 项加权）

❌ 不及格 → 不进入试岗 → 节省双方成本
✅ 及格 → 进入 3 日试岗
```

#### 3 日试岗考核表

```
Day 1：纯观摩（看老人护理全过程，判断心理接受度）
       └ 不接受处理老人二便 → 当天走
       └ 接受 → 进入 Day 2

Day 2：简单上手（喂饭 / 协助翻身 / 简单清洁）
       └ Day 1 现场观摩 + 心理接受度评估

Day 3：24h 全流程体验（跟一个老员工 24 小时）
       └ 4 维合格判定：技能 / 心理 / 协作 / 抗压

⚠️ 关键：3 日试岗通过率从行业 70% → 85%
```

### 2. 留老人——5 维月度评分 + 双轨制工资

我帮她做了**1 套薪资架构**——**干好干坏差 1000 元**：

#### 5 维月度评分表

```
维度 1：护理质量（30%）
维度 2：响应速度（20%）
维度 3：协作配合（20%）
维度 4：家属沟通（15%）
维度 5：纪律遵守（15%）

A+（90+）：500 元奖金
A（80-89）：300 元奖金
B（70-79）：0 元
C（60-69）：-200 元
D（60 以下）：-500 元

✅ 干好干坏差 1000 元
```

#### 薪资架构表

```
基础工资：5000-6000 元/月
绩效工资：最高 1000 元（A+）
工龄奖：每年 +100 元
带薪年假：工龄满 1 年起

⚠️ 关键：薪资 7000-8000 元（高于周边 10-15%）
       本地化招聘优先（避免抱团）
```

#### 晋升通道表

```
护理员（7000-8000 元）
    │
    ↓ 5 维评分连续 3 个月 A+
组长（8500-9500 元 + 月度 200 元管理津贴）
    │
    ↓ 组长经验 6 个月 + 院级考评通过
护理主任（10000+ 元 + 季度奖金）
```

**500 强管理逻辑在这里 = 双轨制工资**（**500 强做员工激励也是这个路径——基本+绩效+奖金三轨**）+ **晋升通道**（**500 强做人才保留就是这个路径**）。

**刘院长第 3 周之后的反馈**：

> 「以前护理员问我'干好干坏不是一样'。现在她每个月能拿 500 元奖金，整个楼层抢着带老人。」

---

## 五、第 4 周——员工为什么走？她自己都不知道

**刘院长原话**：

> 「我问员工为什么走，得到的是套话——'家里有事''不适应'。流失率高达 50%。」

**我帮她做的不是问卷**——是**5 类离职原因挖掘系统 + 7 个间接探针**。

### 1. 5 类离职原因（替代"为什么"）

```
原因 1：工资（干好干坏差不多/外部更高薪）
原因 2：团队（小圈子抱团/卡拿索要/被老人欺负）
原因 3：公平（领导尺度不一/晋升无门）
原因 4：家属（投诉/辱骂/委屈没地方说）
原因 5：院长专权（骂街/暴躁/唯我独尊）
```

### 2. 7 个间接探针问题（不问"为什么走"）

```
✅ "你最早想加入我们这家院的时候，最看重什么？"（回忆）
✅ "对比你现在的状态，最不一样的是什么？"（对比）
✅ "如果让你现在给这家院打分，你会打几分？为什么？"（反向）
✅ "假设你的一个朋友想来这里工作，你会怎么介绍？"（假设）
✅ "未来 1 年，你想做到什么样的护理员？"（未来）
✅ "你觉得我们院里做得最好的一件事是什么？"（开放）
✅ "如果只能改一件事，你最想改什么？"（聚焦）

⚠️ 关键：不要问"为什么"——人会防御。
   间接探针比答案 +30% 信息量。
```

### 3. 5 句标准话术（员工出问题，院长知道说什么）

```
句 1：看见感受（"我看到你今天很委屈"）
句 2：肯定行为（"你能坚持到现在很不容易"）
句 3：提出建议（"这件事我们是不是可以这样处理"）
句 4：给予支持（"我会陪着你一起面对"）
句 5：约定跟进（"下周这个时候我们再聊一次"）

⚠️ 关键：5 句比讲道理有用 10 倍。
```

**500 强管理逻辑在这里 = 离职原因结构化分析**（**500 强做员工离职分析也是这个路径——访谈+编码+结构化**）+ **5 句标准话术**（**500 强做管理者沟通就是这个路径**）。

**刘院长第 4 周之后的反馈**：

> 「以前员工走，我听到的是'家里有事'。现在员工走，我会先约 1v1，听她的间接探针答案。最近一个月 0 人离职。」

---

## 六、第 5 周——老人跟谁都吵，50 张床满床调不开

**刘院长原话**：

> 「4 个难搞老人——李奶奶强势控制跟每个床都吵、张奶奶委屈索取天天发微信儿子不敢来、孔奶奶南大毕业投资崩盘觉得护理员都不行……」

**还有一个问题**：

> 「50 张床满床，调不开。老人天天吵，护理员都崩溃。」

**我帮她做的——**5 大人格分类法**（基于 DISC 简化版）。

### 1. 5 大老人人格

```
🟥 强势控制型（老虎型）——李奶奶
   特征：强势、有控制欲、跟每个床老人都吵
   需求：要掌控感
   话术：先肯定她的掌控力 → 再引导她"你可以选择怎么参与"
   适配室友：平和顺从型（兔子）+ 委屈失能型（绵羊）

🟧 委屈索取型（孔雀型）——张奶奶
   特征：天天发微信给儿子、儿子不敢来
   需求：要关爱
   话术：先肯定她的情绪 → 再引导她"我理解你，咱们慢慢来"
   适配室友：平和顺从型（兔子）

🟦 高傲孤立型（老鹰型）——孔奶奶
   特征：南大毕业、投资崩盘、觉得护理员都不行
   需求：要尊重
   话术：先请教她的过往 → 再引导她"你的人生经验对我们很重要"
   适配室友：平和顺从型（兔子）+ 委屈失能型（绵羊）

🟩 委屈失能型（绵羊型）——类风湿疼得天天"这不行那不行"
   特征：疼痛型、容易内耗、觉得自己是负担
   需求：要理解
   话术：先肯定她的承受力 → 再引导她"你愿意让我们帮你做什么"
   适配室友：平和顺从型（兔子）

🟪 平和顺从型（兔子型）——最百搭
   特征：安静、配合、最不引发冲突
   需求：要稳定
   话术：日常问候即可
   适配室友：所有人都可
```

### 2. 满床调不开 3 大策略

```
策略 1：跨床互调
   └ 把同一类型老人调开（如把 2 个老虎型调到不同楼层）

策略 2：失能老人做"缓冲床"
   └ 把失能老人放在中间床位，两边各放一个平和顺从型（不引发冲突）

策略 3：温和老人做"润滑剂"
   └ 把平和顺从型老人放在强势老人隔壁（化解冲突）
```

### 3. 室友调配方案表

```
床位 | 老人姓名 | 人格类型 | 适配室友 | 不适配室友 | 特殊需求
─────────────────────────────────────────────────────────────
1A   | 张奶奶 | 孔雀 | 兔子 | 老虎 | 每天定时聊 5 分钟
1B   | 兔子老李 | 兔子 | 任何 | — | —
1C   | 老虎老王 | 老虎 | 兔子/绵羊 | 老虎/孔雀 | 给她参与感
```

## 七、第 6 周——食堂大厨不听话 + 我没核算过

**刘院长最后 2 个头疼的事**：

> 「大厨'切菜不是我的事'——只管炒菜。」
>
> 「我没核算过——稀里糊涂。」

### 1. 大厨话术换 1 个字——从"帮我切点"到"你做菜你配"

我帮她写了一句标准话术：

```
❌ 错误："帮我切点葱姜。"
   └ 大厨心理反应："切菜不是我的事。"

✅ 正确："葱姜蒜是炒菜的前置工作——你做菜你配。"
   └ 大厨心理反应："这是做菜的一部分。"

⚠️ 关键：换 1 个字——从"帮我"到"你"。
   帮我 = 请求
   你 = 责任
```

### 2. 大厨亲自送餐 + 录音笔 + 周会播放

```
流程：
1. 大厨每周亲自送餐 2 次
2. 录音笔全程录音（老人对菜品的真实反馈）
3. 周会播放录音——让大厨亲耳听到
4. 大厨根据录音调整下周菜单

⚠️ 关键：回访日老人不把真心话说出来——因为怕大厨生气。
   录音笔 = 帮老人说出心里话。
```

### 3. 食堂 3 阶段渐进融合

```
第 1-2 周：任务独立（大厨做菜 + 帮厨做卫生，互不干涉）
第 3-4 周：交叉协作（大厨做菜时帮厨打下手）
第 5 周起：完全融合（大厨+帮厨作为一个团队）

⚠️ 关键：大厨做菜时间 2 小时足够，其他时间做卫生。
   早餐岗累得不行——是因为分工没融合。
```

### 4. 单床成本核算 3 公式

```
公式 1：单床成本 = 月总支出 ÷ 床数
公式 2：分级定价 = 床位费 + 餐费 + 护理费
公式 3：利润床位比例 = 利润 ÷ 床位收入

健康线：
- 工资占比：50-55%
- 利润床位比例：高 ≥ 30% / 中 ≥ 40% / 低 ≤ 30%
- 单老人日工时：基础 1.0h + 半护+1h + 全护+2h + 特护+3h

⚠️ 关键：刘院长原话——"床位费 1200 不知道高了还是低了"。
   按单床成本 2893 元定价 → 床位费提到 2000-2500 元/月。
```

### 5. 统一打包定价表

```
自理：8200 元/月（含床位 + 餐 + 自理基础护理）
半护：10600 元/月（含床位 + 餐 + 半护护理）
全护：13000 元/月（含床位 + 餐 + 全护护理）
特护：16400 元/月（含床位 + 餐 + 特护护理）

⚠️ 关键：看人收费 → 家属困难的减一点 → 规则不一 → 矛盾多。
   统一打包 → 规则透明 → 矛盾下降。
```

**500 强管理逻辑在这里 = 量化核算 + 流程重组**（**500 强做成本管控就是这个路径**）+ **岗位分工 SOP**（**500 强做组织设计就是这个路径**）。
