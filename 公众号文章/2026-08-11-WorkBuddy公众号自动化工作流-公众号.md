# 一个人干公司最浪费时间的不是写稿，是发稿

第一次，复制完发现正文图片全丢了。

今天这篇，是我从**下载安装 → 配公众号接口 → 搭自动化工作流 → 第一次推送成功**的全过程。不写一行代码，实测 10 分钟跑通。

一个人干公司的朋友，强烈建议收藏。

## 一、先说清楚：WorkBuddy 到底是个啥？

很多人以为它就是个"能聊天的 AI"。

不是。

WorkBuddy 是腾讯出的 AI 智能体**桌面工作台**，它真正值钱的地方，是能把一堆**分散的工作环节**串成一条流水线。

以前我写一篇公众号文章，要在 6 个工具之间来回切：

> 飞书写稿 → AI 工具润色 → Markdown 排版器调样式 → 浏览器登录公众号后台 → 上传图片 → 复制粘贴 → 预览 → 发到手机预览

WorkBuddy 干的事，就是把这些环节**全部塞进一个对话框**：

> 准备素材 → 下达指令 → AI 写作 → 自动排版 → 推送公众号草稿箱

我每天省下来的 40 分钟，现在用来回读者留言、想下一篇选题、看后台数据。

这才是 AI 该有的用法：**不是替你判断，是帮你干掉那些重复、无聊、不需要你思考的环节。**

| 准备项 | 说明 |

## 三、四步搭完整工作流（实操）

### 第一步：拿公众号 AppID（1 分钟）

AppID 就是公众号的"身份证号"，所有接口调用都要用它。

打开浏览器，登录公众号后台：

> https://mp.weixin.qq.com/

用绑了公众号的微信扫码进去。

路径：**左侧菜单 → 设置与开发 → 账号设置 → 公众号开发信息**

![图1：公众号后台 AppID 位置](图位)

你会看到一串以 `wx` 开头的字符，**复制下来，备用**。

AppID 是公开的，不用藏。但下一步要拿的 AppSecret 才是真密码，要保管好。

---

### 第二步：拿 AppSecret + 配 IP 白名单（这一步最容易踩坑）

新开一个窗口，打开**微信开发者平台**：

> https://developers.weixin.qq.com/platform/

**同一个微信扫码登录。**

路径：**我的业务 → 公众号 → 开发密钥**

![图2：开发者平台入口](图位)

如果之前没绑过公众号，系统会让你输入上一步拿到的 AppID 绑定，**管理员扫码一次**就行。

绑好之后往下找「**开发密钥**」，你会看到两样东西：

- AppID：确认和第一步一致
- AppSecret：点「启用」或「重置」→ 管理员扫码 → **生成一串新密钥**

⚠️ **这行加粗，请你务必看清楚：**

> **AppSecret 只显示这一次！** 关掉页面就再也看不到了。忘了？只能再次重置，旧的瞬间作废。

**立刻复制到密码管理器或加密笔记里。**

![图3：AppSecret 生成弹窗](图位)

---

**接下来是最容易踩坑的一步：IP 白名单。**

同一个页面往下拉，找到「**API IP 白名单**」。

它要你填一个 IP 地址。**这个 IP 是微信服务器看到的你电脑的公网出口 IP**，不是你电脑里查到的局域网 IP。

最简单的办法——**直接问 WorkBuddy**：

> "我的公网 IP 地址是多少？"

它会告诉你。

把这个 IP 复制过去，保存。

![图4：IP 白名单配置](图位)

---

**为什么这步我单独强调？**

因为**家庭宽带的 IP 是动态的**。重启路由器、隔几天自动拨号，IP 就会变。

变了之后你再推送，就会报错：

> `errcode: 40164, errmsg: ip not in whitelist hint`

报错信息里的那个 IP，就是你**新的**出口 IP。复制过去更新白名单就好。

我第一周撞了 3 次。现在我每周日晚上让它自动查一次 IP，有变化就提醒我。

---

### 第三步：把凭证告诉 WorkBuddy（1 分钟）

回到 WorkBuddy，输入一句话：

> "帮我连接公众号，AppID 是 wx***，AppSecret 是 ***"

完事。

WorkBuddy 会自动把凭证存到本地配置文件：**`~/.workbuddy/.env`**

如果你想手动来，也行。在那个文件里写两行：

```
WECHAT_APP_ID=你的AppID
WECHAT_APP_SECRET=你的AppSecret
```

配好之后 WorkBuddy 会自动测一次连通性。返回 `access_token` + `expires_in`，**就是连上了**。

![图5：连接成功返回](图位)

### 第四步：发第一篇试试（3 分钟）

凭证搞定，剩下的就一句话：

> "帮我写一篇 200 字的推文，介绍 WorkBuddy 的 3 个亮点功能，用 Markdown 格式，然后发到我的公众号草稿箱。"

WorkBuddy 会自动跑完这一串：

> 格式转换（Markdown → 公众号兼容 HTML）→ 图片上传 → 替换图片链接 → 推送到草稿箱

几分钟后，你打开公众号后台 → 草稿箱，文章已经躺那了。

你只需要：预览一遍 → 确认没问题 → 点「群发」。

**整个过程，再也不用手动复制粘贴了。**

## 四、一个我没想到的彩蛋：AI 排版反而更克制

用之前我担心：AI 排版会不会又给我整那种大红大紫、配 emoji、加边框的"公众号爆款风"？

**没有。**

WorkBuddy 默认的排版非常克制——

- 标题字号统一用公众号原生支持的尺寸
- 段间距、行间距严格按公众号阅读习惯走
- 图片不强行加边框、不加阴影
- 强调只用**加粗**和**引用块**两种

我一开始以为是它偷懒，后来想明白了：

> **真正的阅读体验，是让读者忘了排版的存在。**

花里胡哨的样式反而打断阅读节奏。这点 WorkBuddy 比很多专业排版器还懂。

## 五、几个你一定会问的问题

**Q：未认证订阅号能用吗？**

能。我自己就是未认证订阅号，token 能拿、草稿箱能推。
但订阅号接口权限比服务号少。如果遇到权限报错，考虑升级到认证订阅号或服务号。

**Q：AppSecret 忘了怎么办？**

回开发者平台 → 我的业务 → 公众号 → 开发密钥 → 重置。
旧密钥瞬间作废，重新走一遍流程。

**Q：报错 40164 怎么办？**

IP 不在白名单。重新查出口 IP，去开发者平台更新。
**家庭宽带用户每周都要检查一次。**

**Q：能不能让它直接群发，不进草稿箱？**

不建议。AI 可以提高效率，但企业对外的内容需要人工最后确认。
我把 WorkBuddy 的终点**永远设成"推送到草稿箱"**，最后那一下点击，永远留给我自己。

**Q：安全吗？**

凭证存在本地 `.env` 文件里，**不上传云端**。
文章先到草稿箱，你人工确认才发布。
和手动操作一样安全——甚至更安全，因为你不会半夜手滑点错。
