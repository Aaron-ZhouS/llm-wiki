# 30 天找到你的精准 IP 定位，把短视频做成能转的飞轮

**文 / 琪萌｜共创营第三期主理人**

---

我是琪萌。

40 岁，二胎宝妈，负债 100 万。

这是我现在的真实身份——不是讲师包装。

**去年的我，和你一样**：

- 做了账号 3 个月，发了 10 条视频，**播放量从来没破过 500**
- 看了几十个"IP 定位课"的内容，**听完觉得懂了，做起来又不会**
- 想做短视频，**不知道拍什么、不知道定位是什么、不知道飞轮怎么转**

今年 5 月，我接触到了**三要素定位法**——这是专门帮"我这种卡在定位上 3 个月起不来"的人设计的方法。

**我用 30 天跑了一遍这个方法论。**

跑完之后——
- 我的账号定位写出来了
- 我的短视频选题不再"凭感觉"
- 我的内容每天 3 条飞轮开始转起来
- 我有了自己的**陪跑营**

**今年 8 月开始，我把三要素定位法 + 30 天行动清单，**做成了共创营。

**这是第三期——精准 IP 定位 + 飞轮系统**。

这篇文章讲**三件事**：

1. **三要素定位法到底是什么**（我自己跑通过的版本）
2. **30 天行动清单长什么样**（我陪学员跑过的版本）
3. **飞轮怎么转起来**（不是理论，是每天 3 件可执行的事）

如果你做了账号 3 个月还没找到定位——**这篇你得看完**。

---

## 一、你卡在定位上的 3 个真相

**大多数想做个人 IP 的人，**都死在这 3 个地方——

### 卡点 1：你把"定位"想成了"想"出来的

> 「我应该做什么赛道？」
>
> 「我的标签是什么？」
>
> 「我能给谁提供什么价值？」

**这是我去年最常问自己的问题。**

**我天天想、夜夜想、想了 3 个月——**

**最后定位还是没出来。**

**真相 1：定位不是"想"出来的，是"挖"出来的。**

> 你不需要发明一个身份，你只需要把已经长在身上的东西说清楚。

——这是三要素定位法的第一句话。

### 卡点 2：你不知道"做账号"和"找定位"哪个先

> 「我是先做账号呢？还是先想清楚定位？」
>
> 「我想清楚了再开始，还是边做边想？」

**真相 2：定位是迭代出来的，不是一次想出来的。**

> 30 天跑完定位 → 跑数据 → 用数据微调 → 重新跑定位。

——这是三要素定位法第二句话。

### 卡点 3：你做了账号但起不来——根本原因在底色模糊

**你以为"有数据" = "账号起色"——不是的。**

**真相 3：底色模糊，再多的数据也救不了你。**

> 真正决定你账号能不能起来的，是你这个人本身——
> 你的世界观、人生观、价值观——这些模糊，发什么都是噪音。

——这是我陪学员跑过 50+ 个账号后最深的感受。

## 二、三要素定位法——我自己跑通过的版本

**三要素定位法 = 底色（道） × 本色（术） × 专业色（器）**

我陪学员跑过 50+ 个账号，**最常听到的一句话**——

> 「琪姐，三要素我都写了，但还是不会用。」

我每次都回：**「不会用，是因为你填错了地方。」**

让我把我跑通的版本**一步一步**讲给你听。

### 第 1 步：挖底色（用 1 周时间）

> 底色 = 世界观 + 人生观 + 价值观。
>
> 它决定你吸引谁、留住谁、筛选掉谁。

**第一周，我只做一件事——把三观各写一段 200 字以内的大白话自述**。

不是名人名言，是你**真实怎么看、想成为谁、怎么选**。

#### ① 世界观：你怎么看待这个世界？

```
问自己：
- 这个社会是充满机会还是充满风险？
- 人和人的差距来自哪里？
- 你最相信什么、最怀疑什么？

写下来：
- 用大白话
- 用你向老朋友解释"我怎么看待世界"的口吻
- 200 字以内

⚠️ 关键：不要写"我觉得世界很美好"这种空话。
   写"我 35 岁负债 100 万，所以我相信——现金流比梦想重要"。
```

#### ② 人生观：你想成为一个什么样的人？

```
问自己：
- 你崇拜什么样的人？
- 10 年后你希望别人怎么评价你？
- 你最不想成为什么样的人？

写下来：
- 不写"成功人士"
- 写"我绝不想成为油腻的说教者"也是答案
- 200 字以内

⚠️ 关键：写"我不想要什么"比"我想要什么"更容易写出来。
```

#### ③ 价值观：怎么判断一件事的对错？

```
问自己：
- 你做选择的底线是什么？
- 什么事情你会拒绝？
- 什么钱你不赚？

写下来：
- 价值观是"筛子"
- 它帮你把不合适的人/事筛掉
- 别怕得罪人

⚠️ 关键：写具体场景，不要写大词。
   "我反对职场 PUA"是价值观
   "我反对说教"是价值观
```

#### ④ 立场清单（底色落地成可执行）

> 把底色变成"6 条立场清单"——
>
> 明确支持 3 件 + 明确反对 3 件。

**这一步我反复跟学员强调**：

> 立场不是装饰——是你**每条视频**、**每场直播**都要对照检查的清单。
>
> 立场不一致的内容——直接停发。

**这是我做了 6 个月账号才悟出来的——**

> **真正决定你账号能不能起来的，不是"你会什么"，是"你敢拒绝什么"。**

### 第 2 步：挖本色（用 1 周时间）

> 本色 = 你的真实经历 + 个性。
>
> 真正吸引人的不是知识，而是你的性格和经历。
>
> 关注你的，永远是和你经历相同的人。

#### ① 经历盘点

```
至暗/转折经历：
- 你经历过最大的挫折、低谷、转机是什么？
- 当时怎么走过来的？
- 写下来（可适当公开的版本）

高光/成就经历：
- 你做成过、引以为傲的事是什么？
- 帮助过的人？
```

**我自己填的本色**：

```
至暗经历：
40 岁，二胎宝妈，负债 100 万。

这不是"人设"——这是我打开飞书第一页就能看到的事实。

我做过很多事——实体店主、自媒体、社群运营、训练营讲师，
但每一件事都不是"轻松上手"。

我能做出飞轮，不是因为我聪明——
是因为我试错过太多次，知道哪些坑不能踩。

高光经历：
- 用 6 周陪 1 个养老院院长跑通 6 大管理模块
- 用 AI 帮 50+ 学员写出第一条 1000+ 播放的短视频
- 把三要素定位法从 0 到 1 跑通，开了 2 期共创营
```

#### ② 个性盘点

```
个性标签（3 个词）：
- 用 3 个词形容你的性格
- 比如：真实、倔强、敢说

性格特点：
- 你和别人最大的不同是什么？
- 你擅长的事、你受不了的事
```

**这是我填的本色（真实的我）**：

```
个性标签：真实 / 倔强 / 敢说

性格特点：
- 我不会包装"自己很懂"——我不懂就是不懂
- 我不会为了钱切别人私事——超出立场的事直接拒
- 我受不了"打鸡血"——我讲的每句话都是我撞过的墙
```

#### ③ 独特价值

```
问自己：
- 有什么是只有你能给、别人给不了的？
- 结合你的经历 + 技能，越具体越好

⚠️ 关键：独特价值不是"我比别人更努力"——
   是"我有的经历/视角/方法，是别人学不来的"。
```

### 第 3 步：定专业色（用 1 周时间）

> 专业色 = 你能提供的专业知识和技能。
>
> 它是吸引粉丝、实现变现的"入口"。
>
> 记住：只做 1 个主入口，不要两个都做。

#### ① 主专业入口（二选一，不要贪多）

```
从你的选项中锁死 1 个主领域
（比如：短视频拍摄落地 / AI 工具落地一人公司）

⚠️ 关键：二选一，不是同时做两个。
   同时做两个 = 同时死两个。
```

**我自己锁死的专业色**：

```
主专业入口：AI 工具落地一人公司

不做的：短视频拍摄落地（基础 ROI 太低）

理由：
- AI 工具是 2026 年最大风口
- 我自己有 18 个月 AI 实战经验
- 我陪学员跑通过 50+ 个 AI 落地案例
```

#### ② 能力盘点 + 可交付模块

```
专业技能清单：
- 列出你在这个领域真正会、且能教别人的技能

可交付模块（3-5 个）：
- 把专业拆成 3-5 个可标准化交付的小模块
- 每个都能独立教给用户

⚠️ 关键：每个模块先出 1 条短视频 + 1 篇笔记验证市场。
   不验证 = 你以为的"市场需求"可能是幻觉。
```

#### ③ 受众与价值

```
目标人群（你帮谁）：
- 谁最需要你的专业？
- 描述得越具体越好

他们的问题/痛点：
- 这些人最大的困扰是什么？

你的方法/交付：
- 你具体教他们做什么、怎么交付结果？
```

### 第 4 步：交叉定位（用 1 周时间）

> 把前三步挖到的内容放进三圈——
>
> **我喜欢的（底色驱动） × 我擅长的（本色+专业色） × 市场需要的（可付费）**
>
> 三圈的交集，就是你的定位点。

**这是我做过的三圈求交**：

```
我喜欢的（底色驱动）：
- AI 工具实战
- 学员陪跑
- 把复杂的事讲清楚

我擅长的（本色+专业色）：
- AI 工作流搭建
- 短视频文案
- 学员陪跑
- Obsidian 知识库

市场需要的（可付费）：
- AI 工具落地一人公司
- 短视频飞轮系统
- 共创营陪跑

三圈交集 = 我的定位点：
"用 AI 工具帮 40+ 转型的素人跑通一人公司飞轮"
```

### 第 5 步：出定位宣言（最后一步）

> 工具自动拼出定位宣言与账号简介。
>
> 改任何输入都会联动刷新。

**自动生成的一句话定位**：

```
我帮助【40+ 想转型的素人宝妈/实体店主】
用【AI 工具 + 短视频飞轮】
解决【不会做内容、找不到定位、跑不通变现】的问题，
因为我【40 岁负债 100 万、转型 18 个月、跑通过 50+ 学员案例】，
并始终【真实/倔强/敢说】。
```

**完整版定位宣言（用于个人简介/主页置顶）**：

```
我是琪萌——40 岁二胎宝妈，负债 100 万。

我用 18 个月从 0 跑到 1，跑通了一人公司的最小闭环：
- 用 AI 工具替我完成 60% 的重复工作
- 用短视频飞轮每天 3 条内容持续输出
- 用共创营帮 50+ 学员从"不知道拍什么"到"我买对"

我坚持：
- 真实 > 包装
- 撞过的墙 > 听过的道理
- 跑通 > 完美

我做的是陪跑——不是课程。
我帮的不是"想学 AI"的人——是"想用 AI 改变现状"的人。
```

## 三、30 天行动清单——我陪学员跑过的版本

> 定位不落地 = 空想。
>
> 下面按周列出必做动作，每完成一项就填 "✓"，30 天后复盘定位是否成立。

### 第 1 周：挖底色（写 3 段 + 6 条立场）

```
关键动作：
① 写世界观/人生观/价值观各 200 字自述
② 列支持 3 件 + 反对 3 件
③ 设账号简介 + 个人 IP 手册第一页

输出/证据：
- 3 段自述 + 6 条立场清单
- 贴进简介置顶

验证指标：
- 立场是否写清
- 敢不敢公开
```

### 第 2 周：认对标（只认 1 个，不东抄西抄）

```
关键动作：
① 认准 1 个对标 IP
② 深度拆解其结构（选题/开头/钩子/结构）
③ 只抄这一个，不东抄西抄

输出/证据：
- 对标拆解笔记 1 份

验证指标：
- 能否复述其定位逻辑
- 能否拆解其 3 条爆款视频结构
```

### 第 3 周：定专业色

```
关键动作：
① 锁死 1 个主专业入口
② 拆成 3-5 个可交付模块

输出/证据：
- 专业色页填完
- 模块清单 1 份

验证指标：
- 模块是否可标准化交付
- 每个模块能不能独立教给用户
```

### 第 4 周：首条验证

```
关键动作：
- 每个模块先出 1 条短视频 + 1 篇笔记验证市场

输出/证据：
- 视频 1 条 + 笔记 1 篇发布

验证指标：
- 播放/互动数据
- 评论区有没有"我让这成为我的方法"的反馈
```

### 第 5 周：开启"3+1 专业输出"

```
关键动作：
- 每周 3 条拆解视频 + 1 场直播现场诊断

输出/证据：
- 3 条视频 + 1 场直播

验证指标：
- 粉丝提问数
- 涨粉数
```

### 第 6 周：敢说"不"

```
关键动作：
- 遇到超出立场/专业范围的需求，明确拒绝，不迎合

输出/证据：
- 拒绝记录 1 次

验证指标：
- 立场是否守住
- 取关的人是不是因为"立场分歧"——这才是好定位
```

### 第 7 周：案例沉淀

```
关键动作：
- 连续 4 周邀请粉丝用你的模板做作业并晒成果
- 攒 4 个真实案例

输出/证据：
- 4 个"用户用你方法解决真问题"案例

验证指标：
- 案例数 ≥ 4
```

### 第 8 周（30 天）：复盘迭代

```
关键动作：
- 回看"五定位宣言"成熟度
- 补齐最弱要素
- 用案例作为付费入口证据

输出/证据：
- 30 天复盘 1 份
- 定位迭代记录

验证指标：
- 成熟度是否提升
```

**这 8 周，**不是全部做完才叫"完成"——

是**每一周都填 "✓"，跑完就有数据**。

## 四、飞轮怎么转——每天 3 件可执行的事

> **很多学员问我：**
>
> 「琪姐，定位写完了，下一步怎么做？」

**我每次都回：**

> 「写 ≠ 跑通。你要让飞轮转起来——每天 3 件事，坚持 30 天。」

### 飞轮 = 每天 3 件

```
🌅 早上 - 写点什么
   └ 记录今天做了什么、卡在哪、学到什么
   └ 写到 Obsidian 知识库，让 AI 帮你结构化

🌞 中午 - 拍点什么
   └ 把今天的一件事变成可发布选题
   └ 5 分钟出选题 + 30 分钟出文案 + 5 分钟发布

🌙 晚上 - 每天复盘
   └ 看视频数据和反馈
   └ 找到下一次可以改的地方
   └ 把复盘结果写回 Obsidian
```

**这 3 件事** = **飞轮的 3 个齿轮**。

**第一个齿轮** = 写作（输入）
**第二个齿轮** = 拍摄（转化）
**第三个齿轮** = 复盘（迭代）

**30 天 × 每天 3 件 = 90 次写作 + 90 次拍摄 + 90 次复盘**。

跑完这 90 次——你的飞轮**第一次真正转起来**。

## 五、Obsidian 知识库——为什么是飞轮的发动机

> **这一段很重要。**

**大多数学员的飞轮转不起来——不是不努力，是没有"沉淀"。**

你今天写的内容、拍的视频、复盘的数据——**如果不沉淀到知识库，过 1 周就忘了**。

**30 天后你还是不知道该拍什么。**

**所以——Obsidian 知识库是飞轮的发动机。**

### Obsidian 知识库装什么？

```
📂 定位/
   ├ 01-底色（三观+立场）
   ├ 02-本色（经历+个性）
   ├ 03-专业色（主入口+模块）
   ├ 04-三圈交集
   └ 05-定位宣言

📂 选题/
   ├ 每日选题（每天 3 件记录）
```
