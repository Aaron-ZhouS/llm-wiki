# 【福利包】AI 公众号排版预设参数（直接套用）

> 整理自 3 篇公众号 WorkBuddy 实战教程（To B CGO/小蚂蚁学 AI/TO B 市场人指北）。所有参数都基于 md2wechat 这类 Markdown 转公众号 HTML 工具的设计原则——**让阅读回归文字，不要让排版打断阅读**。

---

## 一、核心原则（排版前必读）

| 原则 | 说明 |
|---|---|
| **克制优先** | 默认排版只做：标题层级、段落间距、加粗、引用块。**不要**边框、阴影、彩色背景、emoji 装饰 |
| **阅读优先** | 字号、行距、段距都要让读者"忘了排版存在"，不是"看见排版好看" |
| **公众号原生** | 只用公众号编辑器支持的样式，避免外链字体、自定义 CSS |

---

## 二、字体设置（基础）

```
正文字号：15px（移动端阅读舒适区间）
正文字色：#333333（深灰，比纯黑 #000 眼睛舒服）
行间距：1.8（松散呼吸感）
字间距：0（不要调，会让中文变形）
字体：-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif
```

---

## 三、标题层级

```
H1（文章大标题）：18px，加粗，字色 #000
H2（一级小标题）：16px，加粗，字色 #000，上下间距 20px
H3（二级小标题）：15px，加粗，字色 #555，前后段距 15px
正文：15px，常规
强调（行内）：加粗 + 字色 #c00（红）或 #06902f（绿），二选一不要混用
```

---

## 四、段落与列表

```
段间距：段与段之间 12px（不要更大，会显得零散）
列表项：上下间距 8px，行内无段距
引用块：左侧 4px 灰色竖线 + 背景 #f5f5f5 + 字色 #666 + 内边距 12px
代码块：背景 #f5f5f5 + 字色 #c7254e + 内边距 12px + 字体 monospace
分割线：单条 1px 灰色横线 #ddd，上下间距 24px
```

---

## 五、图片规范

```
图片宽度：100%（自适应公众号正文区）
图片对齐：居中
图片说明：图片下方 8px 字号 13px 字色 #999 居中
不要：边框、阴影、滤镜、圆角（保持公众号原生质感）
```

---

## 六、给 WorkBuddy 的预设指令（直接复制）

把下面这段作为你每次让 WorkBuddy 排版前的"系统级指令"保存：

```
【公众号排版预设】
- 正文字号 15px，行间距 1.8，字色 #333
- H1: 18px 加粗 #000；H2: 16px 加粗 #000；H3: 15px 加粗 #555
- 段间距 12px；引用块左侧 4px 灰线 + 背景 #f5f5f5
- 图片无边框无阴影，居中，宽度 100%
- 强调只用加粗 + 字色二选一（红 #c00 或绿 #06902f）
- 不要 emoji、不要彩色背景、不要花哨样式
- 输出全内联样式 HTML，兼容公众号编辑器
```

---

## 七、3 套场景化预设（按需切换）

### 预设 A：干货教程类（信息密度高）

```
- 段间距 14px（更紧凑，适合长文）
- H2 上下间距 24px（章节分隔清晰）
- 强调字色 #06902f（绿色，温和不刺眼）
- 多用引用块装"提示框"和"踩坑警告"
```

### 预设 B：故事/随笔类（阅读节奏慢）

```
- 段间距 18px（更舒展，留白多）
- H2 上下间距 32px（让眼睛休息）
- 强调字色 #c00（红色，重点突出）
- 少用列表，多用段落自然过渡
```

### 预设 C：快讯/资讯类（短平快）

```
- 段间距 10px（紧凑）
- 每段不超过 4 行
- 关键句用引用块单独成段
- 图片居中加大（视觉锚点）
```

## 八、WorkBuddy 排版后的必检清单

发布前用这 5 条逐一过一遍：

- [ ] 手机预览一遍，确认字号行距没被编辑器吞掉
- [ ] 图片全部加载，没出现裂图
- [ ] 强调字色统一（不能一段红一段绿）
- [ ] 没有 emoji 渗入正文
- [ ] 段间距肉眼均匀，没有突然变窄/变宽

---

## ⚠️ 一点诚实的提醒

这套参数来自 3 篇公开教程的实操经验，**不是 WorkBuddy 官方文档**。

实际用的时候，你大概率要根据自己的：
- **公众号阅读设备比例**（iPhone / 安卓）
- **粉丝年龄段**（中老年用户字号要更大）
- **内容类型**（干货 / 故事 / 资讯）

微调 1-2 个参数。这套预设给你的是**起点**，不是**终点**。
