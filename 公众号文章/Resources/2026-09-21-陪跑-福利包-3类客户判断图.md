# 3 类客户判断图

> **一句话定位**：咨询/直播之前先用这张图判断对方是哪一类，再决定怎么说话。
> **适用场景**：直播连麦答疑 / 私信咨询 / 短视频评论回复 / 1v1 陪跑对接

---

## 一、3 类客户图（核心 1 页）

```
┌─────────────────────────────────────────────────────────────┐
│  客户类型           真实需求           你该说的话          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 想白嫖 /        「能少付就少付      不要硬推任何产品    │
│     想少付多拿       不行我就不买了」   先看对方到底卡在哪  │
│                                            ↓              │
│                                          给一个"一杯咖啡价"  │
│                                          的入门款           │
│                                                             │
│  2. 真想做但         「我不会电脑       先解决"怕学不会"    │
│     不会、需要       我怕我学不会」     这个情绪            │
│     具体方法                            演示一遍她要做的      │
│                                            ↓              │
│                                          让她跟着做一次      │
│                                          她做完你再讲方法    │
│                                                             │
│  3. 已经做好了       「我已经做了       不要讲基础          │
│     但卡在某个       但卡在某个环节」   直接看她卡在哪一步  │
│     环节                                                  │
│                                            ↓              │
│                                          给具体下一步        │
│                                          而不是底层逻辑      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**核心口诀**：

> **不是她要什么你给什么——是先看她是哪一类，再决定给什么。**
>
> 1 类：接住「想要低价」→ 给入门款
> 2 类：接住「怕学不会」→ 演示给她看
> 3 类：接住「卡在某个环节」→ 给具体下一步

## 二、判断流程（咨询/直播前 30 秒）

### Step 1：问 1 个问题

> 「你现在做这件事，最卡的是哪一步？」

### Step 2：看对方怎么回

| 对方回答 | 类型 | 你的反应 |
|---|---|---|
| "我就是想看看 / 我也不知道 / 先了解一下" | **1 类**（白嫖/低付） | 不硬推，给一杯咖啡价入门款 |
| "我想做但不会 / 我怕学不会 / 我没基础" | **2 类**（不会+怕） | 演示一次让她跟着做 |
| "我已经在做但 X 卡住了" | **3 类**（卡环节） | 不要讲基础，直接给下一步 |

### Step 3：起手式

| 类型 | 起手话术 |
|---|---|
| 1 类 | 「我先给你一个入门款，你跑一遍看效果再说。」 |
| 2 类 | 「我演示给你看一遍，你跟着做，做完你再看值不值得继续。」 |
| 3 类 | 「你说具体卡在哪，我直接给你下一步。」 |

## 三、3 类客户的真实脸（来自琪姐 8/12 第一次直播连麦答疑）

### 客户 A：想做短视频带货的 60 后（2 类，不会+怕）

- **现象**：不会电脑 / 讲了学什么 / 直接没回复
- **没接住的原因**：没接住她「怕学不会、电脑小白」的真实痛点
- **正确做法**：演示一遍"60 后也能用的 AI 工具"——让她看到自己也能做到

### 客户 B：两个咨询"怎么做的"（1 类，想要低价）

- **现象**：想要「付少的价格拿结果」
- **没接住的原因**：推了 6000+ 没推一杯咖啡价入门款；100 倍价差直接劝退
- **正确做法**：一杯咖啡价 + 社群答疑当入口，跑通转化

### 客户 C：晚上直播间接住的 50 多岁粉丝（2+3 混合）

- **现象**：看到了 50 多岁的学员已经跑通，她也 50 多 / 没用 AI 工具 / 家里没电脑
- **接住的回应**：
  > 「一杯咖啡价是不是可以带她跑通变现路径？」
  > 「变现路径是做的过程中长出来的，不是提前设计好的。」
  > 「我能做的就是：你买完小报童，有问题可以直接来问我。」
  > 「不知道怎么下载的，我给你下载网址。」
  > 「使用过程中有问题来问，直播间也可以连线答疑。」

**这一单的接住 = 5 句话模板**：
1. 回应她的具体问题（"一杯咖啡价能不能跑通"）
2. 给真实预期（"路径是做的过程中长出来的"）
3. 明确你交付什么（"有问题来问我"）
4. 降低行动门槛（"我给你下载网址"）
5. 留长期触点（"直播间可以连线答疑"）

## 四、自检清单（每次咨询/直播后 30 秒）

```
□ 我判断了对方是哪一类吗？（1 类/2 类/3 类）
□ 我有"硬推产品"吗？（如果有 → 立刻调整）
□ 我有"讲底层逻辑"吗？（如果对方是 3 类 → 改成具体下一步）
□ 我有"演示一次"吗？（如果对方是 2 类 → 必须演示）
□ 我有"留长期触点"吗？（如果对方是 1 类 → 给她入门款当入口）
```

**5 项全勾 = 这次咨询/直播接住了。少于 3 项 = 对方大概率没成交。**

---

## 五、红灯边界（5 条硬门禁）

- 🚫 **不要硬推 6000+** —— 100 倍价差直接劝退，先给一杯咖啡价入口
- 🚫 **不要讲底层逻辑给 3 类** —— 她已经卡在具体环节，底层逻辑帮不了她
- 🚫 **不要对 2 类说"这个很简单"** —— 她怕的就是学不会
- 🚫 **不要同时给 5 类话术** —— 一次只判断一类，决定一种说法
- 🚫 **不要让 1 类白嫖** —— 给一杯咖啡价的入门款，让对方有最小投入
