# 【福利包】WorkBuddy 公众号自动化指令清单（15 条实战指令）

> 整理自 3 篇公众号 WorkBuddy 实战教程，全部经过实测验证。复制粘贴即用，把指令前缀的 `[占位]` 替换成你的真实内容。

---

## 一、连接与凭证配置（3 条）

### 指令 1：连接公众号

```
帮我连接我的微信公众号。
- AppID：[粘贴你的 AppID]
- AppSecret：[粘贴你的 AppSecret]
连接完成后，自动测一次连通性，把 access_token 和 expires_in 给我看。
```

### 指令 2：查询公网 IP（用于 IP 白名单配置）

```
我的公网 IP 地址是多少？请直接告诉我 IP，不要解释。
```

### 指令 3：手动配置 .env 文件（备用方案）

```
帮我创建 ~/.workbuddy/.env 文件，写入以下两行：
WECHAT_APP_ID=[你的AppID]
WECHAT_APP_SECRET=[你的AppSecret]
保存后测试连通性。
```

## 二、写作 + 排版 + 推送一体化（5 条）

### 指令 4：单篇推草稿箱（最常用）

```
帮我写一篇 [字数] 字的推文，主题是 [主题]。
要求：
- 目标读者：[读者画像]
- 风格：[口语化/专业/幽默]
- 用 Markdown 格式
- 完成微信公众号排版
- 推送到公众号草稿箱
```

### 指令 5：基于本地素材生成文章

```
请根据我引用的 [文件夹/文件]，写一篇 [字数] 字的公众号文章。
文章结构：[列出 3-5 个段落主题]
风格要求：[具体风格描述]
完成排版后推送到草稿箱。
```

### 指令 6：改稿 + 重新排版（不重写）

```
把刚才那篇文章的开头改成 [新的开头要求]。
改完后重新排版，并推送到草稿箱（覆盖原草稿）。
```

### 指令 7：调整排版样式

```
这篇稿子的排版改成：
- 标题字号 [15px/16px/17px]
- 段间距 [数值]
- 强调样式只用加粗和引用块
- 不要 emoji 和花边
完成后推送到草稿箱。
```

### 指令 8：批量生成多平台版本

```
把这篇公众号文章改写成：
1. 微博版（140 字以内，带话题标签）
2. 知乎版（800 字长答案）
3. 小红书版（带 emoji，分段）
完成后每个平台保存为独立文件。
```

## 三、排错与诊断（4 条）

### 指令 9：检查连接状态

```
帮我检查公众号连接状态。如果不通，把完整报错信息给我看，并提示我应该检查哪个环节。
```

### 指令 10：IP 报错的诊断与修复

```
我推送时报错 40164（ip not in whitelist）。
请：
1. 告诉我现在的公网 IP
2. 给出更新 IP 白名单的具体步骤
3. 重新推送测试
```

### 指令 11：AppSecret 重置后的重新配置

```
我重置了 AppSecret，新值是 [新密钥]。
请：
1. 更新 ~/.workbuddy/.env
2. 重新测试连接
3. 推送一篇文章验证
```

### 指令 12：草稿箱残留清理

```
我公众号草稿箱里有 [N] 条未发布的旧稿。
请列出最近 10 条的标题+日期，让我决定哪些保留、哪些删除。
不要直接删除，等我确认。
```

## 四、选题与素材库搭建（3 条）

### 指令 13：手动同步外部文章

```
请同步这篇公众号文章到我的素材库：
- 链接：[粘贴 mp.weixin.qq.com 链接]
抓取：标题、作者、正文、发布时间
分析：关键词、文章结构、金句、标题模板
```

### 指令 14：基于历史文章挖选题

```
分析我最近 [N] 篇已发布文章，找出：
1. 阅读量最高的 3 篇，列出共性
2. 出现频率最高的关键词 TOP10
3. 基于这些规律，给我 10 个可写的新选题
```

### 指令 15：抓外部热点 + 写选题

```
请抓取今天 [百度热搜/微博热搜/知乎热榜] 的前 20 条。
判断哪些和我 [你的赛道] 相关。
给我 5 个可写的选题，每个配 3 个切入角度。
```

## 📌 使用说明

1. **替换占位符**：所有 `[xxx]` 都是占位，复制后改为你自己的内容
2. **增量指令**：每次新需求都可以在前一条基础上加，WorkBuddy 会保持上下文
3. **安全原则**：永远让它推到**草稿箱**，最后那一下"群发"自己点
4. **凭证备份**：AppSecret 一定要存在密码管理器，别只放在 .env 里
