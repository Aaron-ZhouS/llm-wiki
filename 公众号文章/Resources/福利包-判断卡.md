# 【福利包】判断力训练卡模板（5 个字段，照着填就能跑）

> 来自公众号文章《用了 AI 一年我才明白：未来拼的不是会用工具，是判断力》。对应评论区关键词 **"判断卡"**。
>
> 适用读者：你意识到判断力重要，但具体怎么"训练"没思路——用这张卡每天 5 分钟就能跑起来。

---

## 一、为什么需要这张卡？

胡子哥说——

> "**做决策→看结果→复盘纠偏。**"

但**大部分人卡在第二步**——他们做了决策、看了结果，但**没把"决策+依据+预测+归因"沉淀下来**。

下次再做类似决策，**重新来一遍，犯同样的错**。

这张卡的全部价值 = **让你下次不要再做同样的决定**。

---

## 二、5 字段模板（最简版）

每次做完一个重要决策，**填这 5 个字段**（不超过 5 分钟）：

```markdown
## 决策记录卡

### 1. 我做的决策
[一句话说清你做了什么选择]

### 2. 当时的关键依据
[2-3 条，每条不超过 1 句话]

### 3. 我赌的结果
[预测这件事会带来什么具体效果]

### 4. 实际结果
[填卡时如果已经发生，写实际；没发生就留空]

### 5. 下次类似决策怎么改
[学到了什么。如果第 4 项留空就写"待观察"]
```

## 三、真实案例（我自己用过的）

### 案例 A：选一人公司赛道

```markdown
## 决策记录卡

### 1. 我做的决策
选择"一人公司 + AI 副业"作为全职赛道，放弃继续打工路径

### 2. 当时的关键依据
- 通勤 5 小时，45 岁打工时间成本太高
- 风险管理背景可翻译成"帮个人做不确定决策"产品
- 工具链已就位（Hermes + DeepSeek + Aider）
- 视频号口播能快速跑通现金流

### 3. 我赌的结果
- 6 个月内跑通第一笔收入
- 12 个月内实现稳定现金流
- 24 个月内达到与打工收入持平

### 4. 实际结果
- 138 天时：视频号破 50 万播放，公众号起步
- 收入：未达预期（流量起来了，变现慢）
- 现金流：副业打底未断档

### 5. 下次类似决策怎么改
- 流量和变现分开赌，不要捆一起
- 变现产品的设计要在 60 天内验证，而不是 6 个月
- 决策时多问"我愿意放弃什么"，比问"我能得到什么"更准
```

### 案例 B：选 WorkBuddy 作为公众号工具

```markdown
## 决策记录卡

### 1. 我做的决策
用 WorkBuddy 替代人工，做公众号发文自动化

### 2. 当时的关键依据
- 手动发文 45 分钟/篇，时间成本太高
- 公众号接口配置一次成本不到 1 小时
- WorkBuddy 推到草稿箱比人工复制粘贴稳

### 3. 我赌的结果
发文流程从 45 分钟压到 5 分钟

### 4. 实际结果
效果达预期。配 IP 白名单那一步撞了 3 次坑，但整体跑通。

### 5. 下次类似决策怎么改
- 涉及 API 配置的工具，先看"接口文档是否中文"再决定
- 涉及动态 IP 的工具，第一周就要准备"自动查 IP"任务
- 配置类工作流，第一篇草稿先发给自己，别直接发到公众号
```

## 四、怎么用这张卡？

### 用法 1：每天 1 张（最简单）

每天结束前，**填 1 张卡**——哪怕是"今天接了一个合作 / 今天写了一条视频 / 今天砍了一个选题"。

**30 天 30 张 = 一份你自己的判断力档案。**

### 用法 2：每周对比预测和现实

每周日晚上 10 分钟，把这周的几张卡过一遍：

- **预测成立的** → 进"判断技能库"（下次类似场景直接复用）
- **预测失败的** → 三桶归因：
  - 执行桶：想法对，执行没做到位
  - 判断桶：想法本身就错了
  - 噪音桶：运气问题，本次不沉淀

### 用法 3：沉淀进知识库

每张卡的"第 5 项"——**就是你的知识库里最值钱的卡片**。

把它们专门存进 `wiki/concepts/` 或者 `wiki/decision-cards/`，**AI 下次给你建议时会主动调用**。

## 五、什么样的决策值得记？

**记的：**

- 接不接某个合作
- 选哪个赛道
- 做不做某个产品
- 砍不砍某个方向
- 给某个内容投多少时间

**不记的：**

- 今天吃什么
- 周末去哪玩
- 这种"重复性的小决策"不需要浪费卡片空间

**判断标准：**

> **这个决策如果错了，我会损失 ≥ 100 元（钱 / 时间 / 信任）？**
>
> **答是 → 值得记一张卡。**

---

## 六、3 个常见误区

### 误区 1：决策越大越值得记

不对。

**越是日常的小决策越值得记——**因为你每天做 5 个小决策，一年就是 1500+ 次。**1500 次小决策的复利，远比 3 次大决策值钱。**

### 误区 2：预测错了要自责

不对。

**预测错了是你"花钱买判断力"的证据——**没预测就不知道错在哪，预测了才知道下次怎么改。

**预测错了不是失败，是判断力训练的素材。**

### 误区 3：填卡要很久

不对。

**5 个字段，5 分钟，超过这个时间 = 决策不够"日常"，要拆小。**

把大决策拆成几个小决策，分别记卡。

> **判断力 = 撞墙 100 次 + 每次撞完记一张卡。**
>
> **没记的撞墙是浪费，记下来的撞墙是判断力。**
