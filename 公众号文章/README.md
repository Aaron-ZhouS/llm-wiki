# 公众号文章库

> 专门存放「大盛发到微信公众号（视频号同源图文）的长文」的地方。
> 每篇文章独立成文件，便于 Obsidian 改稿、git 备份、二次复用（转视频号口播稿 / 知识卡片 / 小报童文）。

跟 `小报童文稿/` 是**姐妹库**，分工如下：

| 库 | 平台 | 文章长度 | 调性 |
|---|---|---|---|
| [[小报童文稿/README\|小报童文稿]] | 小报童 xiaobaotong.com | 3500-4500 字深度长文 | 教程+体系化 |
| **公众号文章** | 微信公众号 / 视频号图文 | 2500-4000 字中长文 | 钩子+爆款+强共鸣 |

---

## 触发词（AI agent 必读）

**用户说以下任何一句，立刻把内容写进本目录：**

| 触发词 | 动作 |
|--------|------|
| "放公众号文章库" | 把当前草稿写到 `公众号文章/` |
| "这篇发公众号" | 同上 |
| "写公众号文：主题 XXX" | 新建一篇文稿，文件名 `YYYY-MM-DD-主题关键词-公众号.md` |
| "归档公众号" | 把已发布的文稿从草稿目录归档到本目录，添加 `status: published` |

**不要做的：**

- ❌ 不要写到 `Articles/`（那是图片导入归档，不是公众号文章）
- ❌ 不要写到 `Knowledge-Cards/`（那是单点知识卡）
- ❌ 不要写到 `/home/aaron/workspace/`（那是临时草稿）
- ❌ 不要写到 `小报童文稿/`（那是长文教程库，不同平台）

## 文件命名规范

```
YYYY-MM-DD-主题关键词-公众号.md
```

示例：
- `2026-08-10-100条视频没流量-公众号.md`
- `2026-08-15-一人公司100天复盘-公众号.md`

## 文件结构（每篇正文内）

```markdown
# 标题（第一行）

## 开头钩子（3秒抓住读者）
- 具体数字 / 反常识 / 痛点共鸣
- 必须带"我和你一样"的代入感

## 主体（分模块写）
- T-PDCA / 5段结构 / 强破圈
- 每段都带情绪曲线低谷→高峰→递减
- 表格 + bullet + 加粗关键词

## 收尾（呼应开头+金句+转发钩子）
- "收藏+转发"驱动
- 落款"周盛 / 一人公司100天挑战中"
```

## 公众号 vs 小报童 调性差异

| 维度 | 公众号 | 小报童 |
|------|--------|--------|
| 开头 | 钩子+数字+反常识（3秒抓住） | 概念引入+背景铺垫 |
| 节奏 | 口语化、强情绪曲线 | 体系化、有完整结构 |
| 结尾 | "转发给那个……的朋友" | "本周审计清单" |
| 配套 | 视频号图文同发 | 仅小报童平台 |
| 字数 | 2500-4000 字 | 3500-4500 字 |

## 复用关系

公众号文章写完后，可以：
1. **改写成口播稿**（调用 `oral-alchemy` skill）
2. **拆成知识卡片**（调用 `knowledge-card-forge` skill）
3. **扩写成小报童长文**（调用 `xiaobaotong-writer` skill）

逆向复用也可以：小报童文稿的核心模块，可以压成公众号爆款文。
