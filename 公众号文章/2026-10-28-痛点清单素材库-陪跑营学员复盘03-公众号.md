# 化疗掉光了头发的人，现在每天有拍不完的素材

**文 / 琪萌｜陪跑营老师｜一个人公司搭建中**

---

复盘会上，我让每位学员讲自己这一周做了什么。

有一位讲到一半，我打断了她。

因为她讲的那件事，听起来不像"学了 AI"，像换了一个人。

**她曾经患白血病，做过化疗，头发都掉了，一个人孤孤单单去治疗。那时候她没有自信心，整个人低迷。**

现在呢？

她学了 AI 助手和 Obsidian 知识库之后，整个人的状态是翻天覆地的变化。个人 IP 定位是我们陪跑营里帮她一起定位出来的；痛点清单素材库整理好了；每天有拍不完的素材。

上次复盘会开完，我给团队定了一条拍视频的规矩：**别先讲我怎么带的，先把学员拿到的结果往前放。** 我给他们的原话是——**你把前面的这个学员的效果前置，他拿到了什么一个效果，先前置做个强钩子。**

所以今天这篇，我先讲结果。

---

## 一、文姐进陪跑营之前：三个细节

我不打算把这一段写得煽情。她自己的状态就那几个字：以前低迷、生重病。

**第一个细节：化疗。头发都掉了。**

**第二个细节：一个人孤孤单单去治疗。**

**第三个细节：没有自信心。**

我要说的是一件事——**她当时的账号状态，跟她当时的身体状态，是同一个状态。**

一个人刚被病魔按在地上，谁也没心思研究钩子怎么设计、痛点怎么讲。她不是不想做内容，她是那会儿连"想做"这件事的力气都没有。

所以我从不觉得，对这个阶段的人讲"你要有 IP 意识"是句有用的废话。

**先把人扶起来，再谈账号。**

---

## 二、我第一次辅导她，卡在哪

第一次沟通，卡住的不是工具。

她之前做自媒体，用的是"抄对标"——抄张三抄李四。**数据一直不好。** 不知道怎么拍，也不知道产品在哪里。

我先带她做定位（下一节展开）。定位定下来之后，我以为她可以开拍了。

结果复盘的时候，助教跟我讲了她选的对标账号的情况：**一个都不对。**

我们没有绕过去。这个问题现在还没解决。我们打算另外搞一场对标账号的培训，专门教怎么找。

**这一点我必须如实写出来。** 很多复盘文章写到学员这里，就变成"所有人都做到了"。不是的。她还有一个坑，正踩在里面。

那第一次辅导我做了什么？

**我没有催她"先拍一条试试"。**

我常说的一句话是：「结构不是我说了算的，结构是你先去拍一条看看效果怎么样。」但这句话有前提——**手里得有弹药。** 没弹药的时候拍什么都是空转，拍得越多越慌。

所以我先解决她"是谁"的问题，再解决她"拍什么"的问题。

信任感是怎么建立的？不是我说得多有道理，**是她能看见自己在往前走**——从"不知道怎么拍"，走到"有表可查"。

---

## 三、私人订制做了什么：四步

### 第一步：定位诊断

**她的个人 IP 定位，是在训练营里定位出来的。**

定位出来之后，她就知道自己的个人人设是什么、应该帮助哪些特定人群、产品是什么。

这个定位的原话是：**她不但要靠自己的能力把自己从病魔当中挣脱出来，还要做一个独立、有个性、能帮助到其他中年女性的女强人形象。**

用真心、爱心、耐心去做社群；用 AI 帮这些中年女性独立自强。

这句定位里有两层意思：**先救自己，再救别人。** 顺序不能反。

### 第二步：建痛点清单素材库

定位解决"给谁看"，痛点清单解决"看什么"。

**她现在整理好了一个素材库，也就是她的弹药库——每天都有拍不完的素材。**

这一步的价值不在"素材多"，在于**她从"每天重新想选题"，换成了"每天从表里挑一个"。** 开放题变成封闭题，人就敢动手了。

### 第三步：给她短视频的骨架

她现在能用的短视频黄金四大结构是：

```
吸引用户 → 戳中痛点 → 给出方案 → 引导行动（CTA）
```

选题路径也是固定的：

```
整理痛点清单 → 从母痛点里选子痛点 → 每个子痛点拍一条短视频 → 用四大结构优化数据
```

**结构不是内容。** 我给的是骨架，她的痛点清单是血肉，案例是她自己的。

### 第四步：教她"每天写点什么" + 把变现链设计出来

她现在每天要写点东西沉淀：**解决痛点的过程，怎么拍自媒体，怎么选钩子，怎么把痛点讲清楚，用的是价值引导还是情绪引导。**

粉丝开始问问题的时候，这些沉淀就直接变成产品。

**变现链是这样接上的：** 粉丝问"你这个爆款文案结构怎么做的"——她就知道自己的爆款结构是从吸引、痛点、案例、CTA 里一轮轮迭代出来的。所以 1.0 版本要有**痛点清单 + 钩子库 + 案例库**，再做成付费文章、社群、变现手册。

**别人问的问题，就是你的产品目录。** 这是我做变现设计时最爱用的一条路径。

---

## 四、文姐现在什么样

复盘会上她讲自己的变化，讲了三个点。

**第一，她整个人翻天覆地了。** 我们做学员总结的时候，用的就是这四个字——**翻天覆地**。

**第二，她知道人生意义在哪里了。** 她现在想清楚了自己的**人生观、价值观、世界观**。她的一句话是：**人生的意义不是单单活着。**

一个人曾经连"活下去"都要用尽全力的人，开始回答"意义"这个问题了。这个变化，比涨多少粉都重要。

**第三，她的 IP 形象立住了。** 独立、有个性、能帮到其他中年女性的女强人。她还在看很多**女性成长**的书，让自己更自信、更独立。

她现在正处在**要把短视频拍火**的阶段——还差临门一脚，所以后面还有硬仗。

**还有那件没解决的：对标账号一个都不对。** 我们打算单独开一场对标账号的培训。她自己也没有藏着这件事。

## 五、一条能迁移的方法

文姐这期最值得你拿走的，不是"她做成了 IP"，是**她把选题从开放题变成了封闭题**。

我把它整理成四步，叫**「痛点清单到视频」**：

```
痛点清单到视频
├─ 1. 先把痛点清单整理出来（素材库 / 弹药库）
├─ 2. 从母痛点里选一个子痛点
├─ 3. 这个子痛点，拍一条短视频
└─ 4. 用四大结构（吸引→痛点→方案→CTA）优化数据
```

**关键在第 3 步和第 4 步之间。**

拍完一条别急着发下一条，**先看数据，再决定下一条怎么拍**。数据好，就把这套结构的优点放大；数据不好，立刻换结构。

我常说：「最终，最终，最终都是要经过市场验证。」「自己想的东西不对的呀，要经过整个自媒体的迭代的。」

**你今天就能做的动作：** 打开你的微信，翻翻最近的聊天记录，把别人向你求助的**原话**抄下来——一句一句抄，不要改写成总结。

**那些原话就是你表里的每一行。**

---

## 六、为什么陪跑营能做到这些

陪跑营的节奏很固定：**每周一三五上课，周末带大家复盘这一周做了什么。**

分工也很清楚：**助教远程协助装系统，解决技术支持那部分；我负责方法论指导、定位诊断、复盘把关、路径设计。**

讲四个不一样：

**不一样一：定位这一步，有人逼你答。** 文姐的定位不是自己坐着想通的，是有人一句一句追问出来的。自己问自己，很容易糊弄过去。

**不一样二：方向错了，有人第一时间看出来。** 她选的对标账号一个都不对——这种事自己很难发现，因为你不知道你不知道什么。

**不一样三：路径是照着起点设计的。** 文姐的起点是中年女性社群，所以路径是"痛点清单 → 短视频 → 付费文章和社群"。别的学员起点不一样，路径也不一样。

**不一样四：有个真的人在等你的第一个结果。** 定位做完了、素材库建起来了，她下一步就是拍第一条。有人在等，她就不容易发完就忘。

### 适合谁

- **一直在抄对标、数据一直不好的人**——你不是拍得不好，你是没有弹药
- **知道自己想做什么、但不知道怎么开始的人**
- **想用 AI 帮别人一把的人**——文姐的目标就是用 AI 帮这些中年女性独立自强

### 怎么报名

**1. 在公众号后台回复「陪跑营」**，我把陪跑营的安排、上课节奏和适合的人讲清楚。

**2. 也可以先约一次 1v1 视频沟通。** 我听你讲你的赛道，帮你判断你现在卡在哪一段——是定位没定，还是素材不够，还是结构不对。

**报名之后第一件事不是学工具，是把你的定位写出来。**

---

## 写在最后

复盘会上我让每位学员讲自己的过程。

文姐讲完，最让我意外的不是她的定位，是**她已经不需要抄对标了**。

以前她抄张三抄李四，是因为手里没有自己的东西可讲。**现在她每天要解决自己表里的痛点、要用四大结构把痛点讲清楚，她没工夫抄了。**

我心里想，这就是这期最值钱的一句话。

**抄对标，是因为你没有自己的东西可讲。**

**有一句话我想送给你：**

> **"以前我觉得我缺的是方法。后来才发现，我缺的是先想清楚，我到底要帮的是谁。"**

**你也是。**

先把定位写出来，素材表才会长出来。
