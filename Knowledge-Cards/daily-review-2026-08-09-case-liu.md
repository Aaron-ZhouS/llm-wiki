# 案例卡｜刘院长 5 天 6000 成交全过程

## 一句话总结

**不是我在卖，是她看着我在用。** 6000 元学员刘院长，从看到第一条短视频到付款，全程 5 天，一次推销都没有。

## 时间线

| 日期 | 事件 | 关键动作 |
|------|------|---------|
| 6/26 | 第 1 条视频发布 | 展示自己搭系统 + 帮朋友装 + 公司现场图 |
| 6/27 | 第 2 条视频发布 | 第二条变现路径，播放量 9497；评论区主动说"安装业务不会长久存在" |
| 6/27 | 刘院长加微信 | 当天远程装 Hermes + Codex，一路讲我们一个多月怎么起来的 |
| 6/29 | 开始装 5 个 skill | 灵感 / 洞见 / 知识卡片 / 口播文案 / 连接 skill |
| 6/30 | 调试中"顺手截图" | 给她看正在给别人整理文档的画面 + 提到内部直播 |
| 7/1 | 装系统时聊陪跑营 | 装完当场付款 6000，知识库还没完全搭好 |

## 关键画面（画面感锚点）

1. **6/26 视频评论区**：养老院能用不？实体店能用不？——我的系统不是一个垂类应用，是"通用 AI 操作系统"
2. **6/27 评论区那句"我不会让它长久存在"**：主动设限，反而激发购买欲
3. **6/30 截图那一瞬**：不是设计，是真顺手——但这种"现场"画面是销售里被低估的
4. **7/1 装完当场 6000**：知识库都没搭完，但人已经买了

## 反常识点（可复用方法论）

| 错误做法 | 正确做法 |
|---------|---------|
| 主动推销 | 让她看着我怎么用 |
| 单条爆款 | 系列铺垫（前面 4-5 条讲姜胡说系统 + skill 效果） |
| 展示最终产品 | 展示"我在做事"的现场 |
| 承诺长期业务 | 主动设限"不会长久存在" |
| 准备好再卖 | 知识库没搭完，6000 已到账 |

## 核心金句（可单独传播）

- **"成交不是把东西卖出去，是让对方亲眼看见这个东西是怎么用的。"**
- **"不是我在卖，是她看着我在用。"**
- **"短视频不是单条爆款，是系列铺垫。"**
- **"客户买的不是产品，是你这一个月的真实过程。"**

## 可延伸选题（5 个切口）

1. 播放量从 200 到 9497，中间我做了什么（前置铺垫）
2. 陪跑营提前跟合作伙伴谈好的——为什么"提前设计"比"现场推销"更可信
3. "我不会让它长久存在"——主动设限的心理学逻辑
4. 5 天 vs 6 个月：同样是付费学员，为什么差距这么大
5. 截图那一瞬——为什么"让客户看见你正在做事"是销售里被低估的一招

## 用在哪

- 短视频选题：直接出 1 条 30-40 秒短稿（反常识钩子 + 时间线 + 金句）
