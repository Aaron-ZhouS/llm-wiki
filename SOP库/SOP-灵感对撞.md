# SOP · 灵感对撞 Skill

> **一句话定位**：把你库里 2 个以上的素材/卡片，让它们互相"打架"，产生新洞见。
> **核心心法**：单个素材只能挖出深度；多个素材对撞才能挖出新意。

---

## 1. 什么时候用（触发信号 3 条）

✅ **满足任意 1 条就触发**：
- 你库里积累了 2+ 个素材/卡片，想让它们碰撞出新洞见
- 你想批量处理多个素材（一次性产出 1 个新观点）
- 你想用 PARA 方法论管理知识库

## 2. 什么时候不用（避坑 3 条）

❌ **触发这些就别用，换 Skill**：
- **只有 1 个素材** → 换 `灵感炼金` 单素材提炼（这是硬门禁）
- 想做完整方法论 → 换 `灵感炼金`
- 想做知识卡（图卡用 design，纯卡用 forge）→ 走"对撞后铸卡"的下游流程

## 7. PARA 4 阶段工作流（学员需要知道）

```
阶段 1：收件（Identify） — 找素材
   ├─ 学员贴 1-N 段素材
   ├─ 学员指定 PARA 路径
   └─ 触发"挖矿"批量

阶段 2：碰撞（Collide） — 出洞见
   ├─ 抽取：每篇素材的核心 1 句话
   ├─ 配对：找到至少 2 个素材的共同/对立点
   └─ 爆发：用 7 刃或"矛盾-张力-解决"框架产出 1+ 个新洞见

阶段 3：铸卡（Forge） — 把洞见变卡
   ├─ 文字卡 → knowledge-card-forge
   ├─ 图卡 → knowledge-card-design
   └─ 金句 → kuangcai

阶段 4：归档（Archive） — 处理原素材
   ├─ 消化：素材用完了 → 删除或归档到 04-归档/
   ├─ 保存：素材还有用 → 加标签，留在 00-灵感库
   └─ 升级：从 00-升级到 01-项目 或 02-领域
```

## 8. 实战示例（琪萌用例）

> **学员**：琪萌
> **场景**：8 张知识卡积累后，发现有 3 张都在讲"认知迭代"
> **触发**：「/对撞 把 KC-QIMENG-20260813 复盘方法论的认知差、KC-QIMENG-20260814 数据稳定与公众号质量、KC-QIMENG-20260815 30 天挑战与产品矩阵重构 这 3 张对撞」
>
> **AI 跑了什么**：
> 1. 抽取 3 张卡的核心 1 句话
> 2. 配对：发现共同主题 = "认知迭代的节奏"
> 3. 爆发新洞见：**"认知迭代不是一次性升级，是每个月 1 次小迭代比 1 年 1 次大升级更有效"**
> 4. 自动铸卡：图卡（design）→ 发布视频号
> 5. 归档：3 张原卡升级到 02-领域/认知方法论
>
> **学员拿到**：1 张新图卡 + 1 个新认知 + 整齐的归档报告

## 9. 红线（学员最容易踩的 3 个坑）

🚫 **只有 1 个素材就触发"对撞"** — 素材不足，AI 会引导你补到 2 个
🚫 **不写新洞见就归档** — 没产出 = 没对撞，AI 会返工
🚫 **归档后找不到原始素材** — AI 必须留引用链接
