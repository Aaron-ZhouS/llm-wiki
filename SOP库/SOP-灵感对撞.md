# SOP · 灵感对撞 Skill

> **一句话定位**：你库里有 3 张卡片，但每张都是孤岛？灵感对撞让它们互相打架，产出新洞见。
> **核心心法**：单素材只能挖出深度；多素材对撞才能挖出新意。

---

## 一、先看清卡点：为什么卡片越多越没洞见

**场景痛点**：

你库里有 50 张卡片，分类清晰、检索方便。但你想发视频、写文章的时候，发现**没有任何一张能直接用**——它们各自孤立，没有联系。

**认知卡点**：

你以为"沉淀多 = 产出多"。其实**孤立的卡片不会自动合成洞见**，需要主动让它们"打架"。

**解决方案**：

灵感对撞的解法是 PARA 4 阶段（**收件 → 碰撞 → 铸卡 → 归档**）+ 7 刃提炼。**对撞 = 强迫不同卡片在同一个问题上对话**。

**原话**：

> 胡子哥原话："我已经不再追求正确了，我在追求思想的震荡。他有时候给我对撞出来的东西很荒谬，但是那种思考对撞的过程，本质上你是在练习逻辑。"

## 二、什么时候用 / 什么时候不用

### ✅ 满足任意 1 条就用

- 你库里积累了 2+ 个素材/卡片，想让它们碰撞出新洞见
- 你想批量处理多个素材（一次性产出 1 个新观点）
- 你想用 PARA 方法论管理知识库

### ❌ 触发这些就别用

- **只有 1 个素材** → 换 `灵感炼金` 单素材提炼（**这是硬门禁**）
- 想做完整方法论 → 换 `灵感炼金`
- 想做知识卡 → 走"对撞后铸卡"的下游流程（对撞 → 自动成卡）

## 三、4 阶段流程（学员视角只关心前 2 个）

```
【阶段 1】收件：贴 2+ 个素材（或指定 PARA 路径）
       ↓
【阶段 2】碰撞：AI 自动抽核心、配对、爆发新洞见
       ↓
【阶段 3】铸卡（自动）：新洞见自动 → 文字卡/图卡/金句
       ↓
【阶段 4】归档（自动）：原素材消化/保存/升级
```

学员只负责收件 + 看新洞见。后 2 阶段 AI 全自动。

## 五、PARA 4 阶段详解（学员需要知道）

```
阶段 1：收件（Identify） — 找素材
   ├─ 学员贴 1-N 段素材
   ├─ 学员指定 PARA 路径
   └─ 触发"挖矿"批量

阶段 2：碰撞（Collide） — 出洞见
   ├─ 抽取：每篇素材的核心 1 句话
   ├─ 配对：找到至少 2 个素材的共同/对立点
   └─ 爆发：用 7 刃或"矛盾-张力-解决"框架产出 1+ 个新洞见

阶段 3：铸卡（Forge） — 把洞见变卡
   ├─ 文字卡 → knowledge-card-forge
   ├─ 图卡 → knowledge-card-design
   └─ 金句 → kuangcai

阶段 4：归档（Archive） — 处理原素材
   ├─ 消化：素材用完了 → 删除或归档到 04-归档/
   ├─ 保存：素材还有用 → 加标签，留在 00-灵感库
   └─ 升级：从 00-升级到 01-项目 或 02-领域
```

## 八、实战示例（琪萌用例）

**学员**：琪萌

**场景痛点**：8 张知识卡积累后，发现有 3 张都在讲"认知迭代"，但讲的角度不同。

**触发**：「/对撞 把 KC-QIMENG-20260813 复盘方法论的认知差、KC-QIMENG-20260814 数据稳定与公众号质量、KC-QIMENG-20260815 30 天挑战与产品矩阵重构 这 3 张对撞」

**AI 跑了什么**：

1. **抽取**：每张卡的核心 1 句话
   - 0813：复盘的认知差比经验差更重要
   - 0814：数据稳定来自公众号质量判定
   - 0815：30 天挑战逼出产品矩阵
2. **配对**：发现共同主题 = "认知迭代的节奏"
3. **爆发新洞见**：**"认知迭代不是一次性升级，是每个月 1 次小迭代比 1 年 1 次大升级更有效"**
4. **铸卡**：图卡（design）→ 发布视频号
5. **归档**：3 张原卡升级到 02-领域/认知方法论

**学员拿到**：1 张新图卡 + 1 个新认知 + 整齐的归档报告

**原话**：

> 胡子哥原话："缺口儿每天都有，一天一缺口，一天一对撞。"

## 九、3 条红线（学员最容易踩）

🚫 **只有 1 个素材就触发"对撞"** — 素材不足，AI 会引导你补到 2 个
🚫 **不写新洞见就归档** — 没产出 = 没对撞，AI 会返工
🚫 **归档后找不到原始素材** — AI 必须留引用链接

**拒绝话术**：

> AI 会说："我不确定你的 PARA 路径。先跑 5 步发现，确认是 WSL 还是 D 盘。"
