# SOP · 知识库搭建

> **一句话定位**：从空白桌面到能跑通"读书→铸卡→出文案"的最小知识库，30 分钟搞定。
> **核心心法**：知识库不是搭出来就有的，是靠一天天往里填内核，长出来的。

---

## 一、先看清卡点：为什么你"知道要搭"却没动手

**场景痛点**：

你收藏了一堆文章、买了几门课、下了 Obsidian / WorkBuddy / Claude Code——但 3 个月后打开，知识库还是空的，或者里面堆了几百条笔记但从来没调出来用过。

**认知卡点**：

绝大多数人卡在两步：

1. **不知道先装哪个工具**——CLI 工具（Claude Code/Hermes/Codex）和 GUI 工具（WorkBuddy/QClaw）各有各的用法，你不知道哪个适合自己
2. **不知道目录怎么分**——按"哲学/技能/读书笔记"分类，AI 读不懂，对你也没用

**正确的分法**：目录按你的行为目标分，不按类别分——你建这个目录是为了干什么，按目的来分。

---

## 二、起点 3 件事：搞清三者的关系再动手

**一句话说清楚**：

```
知识库 = 目录（里面是 Markdown 文件）
Obsidian = 看这个目录的软件
AI = 能直接读这个目录的助手
```

**为什么是 Markdown？** 因为它是纯文本——任何软件都能打开，不会像 Word 或 Notion 那样把你锁死。更重要的是，**AI 读纯文本不需要转换，打开就能理解**。这是"你的知识库属于你"的底层保障。

---

## 三、第一步：装 AI 工具（5 分钟）

### 推荐工具（任选一个）

**命令行路线（推荐）**：

| 工具 | 适合 | 备注 |
|---|---|---|
| **Claude Code** | 习惯命令行的工程师 | 功能强，能直接操作文件目录 |
| **Hermes Agent** | 一人公司博主/创作者 | 公众号/视频号场景最匹配 |
| **Codex** | OpenAI 生态用户 | 文档处理强 |

**图形界面路线（备选）**：

| 工具 | 适合 | 备注 |
|---|---|---|
| **WorkBuddy** | 完全不想敲命令 | 装好就用，门槛最低 |
| **QClaw** | 国内用户 | 桌面端 |
| **QoderWork CN** | 中文用户 | 国产替代 |

**核心原则**：
- 选一个就行，不影响后面的步骤
- 后续熟悉了再换其他工具
- 这三个工具每天都送大量积分，先下载一个用起来

## 四、第二步：建最简目录（10 分钟）

### 最简方案：4 个文件夹

在你电脑的任意位置建一个文件夹（名字随你，比如"我的知识库"），用 Obsidian 打开它。然后建这 4 个文件夹：

```
我的知识库/
├── 01-Projects/     ← 项目：你正在做的事
├── 02-Areas/        ← 资产：你已经处理好的个人知识
├── 03-Resources/    ← 资源：从外面拿来的参考资料
└── 04-Archive/      ← 归档：暂时不用的旧东西
```

### 多了两个也无妨（推荐用法）

```
├── 00-Inbox/         ← 灵感库：还没处理的原材料
└── 05-Skills/        ← 技能：你经常用的流程/模板
```

### ⚠️ Inbox 的规矩

灵感库是**临时停靠站，不是终点站**。每周花 5 分钟清一次：

- 能归类的拖到 Projects/Areas
- 没用的删掉
- **只进不出，Inbox 会变成另一个垃圾桶**

### 建目录的两种方法

**方法 1：让 AI 直接建（推荐用 CLI 工具）**

复制这段话发给你的 AI：

```
帮我创建一个最简知识库目录，放在桌面上，叫"我的知识库"。
里面建 6 个文件夹：
01-Projects（项目）、02-Areas（资产）、03-Resources（资源）、
04-Archive（归档）、00-Inbox（灵感库）、05-Skills（技能）
```

它会一键建好。你连鼠标都不用动。

**方法 2：手动建（用 GUI 工具）**

1. 在电脑上建一个文件夹，用 Obsidian 打开它
2. 新建这 4-6 个文件夹
3. **不用放任何文件进去**——目录结构先搭好就行

> ⚠️ **很多人死于"等我把笔记迁移完再开始"**。别等。先有目录，再往里扔东西。**空目录也比没有好。**

---

## 五、第三步：告诉 AI 你的目录是干嘛的（3 分钟）

建好目录后，把这段话发给你的 AI **一次**，它以后就知道了：

```
这是我的知识库目录，每个文件夹的用途如下：
- 01-Projects/ = 我正在做的项目。需要了解我当前关注什么时，来这里找。
- 02-Areas/ = 我消化的个人知识。需要匹配我已有观点时，来这里。
- 03-Resources/ = 外面的参考资料。不是我的原创，仅做参考。
- 04-Archive/ = 归档的旧项目。平时不翻，需要历史信息时再来。
- 00-Inbox/ = 还没处理的灵感。帮我看看新内容和已知知识连起来吗？
```

发一次就行，不用每次重复。

---

## 六、第四步：3 个最常用场景，直接上手（10 分钟）

### 场景 1：用 AI 读书

**传统读法**：从头看到尾 → 划线 → 可能整理笔记 → 大概率再也不看

**AI 读法**：你拿一本书（PDF / 复制内容），直接把这段话发给你的 AI：

```
我正在做 [写一个项目名称，比如：短视频内容创作]。
请读这本书，帮我找出：
1. 和我的项目直接相关的内容
2. 和我已有观点相反的东西
3. 我可以马上用的一条建议
```

**AI 做了什么？** 它先读你的项目文件，知道你是谁、你在干嘛，然后去书里找你用得上的东西，**而不是给你全书摘要**。

**产出知识卡片**：读完后让它帮你整理成卡片：

```
把刚才的要点整理成一张知识卡片，标题叫 "xxx"，
包括：核心概念（一句话）、我的理解、可以怎么用。
存到 02-Areas/ 里。
```

> 💡 **更懒的办法**：如果你已经往 Projects 里放过文件，直接跟 AI 说"去我的 Projects 里看看我在做什么，然后读这本书"——它自己会去翻。

---

### 场景 2：把个人经验变成知识卡片

**之前你做完一个项目、想通一个道理，最多当时感慨一下**。过两个月只剩个模糊印象，下次遇到类似问题又从头想。

**现在这样做**：

1. 把你的经验或感悟写到 `00-Inbox/` 里
2. 复制这段话发给 AI：

```
我在 Inbox 里放了一段我的经验，帮我看一下：
- 它和我以前写过的东西哪些能连上？
- 有什么是我以前没注意到的角度？
- 帮我整理成一张知识卡片。
```

3. **AI 读你的资产库（02-Areas/），找到关联的知识，把你的经验凝练成一张卡片**——包含核心判断、适用边界、和已有知识的连接点。

**关键点**：经验不流失，而且每次新卡片都会和你已有的卡片连起来。你的知识库会越长越密。

---

### 场景 3：把知识卡片变成口播文案

这是**最关键的一步**——你前面积累的知识卡片，现在可以变成能发出去的口播文案。

复制这段话发给 AI：

```
去我的 Areas 里找"相关的知识卡片，比如：关于 AI 写作"的卡片。
帮我写一条口播文案，300 字左右，口语化，用我以前的表达方式。
```

**AI 会去你的知识库里翻相关卡片，用你以前的表达方式，输出一条可以直接用的口播文案**。你从"从零开始写"变成了"修改 AI 的初稿"。

**你真正在做的事**：平时读书 + 思考 → 攒卡片 → 需要拍视频时直接调卡片出文案。**卡片越多，出内容越快**。

## 七、附：两个拿来就能用的技能卡

### 🃏 技能卡 ①：铸卡——把一条知识变成知识卡片

**什么时候用**：读完一本书、想通一个道理、做完一个项目之后。

#### 三步走

**第一步：挖核心判断**

不用管格式，先想清楚这条知识的本质。问自己三个问题：

```
1. 这个知识在说什么？（一句话说清）
2. 它打破了我什么旧认知？（"我以为 X，其实 Y"）
3. 为什么这对我是有用的？（和我做的事有什么关系）
```

**第二步：填空成卡**

想清楚了，直接填空（复制这段，粘贴就能用）：

```
标题：[一句话概括这个知识点]
核心概念（用你自己的话）：
[不要抄书。想象你在给朋友讲]
为什么值得关注：
[它为什么对 + 背后的因果链，2-3 步]
能用在哪 / 不能用在哪：
[什么场景下可以用 + 什么场景下会失效]
最小行动：
[看完这个你能马上做的一件事，≤20 字]
和已有知识的连接：
[和你知道的其他东西互补还是冲突]
```

**第三步：存起来**

保存到你的 `02-Areas/` 文件夹里。文件名就是标题。以后要用直接翻。

**检查标准**：抽掉任意一句话，卡片还成立吗？成立 → 删掉。核心判断能转述给朋友听吗？不能 → 重新写。

---

### 📷 技能卡 ②：口播——从知识卡片到口播文案

**什么时候用**：想拍视频但不知道从哪开口的时候——从你已有的知识卡片里选一张。

#### 四步填空（复制这段，粘贴就能用）

```
第一步：确定选题（4 项全过再往下走）
□ 反直觉——打破常见认知？
□ 痛点精准——指向具体谁在痛？
□ 可执行——观众看完能做什么？
□ 有金句——至少一句可以截图的话？

第二步：写前 3 秒（三帧法）
第一帧 反常识断言（1 句让人愣住的话）：
[____________________________________]
第二帧 具象画面（≤15 字，让观众"看见"）：
[____________________________________]
第三帧 收益预告（观众能带走什么）：
[____________________________________]

第三步：骨架展开
① 用户画像：谁在听？一句话点明
② 场景痛点：他们在什么场景下遇到这个问题
③ 解决方案：为什么有效 + 怎么做的核心逻辑
④ 实操方法：具体步骤（每步一句话）

第四步：收尾
给观众一个能带走行动指令，不要总结。用一句话收住。
```

#### 口播铁律

- 用"你"不用"大家"
- 短句优先
- 像跟朋友聊天不是讲课
- 读完录一遍，不像说话像念文章 → 重写

---

## 八、遇到问题直接问 AI

比如：

- "AI 读不到我的目录怎么办"
- "我的文件格式不对"
- "目录建错了能改吗"

把它发给你的 AI 工具，让 AI 帮你解决。**你不需要记住所有细节，会用就行**。

---

## 九、自检清单（30 分钟跑完）

填完后自检：

```
□ 第一步：装了 1 个 AI 工具（CLI 或 GUI 任选）
□ 第二步：建好 4-6 个目录（01-Projects / 02-Areas / 03-Resources / 04-Archive / 00-Inbox / 05-Skills）
□ 第三步：把"目录用途"那段话发给了 AI
□ 第四步：跑了至少 1 个场景（读书 / 铸卡 / 口播）
□ 第五步：把第 1 张知识卡片存进了 02-Areas/
```

**少于 4 项 → 重新跑 SOP**。

---

## 十、常见错误

❌ **目录按"哲学/技能/读书笔记"分类** —— AI 读不懂，对你也没用

❌ **Inbox 一直不清** —— 只进不出，30 天后变成新的垃圾场

❌ **铸完卡就扔着** —— 不调出来用，卡片就是死的资产

❌ **AI 不会用就放弃** —— 直接问 AI，让 AI 自己解决自己的问题
