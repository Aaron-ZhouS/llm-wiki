# SOP · 口播炼金 Skill

> **一句话定位**：你手里有一堆素材，但讲不出口？口播炼金帮你炼成一段 3-7 分钟的可念逐字稿。
> **核心心法**：原始素材不是素材，是矿；矿不炼就是石头。

---

## 一、先看清卡点：为什么素材堆在那讲不出来

**场景痛点**：

你有故事、有观点、有数据。但每次想拍视频，要么憋 30 分钟写不出一句，要么写出来的稿自己念都嫌假。素材明明在脑子里，出不来。

**认知卡点**：

你以为"写不出"是表达能力问题。其实是**素材没结构化**——矿埋在石头里，你以为石头就是矿。

**解决方案**：

口播炼金的解法是 8 大叙事库选结构 + 7 步黄金骨架搭框架。**素材不需要你"写出来"，需要你"选结构+填框架"**。

**原话**：

> 胡子哥原话："你有素材但讲不出来，不是你不会讲，是你没有结构。结构对了，素材自己会排队。"

---

## 二、什么时候用 / 什么时候不用

### ✅ 满足任意 1 条就用

- 你想做 3-7 分钟中长视频（B 站 / 视频号中视频 / 公众号音频）
- 你有完整素材/选题/案例，但不知道怎么组织成稿
- 你想用 8 大叙事库挑结构、7 步骨架搭框架

### ❌ 触发这些就别用

- 只想做 30-40 秒短视频 → 换 `koubo-cola` / `video-script-generator`
- 只有模糊想法没素材 → 先去 `00-灵感库/` 积累
- 想写成文章不是口播 → 走公众号文章工作流

## 三、3 步调用流程

```
Step 1：投喂素材（选题 + 故事 + 目标时长）
       ↓
Step 2：AI 自动选 8 大叙事库 + 搭 7 步骨架
       ↓
Step 3：AI 输出逐字稿 + 6 道质量防线自检
       ↓
学员读 1 遍顺口 → OK
不顺口 → 说"再打磨" → AI 修
```

### 触发词（任意一个）

```
/口播炼金
/长口播
写个 5 分钟口播
帮我写一段口播逐字稿
```

   例："拖延不是懒，是恐惧"

【故事/案例】
<具体事件，包含时间/人物/场景/结果>
   例："我之前做副业，3 个月没收入。后来..."

【目标时长】
<3min / 5min / 7min+>
```

✅ 7 步骨架时分表
✅ 质量防线自检清单（6 项 ≥5 项过）
```

---

## 六、6 道质量防线（学员必背）

> 出稿前自检，少于 5 项过 = 重新出稿。

```
□ 防 1：开头 15s 内能否引发"想继续看"？
□ 防 2：PROBLEM 段是否让观众有共鸣（不是自嗨）？
□ 防 3：故事/案例是否有具体细节（不是"我有一个朋友"）？
□ 防 4：观点是否一句说清（不是 3 句绕弯子）？
□ 防 5：对标迁移是否跨 ≥2 个领域（不是同一个领域说 3 遍）？
□ 防 6：落地行动是否 5 分钟内能做（不是"努力""坚持"）？
```

## 七、与其他 Skill 的联动

| Skill | 关系 | 怎么用 |
|-------|------|--------|
| **挖矿压缩机** | ← 上游 | 先用挖矿压出 200 字金句判断 |
| **可运行性检查** | ← 门禁 | 写完后三问判断值不值得发 |
| **灵感对撞** | ← 上游 | 用对撞产生的洞见炼长稿 |
| **知识卡片** | → 下游 | 把口播里的"金句"沉淀成卡片 |
| **真实故事提炼器** | ← 配合 | 先把真实故事提炼出来再喂口播 |

**完整闭环**：
```
挖矿压缩机（200 字金句）
       ↓
可运行性检查（三问 → Runnable-A）
       ↓
口播炼金（扩成 5 分钟长稿）
       ↓
发到 B 站 / 视频号
       ↓
口播里的金句 → 知识卡片（沉淀资产）
```

## 八、实战示例（琪萌用例）

**学员**：琪萌（母婴店主 / 二胎宝妈）

**场景痛点**：想拍 5 分钟视频讲"直播答疑首秀的转化卡点"，素材堆在飞书日记里，憋了一周没出稿。

**触发**：「/口播炼金 选题：直播答疑首秀的转化卡点 故事：第一次直播答疑只来了 3 个人，但我当天转化了 2 单 时长：5min」

**AI 跑了什么**：

1. **8 大叙事库选型**：选了"问题反转库"——大家都觉得直播要人多才赚钱，但琪萌反过来了（人少反而转化高）
2. **7 步骨架时分表**：
   - 开场 15s（"直播人少就赚不到钱？未必"）
   - PROBLEM 35s（"为什么大多数人觉得人少=失败"）
   - 故事 90s（**核心证据段**：3 人直播如何转化 2 单）
   - 观点 25s（"转化率比流量更重要"）
   - 对标迁移 30s（"卖课/直播/电商 都适用"）
   - 落地 15s（"今天就改你的直播策略"）
   - 结尾 10s（"你怎么看？评论区告诉我"）
3. **6 道质量防线自检**：6/6 全过

**学员拿到**：可以直接照念的 5 分钟稿 + 6/6 防线自查表

## 九、3 条红线（学员最容易踩）

🚫 **素材只有观点没案例** — 回 Step 1 补故事
🚫 **行动建议是"用心""坚持"** — 让 AI 重写（防 6 不过）
🚫 **一篇稿 15 分钟以上** — 让 AI 拆成上下集

**拒绝话术**：

> AI 会说："素材缺案例，给我一个具体的事件或数据，否则没法写。"
