# SOP · 口播炼金 Skill

> **一句话定位**：把你手头的素材，炼成一段可直接拍摄的 3-7 分钟口播逐字稿。

---

## 1. 什么时候用（触发信号 3 条）

✅ **满足任意 1 条就触发**：
- 你想做 3-7 分钟的中长视频（B 站 / 视频号中视频 / 公众号音频）
- 你有完整素材/选题/案例，但不知道怎么组织成稿
- 你想用 8 大叙事库选结构、7 步黄金骨架搭框架

## 2. 什么时候不用（避坑 3 条）

❌ **触发这些就别用，换 Skill**：
- 只想做 30-40 秒短视频 → 换 `video-script-generator` 或 `koubo-cola`
- 只有模糊想法没素材 → 先去 `00-灵感库/` 积累
- 要写成文章而非口播 → 换 `oral-alchemy` 不适合，要走公众号文章工作流

---

## 3. 调用方法（触发词 + 3 步流程）

### 触发词（任意一个）

```
/口播炼金
/长口播
写个 5 分钟口播
帮我写一段口播逐字稿
```

### 3 步流程

```
Step 1：投喂素材（选题 + 故事 + 目标时长）
       ↓
Step 2：AI 自动选 8 大叙事库 + 搭 7 步骨架
       ↓
Step 3：AI 输出逐字稿 + 6 道质量防线自检
       ↓
学员读 1 遍顺口 → OK
不顺口 → 说"再打磨" → AI 修
```

## 4. 输入模板（学员复制粘贴即可）

```yaml
【选题/观点】
<你想讲的核心主张，一句话>
   例："拖延不是懒，是恐惧"

【故事/案例】
<具体事件，包含时间/人物/场景/结果>
   例："我之前做副业，3 个月没收入。后来..."

【目标时长】
<3min / 5min / 7min+>
```

```

✅ 8 大叙事库选型说明（为什么选这个结构）
✅ 7 步骨架时分表
✅ 质量防线自检清单（6 项 ≥5 项过）
```

## 7. 实战示例（琪萌用例）

> **学员**：琪萌（母婴店主 / 二胎宝妈）
> **场景**：想把直播答疑的复盘做成口播视频
> **触发**：「/口播炼金 选题：直播答疑首秀的转化卡点 故事：第一次直播答疑只来了 3 个人，但我当天转化了 2 单 时长：5min」
>
> **AI 跑了什么**：
> 1. 8 大叙事库 → 选了"问题反转库"（大家都觉得直播要人多，但琪萌反过来了）
> 2. 7 步骨架 → 5min 时长，故事段给 90s（核心证据）
> 3. 输出逐字稿 + 6 道防线自检
>
> **学员拿到**：可以直接照念的 5 分钟稿 + 质量自查表
