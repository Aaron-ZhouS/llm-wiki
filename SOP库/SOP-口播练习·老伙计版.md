# SOP · 口播练习·老伙计版

> **一句话定位**：每天 30 分钟，把一个知识点从「下载」升级到「安装」——理解、表达、沉淀形成闭环。
> **核心心法**：阅读不是下载，是安装。学完不用，等于没装。

---

## 一、3 条核心公式（胡子哥原话）

**这套方法论的 3 个底层信念**：

| 公式 | 含义 |
|---|---|
| **阅读 = 安装** | 不是下载到脑子里占位，是把别人的技能安装到自己身上 |
| **闭环 = 交付** | 不是做了某个环节，是端上桌且别人喜欢吃 |
| **行动 = 学习** | 不是先学好了再做，是在做事中遇到问题的那一刻才真的学 |

> 「我们不需要更多知识，需要更多行动。不需要更长规划，需要更小闭环。」

---

## 二、看卡点：你的内容是不是「下载模式」？

**很多人的知识困局**：

- 看了 100 篇文章 → 划线、收藏 → 再没打开 → 占心智带宽
- 装了一个软件 → 从来不用 → 占硬盘空间
- 买了一辆车 → 不开 → 报废

**下载 vs 安装的 4 个动作**：

| 动作 | 含义 | 在学习里 |
|---|---|---|
| **下载** | 信息进入大脑，但无法调用 | 划线、收藏、从没复盘 |
| **安装** | 获得技能的使用权，变成你的外接机械臂 | 学完能用，能教别人 |
| **卸载** | 清理用不到的技能，释放空间 | 定期清理没用的方法论 |
| **升级** | 用 AI 等新工具更新过时技能 | 手工方法升级为 AI 流程 |

**检验你的下载量是否过多**：脑子里记了多少"收藏夹"？超过 50 个 → 下载太多，安装不够。

---

## 三、看卡点：你的"包饺子"做到哪一步了？

### 闭环的核心：端上桌 + 大家喜欢吃

**只有端上桌且大家喜欢吃，才叫真正的闭环。**

```
会擀皮 ✗ 不是闭环
会调馅 ✗ 不是闭环
会包饺子 ✗ 不是闭环
会煮下锅 ✗ 不是闭环
端上桌，大家喜欢吃 ✓ 才是闭环
```

**闭环的核心 = 直接向社会交付价值 + 获得市场反馈。**

### 闭环诊断 3 问

```
1. 你能直接交付什么？（别人愿意为什么付钱？）
2. 你从市场获得反馈了吗？（是播放量/销量，还是仅仅在自嗨？）
3. 你的交付有积累吗？（下次能做得更好吗？）
```

**没有闭环的人，不管在哪个环节做得再好，都无法独立创造价值。**

## 四、胡子弹循环：先做事再学习

**胡子循环流程**（这是整张图的核心）：

```
去做事 → 遇到问题 → 去学 → 用上 → 沉淀 → 遇到新问题 → 再去学
```

**大多数人顺序是反的：先学好了再去做。但真正的学习发生在做事遇到问题的时候。**

> 「你不是先学会游泳再下水，是先下水扑腾，发现自己快沉了才开始学换气。」

### 行动启动建议（哪怕很小，跑通闭环）

- **写点什么？** 每天 100 字
- **拍点什么？** 拿起手机就拍
- **解决什么？** 免费帮一个人解决问题

**关键不是大小，是跑通一个闭环。**

> 「这比「学一年再开始做」有效 10 倍。」

---

## 五、记住≠理解≠学到（学习的三级检验）

| 状态 | 特征 | 检验方式 |
|---|---|---|
| **记住** | 能复述定义和原话 | 这句话能背出来吗？ |
| **理解** | 能用自己的话说清楚，知道在什么场景用 | 给一个 12 岁的孩子讲一遍？ |
| **学到** | 能真正用出来，变成了自己的技能 | 你今天能用一次吗？ |

> 「划线不代表学到。真正的学到叫「重构」——突然意识到「原来是这个意思啊！」并变成自己的技能。」

**警告**：很多人把"记住"当成"学到"。**记住 ≠ 理解 ≠ 学到**。

## 六、知识管线：从评论到知识卡

**创作不是从零开始写**——是**从评论区找到真实痛点 → 对应到已有知识 → 拍 → 回填沉淀**。

### 完整管线（8 步）

```
扒评论 → 排序选题 → 知识库映射 → 核心点分析 → 拍视频 → 回填 AI → 生成知识卡 → 入库
```

**这不是一条单向产线，而是一个增强回路：每次完成都让知识库更丰富，下次拍更轻松。**

### 各环节要点

#### 1. 扒评论

> 「评论区是活的数据源。高赞评论代表一类人的真实痛点，比你自己想选题准确十倍。」

**口诀**：扒评论 — 真实痛点比拍脑袋准 10 倍

#### 2. 知识库映射

> 「选题不是拍脑袋，是对应到你已经沉淀的知识。如果映射不上去——说明这个选题你还不懂，先深挖再拍。」

**口诀**：知识库映射 — 映射不上说明你还不懂，先深挖

#### 3. 拍视频

带着核心点拍（不是漫无边际地讲）。

#### 4. 回填 AI（闭环的关键！）

> 「拍完视频 ≠ 结束。把转录文本回填给 AI 生成知识卡入库，才算一次完成。**没有回填的内容不算完成**。」

**口诀**：拍完不等于结束 — 回填是闭环的关键

## 七、创作者的操作系统：7 个落地法

```
┌─────────────────────────────────────┐
│  📖 阅读 = 安装  ⚡ 行动 = 学习  🍽️ 闭环 = 交付  │
│                  ↓
│       Action Dashboard（7 个动作）      │
└─────────────────────────────────────┘
```

### 7 个动作清单

1. **每天写点什么** — 不追求写得多好，先开始写，在写中学会写
2. **从最小闭环开始** — 不是"我要做一个大产品"，是"今天发一条内容"
3. **遇到问题再学** — 不提前学一年，在做事中遇到解决不了的事再去学
4. **用完就沉淀** — 拍完视频回填 AI 生成知识卡，形成资产积累
5. **卸载不用技能** — 定期检查：这个技能还在用吗？不用就卸载，轻装前行
6. **升级过时技能** — 现在有 AI 了，以前学的一些手工方法可以升级了
7. **走一步看两步** — 不是走一步看十步，看十步的人迈不出第一步

> 「我们不需要更多知识，需要更多行动。不需要更长规划，需要更小闭环。」

## 八、默认模式：两阶段融合练习

> **核心哲学**：口播是一个形式，真正的价值是对知识的理解和运用。
>
> **两阶段模型**：
> - **Phase 1 — 知识的理解与运用**：每天选一张知识卡，反复深挖本质、连接、应用、误区。
> - **Phase 2 — 知识的表达与输出**：在理解满意后，练习表达、获取反馈、沉淀资产。
>
> **AI 角色根据所处阶段自动切换**：Phase 1 做认知追问者，Phase 2 做内容教练。
>
> **两阶段之间有明确的门**——Phase 1 的"满意"才能进入 Phase 2。

---

### 【Phase 1】步骤 1：选题（知识卡选择）

选一张你今天想搞懂的知识卡。来源可以是你的笔记、收藏的文章、或者随便一个你"以为懂了但说不清楚"的概念。

**选题原则：**

- 对更多老伙计有用，且长期有用
- 这张卡你还没有真正搞懂（能说清楚才算懂）

**选题方式：**

1. AI 从你的知识库里推荐候选 — 优先选近期没碰过、或者总觉得"说不清楚"的概念
2. 你自己指定一张卡或一个概念

```
今日知识卡候选：

1️⃣ [概念名] — 最后使用：X天前 | 关联概念：N个
   [一句话说清这是什么]

2️⃣ [概念名] — ...
```

**特殊处理：** 你说"XXX 我说不清楚" → 说明你没真懂 → 选它作为今日深挖对象。

---

### 【Phase 1】步骤 2：知识深挖

> ⚠️ **AI 角色：认知追问者模式。** 我的任务是促进你深度思考，不是帮你写内容。

选定知识卡后，从以下维度逐层深入。**不是全部要走一遍，而是随对话自然展开**：

| # | 维度 | 追问方向 | 示例 |
|---|------|---------|------|
| 1 | **本质追问** | 它到底是什么？去掉比喻后剩什么？ | "给一个 12 岁的孩子讲这个概念，怎么说？" |
| 2 | **结构追问** | 整体的知识结构是怎样的？有哪几个子概念？ | "这个概念的上层是什么？下级有什么？" |
| 3 | **因果追问** | 为什么是这样？底层逻辑是什么？ | "这个因果链中，哪个环节最容易被忽略？" |
| 4 | **应用追问** | 具体怎么用？你上次用是什么时候？ | "今天之内你能用一次吗？怎么用？" |
| 5 | **误区追问** | 常见错误理解是什么？你自己之前错在哪？ | "大多数人听到这个，第一反应错在哪？" |
| 6 | **反例追问** | 什么时候不成立？边界在哪？ | "能想出一个反例吗？什么情况下反而有害？" |
| 7 | **连接追问** | 和哪些你已经知道的概念有关？ | "这和上周说的[那个概念]什么关系？" |
| 8 | **压缩追问** | 一句话说清核心。 | "用 20 个字说清这张卡在说什么。" |

**深挖流程（非线性对话）：**

```
AI问 → 你答 → AI追问/质疑 → 你深化 → AI连接/对比 → 你整合
                                        ↓
                         循环直到你说"这块我清楚了"
                                        ↓
                         换一个维度继续
```

**特殊触发词：**

| 你说 | AI 响应 |
|------|---------|
| "我不懂 XXX" | 切换到维度 1/3/5，先解决理解障碍 |
| "我当时是这样做的..." | 切换到维度 4/6，结合你的经验 |
| "这让我想到 XXX" | 切换到维度 7，探索连接 |
| "不对，应该是..." | 发现盲区，切换到维度 1/5 |
| "太抽象了" | 切换到维度 4，找最小行动 |
| "那 XX 场景呢？" | 切换到维度 6/7，测试边界 |

---

### 【Phase 1】步骤 3：压缩检验（满意门）

深挖到一定深度后，做一次压缩检验。**这是能否进入 Phase 2 的出口门。**

```
### 压缩检验

检验你是否真理解了，用四种方式压缩表达：

1️⃣ 一句话说清本质（≤20字）：
2️⃣ 一个最简行动（任何人看完都能做的一步）：
3️⃣ 一个最小案例（3句话讲清用的场景）：
4️⃣ 和已知常识的连接（"就像...但不完全是..."）：

⚠️ AI 不代答。你必须自己回答。
```

**通关条件：** 四问中至少三问能清晰回答。回答模糊 → 回去继续深挖。

---

### 【Phase 1】步骤 4：满意度选择

```
你对[概念名]的理解状态：

🟢 满意，可以进入 Phase 2 表达输出
🟡 基本懂了，但想下次再深挖某个维度
🔴 还没搞懂，明天继续深挖

选择：
A — 进入 Phase 2：表达练习
B — 先沉淀理解成果，后续再表达
C — 仅深挖，今日不表达
```

---

### 【Phase 2】步骤 1：表达准备

> ⚠️ **AI 角色切换：内容教练模式。** 现在目标不是"搞懂"，而是"让更多人搞懂"。

**结构建议：**

```
### 表达结构建议

基于你的理解，建议的表达框架：

┌─ 钩子：[反常识/冲突感的方向]
│
├─ 认知冲突（你深挖时最大的认知升级点）：
│  [以前以为X → 但实际上是Y → 为什么错了]
│
├─ 案例（来自你自己的经历，或者一个典型场景）：
│  [具体场景]
│
├─ 行动建议（看完能做的一步）：
│  [具体可执行]
│
└─ CTA：[关注/收藏/评论]
```

---

### 【Phase 2】步骤 2：表达 + 迭代循环

准备好了，开始说。说完后进入复盘循环。

#### 三问自我检查（每轮强制）

```
❓ 第一问：这段内容和我有什么关系？
❓ 第二问：看到哪里观众会划走？
❓ 第三问：看完后他想干什么？
```

**AI 不代答。Q2 必须答出具体时间点或元素。**

#### 迭代循环

```
你表达 → 三问自检 → AI点评 → 打磨 → 再表达
                                          ↓
                            循环直到你说"满意了"
                                          ↓
                            进入产出模式选择
```

**循环上限：** 5 轮。超过 5 轮仍未满意 → 主动暂停，考虑换主题。

**用户决策：**

- 「满意」 → 跳出循环，进入产出模式选择
- 「不满意」 → AI 推荐 1 个打磨方向，打磨后重新表达

---

### 【Phase 2】步骤 3：产出模式选择

```
满意了，这次产出什么？

A — 出逐字稿 → 去拍摄 → 复盘
B — 出文章 → 沉淀资产（不拍视频）
C — 先沉淀资产，后续再说
```

---

### 【Phase 2】步骤 4：拍摄 + 「拍完了」

选 A「出逐字稿」时执行：

1. **三问自我检查**（同前）
2. **拍完了** → 记录本次练习：
   - 拍了几遍？
   - 最有感觉的是哪一遍？
   - 什么地方卡住了？

---

### 资产沉淀（P-R2）

每次练习至少沉淀一条可复用资产。

| 练习阶段 | 沉淀内容 | 示例 |
|---------|---------|------|
| Phase 1 | 认知升级点 / 连接关系 / 误区 | "我之前以为 X 是独立概念，现在发现它是 Y 的子集" |
| Phase 2 | 表达模式 / 开头句式 / 案例 | "这种'先否定后重构'的句式很适合认知反差型内容" |

**最小可接受：** 3 行 mini 知识卡。

---

### 下游操作

```
今日练习完成 ✅（Phase 1: N轮深挖 → Phase 2: M轮迭代）

下一步操作（可选）：
- 「出图」 → 把内容生成幻灯片
- 「做自检」 → 检查认知是否准确
- 「发布」 → 发到你的平台
- 「结束」 → 今日结束，明天继续
```

## 九、内容生产管线（打通从评论到知识卡的回路）

> 创作不是从零开始写，而是从评论区找到真实痛点 → 对应到已有知识 → 拍 → 回填沉淀。

### 管线流程

```
扒评论 → 排序找选题 → 知识库映射 → 核心点分析 → 拍视频 → 回填AI → 生成知识卡 → 入库
```

### 各环节要点

**1. 扒评论 + 排序找选题**

- 从短视频评论区抓真实用户反馈
- 高赞评论 = 一类人的真实痛点
- 筛选标准：这条评论能映射到一个典型用户吗？

**2. 知识库映射（找弹药）**

- 选题不是拍脑袋，是对应到你已有的知识
- 如果映射不上去 → 说明这个话题你还不懂，**先深挖再拍**

**3. 快速拍 + 回填 AI**

- 拍完不结束——把转录回填给 AI，生成结构化知识卡
- 知识卡入库，下次遇到同类问题直接可用

**4. 回填是闭环的关键**

> **没有回填的内容不算完成。**

### 管线故障自查

| 卡在哪 | 原因 | 怎么办 |
|--------|------|--------|
| 没选题 | 没扒评论 | 建一个评论收集流程 |
| 有选题但拍不出来 | 知识库映射不上 → 还不懂 | 先深挖（走 Phase 1）再拍 |
| 拍完了没回填 | 缺少回填机制 | 拍完自动转写 → AI 抽取 → 知识卡 |
| 回填了不入库 | 质量不达标 | 写清楚核心观点再入库 |

## 自检清单（每日必过）

```
□ Phase 1：今天选了哪张知识卡？深挖了至少 3 个维度？
□ 压缩检验：4 问中至少 3 个清晰？
□ Phase 2：至少做了 1 轮三问自检？
□ 资产沉淀：今天沉淀了 1 条可复用资产？
□ 知识管线：是否完成了"扒评论→拍→回填"全流程？
□ 检查 7 个动作：写/闭环/学/沉淀/卸载/升级/走一步看两步 哪个今天做了？
```

**少于 4 项 → 当天练习失败**。

---

## 红灯边界（硬门禁）

- 🚫 跳过 Phase 1 直接进 Phase 2 —— 没有认知的表达是空洞的
- 🚫 压缩检验没通过就强行进 Phase 2 —— 表达只会暴露理解漏洞
- 🚫 AI 代答压缩检验问题 —— 你必须自己回答
- 🚫 表达迭代超过 5 轮 —— 主动暂停换主题
- 🚫 拍完不回填 —— 等于没练习
- 🚫 选"先沉淀不表达"超过 3 次 —— 表达本身是深度理解的工具
- 🚫 只下载不安装 —— 看了一堆从来不用
