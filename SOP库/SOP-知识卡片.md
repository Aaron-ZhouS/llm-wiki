# SOP · 知识卡片 Skill

> **一句话定位**：把你脑子里零散的经验/教训，锻造成可复用、可证伪、能随时调用的 L1 卡片。
> **这个 Skill 有两版**：文字卡（forge）+ 图卡（design，Kindle 纸书风）。学员自己选。

---

## 1. 什么时候用（触发信号 3 条）

✅ **满足任意 1 条就触发**：
- 你有一条新经验/教训想沉淀下来（"我发现写周报先写成果，领导反馈好很多"）
- 你想建立个人知识库（卡片形式积累）
- 你想把口播/文章里的"金句"变成可发布的小红书/视频号图卡

## 2. 什么时候不用（避坑 3 条）

❌ **触发这些就别用，换 Skill**：
- 只有模糊想法没具体经验 → 先去积累或用 `灵感炼金` 提炼
- 想做完整方法论 → 换 `linggan-alchemy`
- 想做长文输出 → 换 `oral-alchemy`
- 想压成短句金句 → 换 `挖矿压缩机`（这个更轻量）

---

## 3. 调用方法（触发词 + 3 步流程）

### 触发词（任意一个）

```
/锻造          ← 启动从零锻造
/迭代 [卡片ID]  ← 更新已有卡片（如 /迭代 KC-AARON-001）
/升级 [卡片ID]  ← 申请升级等级（如 /升级 KC-AARON-001）
/评估 [卡片ID]  ← 体检卡片质量

/出图          ← 把锻造好的卡渲染成 Kindle 纸书风图卡
```

### 文字卡（forge）4 步流程

```
Step 1：投喂经验（"我发现..."）
       ↓
Step 2：AI 追问（提炼核心洞察、构建行动指南、标定绿灯/红灯）
       ↓
Step 3：4 铁律检验（不过就返工）
       ↓
Step 4：生成 L1 卡片 → 自动入库
```

### 图卡（design）补充流程

```
文字卡锻造完成
       ↓
说"出图"
       ↓
AI 渲染 HTML + 截图 PNG + 入库 Markdown（三线输出）
       ↓
学员看图 → 调 → 发布
```

## 4. 输入模板（学员复制粘贴即可）

### 文字卡（forge）

```yaml
【经验/教训】
<一条你觉得有用的经验、教训或技巧>
   例："我发现写周报时先写成果再写计划，领导反馈好很多。"

【我的绿灯（什么场景能用）】
<你真实用过的 1-2 个场景>
   例："周一写周报、季度汇报"

【我的红灯（什么场景失效）】
<你真实遇到过的失效场景>
   例："项目刚启动还看不到成果时"
```

### 图卡（design）

```yaml
【基于哪张文字卡】
<引用卡片 ID>
   例："KC-QIMENG-20260812"

【发布渠道】
<小红书 / 视频号 / 公众号>
   例："视频号封面图"
```

## 8. 红线（学员最容易踩的 5 个坑）

🚫 **绿灯写"任何场景"或"看情况"** — 必须有真实经历支撑
🚫 **红灯写"没什么不适用"** — 必须能描述出失效场景
🚫 **核心洞察太长（>30 字）** — AI 会追问重提炼
🚫 **行动指南太抽象（"用心""坚持"）** — 必须 5 分钟内能开始
🚫 **升级举证说"应该能用"** — 必须有 2 个真实使用场景
