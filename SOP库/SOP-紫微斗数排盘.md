# SOP · 紫微斗数排盘 Skill

> **一句话定位**：给一个生辰，Hermes 60 秒给你一张能看懂的紫微命盘——十二宫、主星、亮度、四化、大限、格局吉凶全齐。
> **核心心法**：引擎算盘，AI 读盘。**别让 AI 自己编盘，也别让它自己编大限四化。**

---

## 一、先看清卡点：为什么手排紫微斗数是浪费时间

**场景痛点**：
你想知道自己或家人的命盘。但紫微斗数不是排 App 点两下就完事——真太阳时校正、闰月归属、晚子时换日、亮度流派，每一步选错，整张盘就是错的。网上排盘软件各选各的口径，你根本不知道谁对。

**认知卡点**：
你以为「排盘」是找个软件的事。其实**排盘是选口径的事**——同一生辰，口径不同，命宫就不同，后续解读全部作废。

**解决方案**：
这个 Skill 把主流排盘口径**固化在引擎里**（正月初一换年、闰月分半、QS 亮度流派、真太阳时自动校正），你只需要给生辰。口径不再是你的负担。

**原话**：

> 倪师原话：「命宫为本，三方为用——命宫主星决定基本格局与天生性格，三方决定用武之地。」

## 二、什么时候用 / 什么时候不用

### ✅ 满足任意 1 条就用

- 想知道自己或家人的紫微命盘（性格、事业、婚姻、健康倾向）
- 想看某个流年/大限的处境
- 想做合盘（两人关系：合婚、合伙、亲子）
- 想查某个格局的吉凶条件，或倪师《天纪》讲过什么原话
- 想系统学紫微斗数（有古籍原文 + 倪师体系）

### ❌ 触发这些就别用

- **要精确到分钟的择时/风水/八字** → 紫微斗数解决不了，八字走另一套
- **要做医疗/法律/投资决策** → 这是传统命理参考，不是决策依据
- **只想要一句话结论**（"我今年运势如何"）→ 直接说，让 Hermes 排完再答，不用自己看盘
- **要看六亲的准数**（父母兄弟子女到底靠不靠得住）→ 倪师自己都说「斗数批六亲本来就比较差一点」，别在这上面较真

> 📌 六亲局限的出处：倪师《天纪》2上 00:25:27（https://www.bilibili.com/video/BV1KJsLekEfA?p=3&t=1527 ）。上游 README 也特别标注「与六亲相关的分析仅供参考」。

## 四、输入模板（复制粘贴即可）

```
【公历生日】<年-月-日>
   例：1988-10-08

【时辰】<子丑寅卯辰巳午未申酉戌亥 / 或钟点 / 或"不知道">
   例：未时   /   15点   /   不知道（让 Hermes 按正午算并标注）

【性别】<男 / 女>

【出生地】<城市名，用于真太阳时校正>
   例：上海
```

> ⚠️ **时辰不知道怎么办**：说"不知道"，Hermes 会按午时排，并在解读里标注「时辰未知，边界可能偏移」。

## 六、5 条口径红线（出错的 5 个地方，学员/使用人必背）

> 这 5 条决定盘准不准。**AI 排完你扫一眼 `※` 开头的行，确认口径对。**

```
□ 红线 1：闰月生人 —— 倪师派要显式说「按倪师口径」
           现代年份闰月最长仅 10 天，默认 split 与 prev-month 结果完全一样，
           只有 next-month（闰月归下月）才是倪师体系。
           → 命中闰月时，务必让 Hermes 用 next-month。

□ 红线 2：亮度流派 —— 默认 QS（斗数全书）= 主流排盘口径
           同星不同派差 3 档（太阴：旺/不/陷/闲），不可混用。
           → 除非你明确要某派，否则别动。

□ 红线 3：真太阳时 —— 出生地一定要给
           乌鲁木齐比上海晚 2 小时 16 分，同一钟点可能落在不同时辰，整盘皆变。
           → 出生在时辰交界 ±5 分钟内的，报出来时要说明可能归前后两宫。

□ 红线 4：大限没有四化 —— 别让 AI 编
           引擎按倪师「四化永远固定，大限只看宫位移动」下线了飞星派字段。
           → 看到 AI 说"你大限化忌在..."，那是编的，要求重排。

□ 红线 5：四柱两行不一致是正常的
           节气口径（八字用）vs 农历口径（紫微用），换年规则不同。
           → 不是 bug，别让 AI 去"修"。
```

## 七、参数速查（直接调 CLI 时用）

```bash
cd ~/.hermes/skills/ziwei-chart
./node_modules/.bin/tsx scripts/chart.ts \
  --year 1988 --month 10 --day 8 --hour 未时 --gender male \
  --city 上海 --patterns --target-year 2026
```

| 参数 | 说明 |
|---|---|
| `--year --month --day` | 公历生日（必填） |
| `--hour` | 时辰：`0`=子…`11`=亥，或中文 `未时`，或 12-23 钟点 |
| `--clock` | 显式按钟点取时辰（`--clock 15` = 申时），避免 0-11 歧义 |
| `--gender` | `male` / `female`（必填） |
| `--city` | 出生城市（34 省 / 484 城市），做真太阳时校正 |
| `--school` | 亮度流派：`QS`（默认）/ `XD1` / `XD2` / `ZZ` |
| `--leap` | 闰月口径：`split`（默认）/ `next-month`（倪师派）/ `prev-month` / `origin-month` |
| `--target-year` | 运限目标年（1900-2100） |
| `--patterns` | 附格局检测结果 |
| `--json` | 输出完整 JSON |

**完整手册**：`~/.hermes/skills/ziwei-chart/references/使用说明书.md`（10 章，含 JSON 结构、排错表、维护更新）

## 十、实战示例

**场景**：想看自己 2026 年的整体处境，顺带问事业。

**触发**：「排个命盘：1988年10月8日 未时 男 上海，看看 2026 年」

**Hermes 跑了什么**：

1. **调 CLI 排盘**（口径全默认，`※` 行确认 QS + split + 已做真太阳时校正）
2. **读命宫**：寅宫，天机（得）化忌 + 太阴（旺）化权 → 命格总览「天机、太阴（智慧星）」，性格关键词：智慧、机变、善谋、柔美、财富
3. **读格局**：
   - `机月同梁 [excellent]` —— 四星齐入命迁财官，最适合公职/学术/文艺/医疗/服务
   - `天机化忌入命 [caution]` —— 需留意自身固执、心理障碍或健康隐患
   - `天马入命 [neutral]` —— 一生奔波、动中得财，倪师说「天马入命，无禄不发」
4. **读运限**：2026 年走 32-41 岁大限（田宅宫），虚岁 39，覆盖 2019-2028

**拿到**：一张准盘 + 三档格局判断 + 当前大限定位 + 破格提醒

## 十一、3 条红线（最容易踩）

🚫 **别信 AI 编的大限四化** —— 引擎没这字段。要求重排或让它说明"大限只看宫位移动"。
🚫 **别用错的闰月口径解倪师体系** —— 闰月生人必须 `next-month`。
🚫 **别把六亲断语当定论** —— 倪师原话「斗数批六亲本来就比较差一点」。

**拒绝话术**：

> AI 会说："大限四化需要按宫干推算，本 Skill 未提供，请自行判断或参考其他工具。"
> ——这是正确行为，说明它守住了边界。

## 十二、为什么必须有这个 Skill（必看）

没有它 = 每次排盘都在赌口径对不对
有了它 = 口径固化在引擎里，你只管给生辰

> 倪师原话：「大道至简——飞星飞来飞去太复杂，不搞这个。」

这个引擎就是按这句话做的：**能自动算的绝不让你选，口径有分歧的给你列清楚并标出默认是什么。**
