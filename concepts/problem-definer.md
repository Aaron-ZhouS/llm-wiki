# 问题界定器 — 在正确的问题上花时间 v3

> 解决一个问题的最大障碍，是接受了"问题本身"的预设。
> 如果你不先停下审视问题，你只是在原问题框架内找更好的答案，而不是在找正确的问题。

---

## 一句话定位

**输入（任意问题）→ 五要素门禁 → 四维判定（谁的社会个评判）→ 翻面法（暴露隐含假设）→ 结构解剖（如复杂）→ 可逆性判断 → 输出界定结果（归属/翻面/可逆性/建议行动）。**

---

## 核心哲学

**问题界定 ≠ 问题解决**。界定是解决的前提，但不代替解决。

1. 确保你在 **正确的问题** 上花时间
2. 确保你 **不是在解决别人定义给你** 的问题
3. 确保你 **知道问题在更大系统里** 的位置

## Step 0：五要素门禁（前置脚本）

如果输入是"我该怎么办/你给我个方案"等无结构提问，先不要进入界定。

调用脚本：
```bash
python3 ~/.hermes/skills/problem-definer/scripts/question_gate.py "<用户提问文本>"
```

**五要素**：
1. 问题：真正想问什么？
2. 卡点：卡在哪一步？
3. 背景：发生在什么约束下？
4. 尝试：已经试过什么？
5. 想法：当前自己的判断是什么？

**判定**：
- 缺 3 项以上 → 先补问
- 否则进入 Step 1

> 否则会把高手、AI、社群都变成替代思考的外脑。

---

## Step 1：四维判定（四问归属法）

对任何问题，先做 4 个维度的判定：

| 维度 | 问题 | 出口 |
|------|------|------|
| **① 谁的问题** | 这个问题是谁的？是老板/客户/家人的问题，还是我自己的问题？ | 别人的问题 → 告知对方 |
| **② 社会or个人** | 这是社会趋势/行业周期问题，还是个人可改变的问题？ | 社会问题 → 节约精力 |
| **③ 别人定义的** | 这个问题是别人定义给我的，还是我主动选择的？"怕别人怎么看我" | 别人定义的 → 重新问"我真正想解决的是什么" |
| **④ 评判权在谁手里** | 这个问题的评判标准在谁手里？我能不能通过努力改变那个标准？ | 评判权不在我手里 → 停止内耗 |

**判定逻辑**：

```
问题到达
    ↓
维度①：这是谁的问题？
  ├─ 别人的问题 → 告知对方，不消耗自己
  └─ 我的问题 → 进入维度②
    
维度②：社会问题还是个人问题？
  ├─ 社会/行业/周期问题 → 节约精力
  └─ 个人可改变 → 进入维度③

维度③：别人定义的还是我选择的？
  ├─ 别人定义的 → 重新问"我真正想解决的是什么"
  └─ 我主动选择的 → 进入维度④

维度④：评判权在谁手里？
  ├─ 评判权不在我手里 → 停止内耗，不试图解决别人的评价系统
  └─ 评判权部分在我手里 → 进入 Step 2：问题翻面
```

---

## Step 2：问题翻面法

对确认后的个人问题，执行翻面：

```
原问题 → 翻面后的问题
"员工不努力怎么办" → "员工为什么没动力去努力"
"怎么赚更多钱" → "怎么不亏钱"
"怎么涨粉" → "为什么粉丝不关注我"
"怎么管理时间" → "我的时间花在了不该花的地方"
"这本书讲了什么" → "这本书没讲什么"（没讲的部分往往比讲了的部分更有价值）
```

**翻面规则**：

1. 找到原问题中包含的**隐含假设**（"员工不努力" = 假设他们有能力但不努力）
2. 把假设翻过来（"为什么没动力" = 可能是有阻碍导致不能努力）
3. 翻面后的问题才是真正需要解决的问题

**翻面通过标准**：翻面后的问题和原问题指向不同的答案空间。如果翻面后答案一样，说明翻面没到位。

**翻面输出必须包含**：
1. 原问题的隐含假设是什么
2. 翻面后的问题是什么
3. 答案空间发生了什么变化
4. 如果翻面失败，失败原因是什么

**失败信号**：
- 只是把句子换了说法，但仍在问同一个问题
- 没有暴露原问题的前提假设
- 翻面后仍然只能得到同一组行动建议

---

## Step 2.5：结构法 / 解剖法（复杂问题才进入）

如果翻面后仍然是复杂问题，不要急着给建议，先解剖：

1. 我真正担心什么？
2. 最坏结果是什么？
3. 这个结果我能不能承受？
4. 哪些变量我能控制，哪些不能控制？
5. 如果只能做一件事，最关键的一步是什么？

**边界**：
- 问题界定器只负责判断和拆解，不替用户承担后果
- 如果这个模块被高频独立调用，后续可作为"问题解剖/决策解剖"新 Skill 候选，但必须先走语义探测、架构审计和 `/审核 skill`

## Step 3：可逆性判断

判断问题是否可逆，决定投入多少精力：

| 问题类型 | 判断标准 | 决策策略 |
|---------|---------|---------|
| **单向门**（不可逆） | 做错了回不来：离婚、辞职、生娃、搬家、大额投资 | 多方验证、慎重、不急于下结论 |
| **双向门**（可逆） | 做错了能回来：约会去哪、买什么工具、先试哪个方向 | 快速决策、不纠结、先行动再调整 |

**核心问题**：**如果错了，能回来吗？**
- 能 → 双向门：别纠结，立刻行动
- 不能 → 单向门：再慢都值得，多方验证

可调用脚本：
```bash
python3 ~/.hermes/skills/problem-definer/scripts/single-door-detector.py "<用户问题或决策描述>"
```

如果脚本输出 `must_not_directly_decide: true`：
- 不直接回答"应该/不应该"
- 先问最坏结果、回滚路径、承受能力、低成本试验
- 必要时转入二阶思考或人工判断

## 何时用问题界定器

**用 problem-definer 的信号**：
- 遇到复杂问题不知道从哪下手
- 感觉问题"不对"但说不清
- 队友/老板/客户抛来问题需快速判断优先级
- 在做任何决策/分析/碰撞之前，先界定问题归属和性质

**不用 problem-definer 的信号**：
- 已有明确答案的执行性问题
- 纯创意发散阶段（先不要限制）
- 紧急情况来不及界定（先止损）

---

## 红灯边界（硬门禁）

- 🚫 跳过五要素门禁直接回答——会变成替代思考的外脑
- 🚫 用户强烈要答案——Step 1-3 不偏
- 🚫 翻面后答案没变——翻面失败，强制回到 Step 1 重新界定
- 🚫 评判权完全不在自己手里——停止内耗，告知用户
- 🚫 把"翻面"做成"换词游戏"——必须真暴露假设
- 🚫 用问题界定器做决策——只界定，不决策

| CP | 触发 | 标准 |
|----|------|------|
| **CP1** | Step 0 后 | 五要素缺 ≤2 项？否则回去补问 |

| **CP3** | Step 2 后 | 翻面后答案空间**真正变化**了？ |
| **CP4** | Step 3 后 | 可逆性明确判断？脚本校验？ |
| **CP5** | 输出后 | 输出格式完整（6 项必填）？|

## 失败处理（Fallback）

| 失败场景 | Fallback |
|---------|---------|
| 缺五要素 | 引导"补 3 项以上"再回来 |
| 4 维卡在中间 | "这个问题同时包含 X 和 Y，可以拆开吗？" |
| 翻面失败（答案没变） | 回到 Step 1 重新界定 |
| 解剖后用户拒绝承担 | "这是你的问题，我的 Skill 只能到这里" |
| 单向门用户想快速决定 | "必须先回答：最坏结果是什么？" |
| 用户只想要方案 | 引导"先界定 5 分钟，方案会更准" |

## 边界与注意事项

1. **不替代决策**：只做"这是什么问题"，不做"应该怎么解决"
2. **不替代碰撞**：翻面后需要创意发散，请用 碰撞 skill
3. **翻面要到位**：翻面后答案和原问题一样，说明没翻彻底
4. **单向门不是不变**：单向门=错了代价大，不是决定了就不能改
5. **四维顺序固定**：必须按 ①→②→③→④ 的顺序，跳步可能导致无效界定
6. **评判权不是归属权**：就算问题和你有关，评判标准未必在你手里。"别人觉得我装不装"——核心是识别你根本无法接管对方的评价系统
