# 口播练习·老伙计版 v3

> 核心哲学：口播是一个形式，真正的价值是对知识的理解和运用。

---

## 一句话定位

**输入（每日固定时间）→ Phase 1 知识深挖（4 步骤）→ 满意度门 → Phase 2 表达输出（4 步骤）→ 资产沉淀（每日必沉淀）→ 可选内容生产管线（评论→拍摄闭环）。**

---

## 两阶段模型

```
Phase 1 — 知识的理解与运用
  每天选一张知识卡，反复深挖本质、连接、应用、误区
  AI角色：认知追问者（质疑/批判/连接）

Phase 2 — 知识的表达与输出
  在理解满意后，练习表达、获取反馈、沉淀资产
  AI角色：内容教练（结构/表达/打磨）

两阶段之间有明确的门：
  Phase 1 的"满意"才能进入 Phase 2
```

---

## Phase 1：知识的理解与运用

### 步骤 1：选题（知识卡选择）

选一张你今天想搞懂的知识卡。

**选题原则**：
- 对更多老伙计有用，且长期有用
- 这张卡你还没有真正搞懂（能说清楚才算懂）

**AI 推荐**（从知识库）：
```
今日知识卡候选：

1️⃣ [概念名] — 最后使用：X天前 | 关联概念：N个
   [一句话说清这是什么]

2️⃣ [概念名] — ...
```

**特殊触发**："XXX 我说不清楚" → 你没真懂 → 选它作为今日深挖对象。

### 步骤 2：知识深挖（8 维度）

> ⚠️ AI 角色：认知追问者模式。任务是促进你深度思考，不是帮你写内容。

| # | 维度 | 追问方向 | 示例 |
|---|------|---------|------|
| 1 | **本质追问** | 它到底是什么？去掉比喻后剩什么？| "给一个 12 岁的孩子讲这个概念，怎么说？" |
| 2 | **结构追问** | 整体知识结构？子概念？| "上层是什么？下级有什么？" |
| 3 | **因果追问** | 为什么是这样？底层逻辑？| "哪个环节最容易被忽略？" |
| 4 | **应用追问** | 具体怎么用？你上次用是什么时候？| "今天之内你能用一次吗？" |
| 5 | **误区追问** | 常见错误理解？你自己之前错在哪？| "大多数人听到这个第一反应错在哪？" |
| 6 | **反例追问** | 什么时候不成立？边界？| "能想出一个反例吗？什么时候反而有害？" |
| 7 | **连接追问** | 和已知概念有关？| "这和上周说的[概念]什么关系？" |
| 8 | **压缩追问** | 一句话说清核心 | "用 20 个字说清这张卡在说什么。" |

**非线性深挖流程**：

```
AI问 → 你答 → AI追问/质疑 → 你深化 → AI连接/对比 → 你整合
                                        ↓
                         循环直到你说"这块我清楚了"
                                        ↓
                         换一个维度继续
```

**特殊触发词**：

| 你说 | AI 响应 |
|------|--------|
| "我不懂 XXX" | 切换到维度 1/3/5，先解决理解障碍 |
| "我当时是这样做的..." | 切换到维度 4/6，结合你的经验 |
| "这让我想到 XXX" | 切换到维度 7，探索连接 |
| "不对，应该是..." | 发现盲区，切换到维度 1/5 |
| "太抽象了" | 切换到维度 4，找最小行动 |
| "那 XX 场景呢？" | 切换到维度 6/7，测试边界 |

### 步骤 3：压缩检验（满意门）

深挖到一定深度后做压缩检验。这是能否进入 Phase 2 的出口门。

```
### 压缩检验

⚠️ AI 不代答。你必须自己回答。

1️⃣ 一句话说清本质（≤ 20 字）：
2️⃣ 一个最简行动（任何人看完都能做的一步）：
3️⃣ 一个最小案例（3 句话讲清用的场景）：
4️⃣ 和已知常识的连接（"就像...但不完全是..."）：
```

**通关条件**：四问中至少三问能清晰回答。回答模糊 → 回去继续深挖。

### 步骤 4：满意度选择

```
你对 [概念名] 的理解状态：

🟢 满意，可以进入 Phase 2 表达输出
🟡 基本懂了，但想下次再深挖某个维度
🔴 还没搞懂，明天继续深挖

选择：
A — 进入 Phase 2：表达练习
B — 先沉淀理解成果，后续再表达
C — 仅深挖，今日不表达
```

## Phase 2：知识的表达与输出

> ⚠️ AI 角色切换：内容教练模式。目标不是"搞懂"，而是"让更多人搞懂"。

### 步骤 1：表达准备（结构建议）

```
┌─ 钩子：[反常识/冲突感的方向]
│
├─ 认知冲突（深挖时最大的认知升级点）：
│  [以前以为 X → 但实际上是 Y → 为什么错了]
│
├─ 案例（来自你自己的经历，或者典型场景）：
│  [具体场景]
│
├─ 行动建议（看完能做的一步）：
│  [具体可执行]
│
└─ CTA：[关注/收藏/评论]
```

### 步骤 2：表达 + 迭代循环

```
你表达 → 三问自检 → AI 点评 → 打磨 → 再表达
                                          ↓
                            循环直到你说"满意了"
                                          ↓
                            进入产出模式选择
```

**三问自我检查（每轮强制）**：

```
❓ 第一问：这段内容和我有什么关系？
❓ 第二问：看到哪里观众会划走？（必须答出具体时间点或元素）
❓ 第三问：看完后他想干什么？
```

**循环上限**：5 轮。超过 5 轮仍未满意 → 主动暂停，考虑换主题。

**用户决策**：
- "满意" → 跳出循环，进入产出模式选择
- "不满意" → AI 推荐 1 个打磨方向，打磨后重新表达

### 步骤 3：产出模式选择

```
满意了，这次产出什么？

A — 出逐字稿 → 去拍摄 → 复盘
B — 出文章 → 沉淀资产（不拍视频）
C — 先沉淀资产，后续再说
```

### 步骤 4：拍摄 + "拍完了"

选 A "出逐字稿" 时执行：

1. **三问自我检查**（同前）
2. **拍完了** → 记录本次练习：
   - 拍了几遍？
   - 最有感觉的是哪一遍？
   - 什么地方卡住了？

## 资产沉淀（每日必做）

每次练习至少沉淀一条可复用资产。

| 练习阶段 | 沉淀内容 | 示例 |
|---------|---------|------|
| Phase 1 | 认知升级点 / 连接关系 / 误区 | "我之前以为 X 是独立概念，现在发现它是 Y 的子集" |
| Phase 2 | 表达模式 / 开头句式 / 案例 | "这种'先否定后重构'的句式很适合认知反差型内容" |

**最小可接受**：3 行 mini 知识卡。

---

## 内容生产管线（打通评论→拍摄→沉淀）

> 创作不是从零开始写，而是从评论区找到真实痛点 → 对应到已有知识 → 拍 → 回填沉淀。

```
扒评论 → 排序找选题 → 知识库映射 → 核心点分析 → 拍视频 → 回填 AI → 生成知识卡 → 入库
```

### 各环节要点

**1. 扒评论 + 排序找选题**
- 从短视频评论区抓真实用户反馈
- 高赞评论 = 一类人的真实痛点
- 筛选标准：这条评论能映射到一个典型用户吗？

**2. 知识库映射（找弹药）**
- 选题不是拍脑袋，是对应到你已有的知识
- 如果映射不上去 → 说明这个话题你还不懂，**先深挖再拍**

**3. 快速拍 + 回填 AI**
- 拍完不结束——把转录回填给 AI，生成结构化知识卡
- 知识卡入库，下次遇到同类问题直接可用

**4. 回填是闭环的关键**
> **没有回填的内容不算完成。**

### 管线故障自查

| 卡在哪 | 原因 | 怎么办 |
|--------|------|--------|
| 没选题 | 没扒评论 | 建一个评论收集流程 |
| 有选题但拍不出来 | 知识库映射不上 → 还不懂 | 先深挖（走 Phase 1）再拍 |
| 拍完了没回填 | 缺少回填机制 | 拍完自动转写 → AI 抽取 → 知识卡 |
| 回填了不入库 | 质量不达标 | 写清楚核心观点再入库 |

## 何时用口播练习

**用 oral-practice 的信号**：
- 每天固定时间做口播练习
- 想系统化提升认知深度
- 想把知识转化为可表达内容
- 想搭评论→拍摄→沉淀的闭环

**不用 oral-practice 的信号**：
- 只想快速产出口播脚本（用 oral-alchemy）
- 完全没基础要先学（用 sankuaifa）
- 只想出图不做口播（用 knowledge-card-design）

---

## 红灯边界（硬门禁）

- 🚫 跳过 Phase 1 直接进 Phase 2 —— 没有认知的表达是空洞的
- 🚫 压缩检验没通过就强行进 Phase 2 —— 表达只会暴露理解漏洞
- 🚫 AI 代答压缩检验问题 —— 你必须自己回答
- 🚫 表达迭代超过 5 轮 —— 主动暂停换主题
- 🚫 拍完不回填 —— 等于没练习
- 🚫 选"先沉淀不表达"超过 3 次 —— 表达本身是深度理解的工具

## 检查点设计（CP1-7）

| CP | 触发 | 标准 |
|----|------|------|
| **CP1** | Phase 1 开始 | 选题完成？（用户已确认知识卡） |
| **CP2** | Phase 1 中 | 深挖了至少 3 个维度？ |
| **CP3** | Phase 1 完成 | 压缩检验 4 问至少 3 个清晰？ |
| **CP4** | Phase 1→2 切换 | 用户明确说"满意"或选 A？ |
| **CP5** | Phase 2 中 | 表达至少做了 1 轮三问自检？ |
| **CP6** | Phase 2 完成 | 用户明确说"满意"或选 A/B/C？ |
| **CP7** | 练习结束 | 至少沉淀 1 条资产？ |

---

## 失败处理（Fallback）

| 失败场景 | Fallback |
|---------|---------|
| 用户不知道选哪张卡 | AI 推荐 3 张候选 + "选 1 张" |
| 深挖卡在某维度 | 切换到不同维度（用 8 维度表） |
| 压缩检验答不出 | 回去继续深挖，不是退出 |
| Phase 2 迭代超过 5 轮 | 主动暂停："建议换主题，今天先到这里" |
| 拍完忘了回填 | 提醒："回填是闭环的关键，没回填不算完成" |
| 表达空洞无内容 | 回到 Phase 1 重做理解 |
| 用户嫌太累想跳过 Phase 1 | 提醒："跳过理解，表达只会暴露漏洞" |
