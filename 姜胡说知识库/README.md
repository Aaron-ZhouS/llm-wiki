## 收录的文档格式规范

转录件通常来自「得到大脑」，自带以下结构：

```
# 📑 智能总结        ← AI 摘要（含录音信息 / 录音总结）
# 📅 章节概要        ← 带时间戳的章节导航（重要，用来快速定位）
# ✨ 金句精选        ← 已标注类型（方法技巧/战略洞见/情绪共鸣…）
# 📋 待办事项        ← 责任到人的行动项
# 原文              ← 完整逐字稿（很长）
```

**处理原则：**
- **完整保留原文**，不要截断 —— 这是原始素材，是金矿
- 图片链接（`![](https://...oss...)`）保留，但会失效；如需本地化可单独下
- 章节概要 + 金句精选 + 待办事项是**高价值索引**，不要删
- 原文部分超长（可能几千行）时，如果超过 500 行，按 SCHEMA 规则拆分或移入 `_raw/`

```text
用户上传课程 MD（得到大脑转录件）
   ↓
① 原始件归档 → 姜胡说知识库/线下答疑|线上课程/YYYY-MM-DD-主题-姜胡说.md
   ↓
② 精读章节概要 + 金句精选 → 提炼 3-8 个核心方法论
   ↓
③ 核心方法论概念卡 → 姜胡说知识库/核心方法论/（标注来源链接到实录）
   ↓
④ 金句索引 → 姜胡说知识库/金句库/（按主题聚合 + 标出处）
   ↓
⑤ 二次创作（可选）：口播 / 公众号 / 小报童 / PPT → 各自的目标库
```
