# 影响力写作每一部分都是资产

> **一句话**：**写的每一部分都是资产，都在构建影响力** —— 每个内容都要想「**我在影响别人，同时反过来影响自己**」。

---

## 原始定义（2026-11-12 · 江湖说三天线下活动复盘分享会 · 影响力写作讲解）

胡子哥的原话：

> **影响力写作：不是上学时的写作、抒情诗、情书、散文**，而是**写的每一部分都是资产，都在构建影响力**，每个内容都要想「**我在影响别人，同时反过来影响自己**」。

**第一条爆款（反面教材的定位）**：
> **胡子哥第一条爆款是精心设计的，每一句都是沟通（钩子），让人从头看到尾，一定会点赞评论收藏关注。** 可作为教学片拆解，**但不推荐大家做那样的视频**。

**商业模式的配合（同一段）**：
> **你的用户群体是谁？你能给他们提供什么价值？为什么是你？（又便宜又快又好）**

**用户思维（同一场，财税从业者案例）**：
> **不能一开场就说「我是什么、我要干什么」**，而应**从客户在想什么出发**，感受客户的焦虑、担心，**通过语言嫁接到知识上传给客户，让客户产生信任**。

---

## 逻辑框架

```
❌ 上学写作                    ✅ 影响力写作
──────────                    ────────────
抒情诗 / 情书 / 散文            每段都有功能
  ↓                              ↓
表达自我                        影响读者
  ↓                              ↓
读完就忘                        读完被改变 + 资产累积
```

**双向机制（关键）**：
```
      我写内容
         ↓
    影响读者 ──→ 读者行动
         ↑
    反过来影响我（写的过程本身就是认知梳理）
```

**关键**：**「反过来影响自己」是大多数人不认的部分** —— **写不是输出，是双向的。**

---

## 落地动作

1. **每段问「这段在干什么」** —— **钩子/共鸣/方案/CTA，不能只是抒情**
2. **别写「我是谁我要干嘛」** —— **从读者在想什么开始**
3. **语言嫁接** —— **用读者的焦虑语言，带出你的知识**
4. **写完自查「这会影响谁」** —— **影响不了任何人 = 白写**
5. **把写当认知梳理** —— **写不动 = 想不清**
6. **自检**：我这段写完，读者多了什么认知或动作？

## 配套：与「结果前置做强钩子」的合流

[[结果前置做强钩子]]（10-22）：**必须把学员拿到的结果前置做强钩子。**

**本卡是它的「上位原则」** —— 「每一句都是沟通（钩子）」正是**结果前置**的极致（胡子哥第一条爆款）。

**关键**：**胡子哥明确说「不推荐大家做那样的视频」** —— **因为那是为他的个人品牌设计的**，**普通人照抄会失效**。

## 配套：与「故事化表达结构」的呼应

[[故事化表达结构]]（09-28）：**用故事代替说理**。

**本卡说「每段的功能」，那张卡说「用什么承载」** —— **故事是手段，资产是标准。**

## 配套：与「自媒体传播三问」的对照

[[自媒体传播三问]]（10-23）：**内容传播的三问**。

**本卡加一条第四问** —— **「这段在影响谁？」** —— **前三问管传播，第四问管复利。**

## 配套：与「用户思维」的直接合流

同一场财税从业者案例：**「不能一开场就说『我是什么、我要干什么』，而应从客户在想什么出发，感受客户的焦虑、担心，通过语言嫁接到知识上传给客户，让客户产生信任。」**

**本卡是这条的执行标准** —— **「语言嫁接」就是影响力写作的具体手法**：
```
读者的焦虑语言  →  嫁接  →  你的知识
```

## 自检清单

- [ ] 我这段是在抒情还是在干活？
- [ ] 我一开口说的是「我是谁」还是「你在想什么」？
- [ ] 我用了读者自己的语言吗？
- [ ] 这段写完，读者多了什么认知或动作？
- [ ] 写这段的过程，我自己想清楚了吗？
- [ ] 我是不是在照抄「爆款模板」？（胡子哥自己说不推荐）
