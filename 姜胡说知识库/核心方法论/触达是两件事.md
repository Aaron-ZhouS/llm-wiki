# 触达是两件事

> **一句话**：**触达分为两个核心部分** —— 第一是**让用户在认知上看见你、知道你的产品价值**，第二是**让用户可以方便地拿到你的产品**。

---

## 原始定义（2026-10-14 · 赚钱的完整闭环）

胡子哥的海飞丝类比（**完整原话**）：

> **触达分为两个核心部分，第一是让用户在认知上知道你的产品价值，第二是让用户可以方便拿到你的产品。**

> **以海飞丝为例，需要先让用户记住「去头屑用海飞丝」，再让用户可以方便买到海飞丝，才算完成有效触达。**

**当前普遍的触达问题**：

> **多数经营者不愿意露脸，不愿意做媒体传播，不愿意线下见客户铺货**，导致**信息和物理层面都无法完成有效触达**。

---

## 触达两件事对照

| | ① 认知触达 | ② 物理触达 |
|---|---|---|
| **要达成** | 用户**知道你的价值** | 用户**能方便拿到** |
| **海飞丝** | 记住「去头屑用海飞丝」 | **方便买到**海飞丝 |
| **靠什么** | 内容 / 媒体 / 口碑 / 直播 | 渠道 / 铺货 / 购买路径 |
| **失败症状** | **没人知道你有这本事** | **知道了但找不到你** |
| **对应的卡点** | **不愿意露脸、不做媒体传播** | **不愿意线下见客户、不铺货** |

**关键**：**只做 ① = 纸上谈兵；只做 ② = 摆地摊没人问。** —— **两件都做才算有效触达。**

---

## 落地动作

1. **先问「他知道吗」** —— **认知触达**：反复讲同一件事（参考「去头屑用海飞丝」的句式）
2. **再问「他买得到吗」** —— **物理触达**：购买路径**别超过 3 步**
3. **露脸是认知触达的核心** —— **不露脸 = 只能靠转发，触达效率最低**
4. **线下见客户 / 铺货是物理触达的核心** —— **很多人只做线上**
5. **两件事各配一个具体动作** —— **别停在「我要做推广」**
6. **自检**：他**知道**吗？他**拿得到**吗？

## 配套：与「输出扩张幸运表面积」的合流

[[输出扩张幸运表面积]]（10-12）：**通过输出扩张幸运表面积，让别人看到你的价值。**

**本卡补上输出的另一半** —— **输出只解决 ① 认知触达，不解决 ② 物理触达**。

**关键**：**「内容做起来了但变现不了」= 物理触达断了** —— **产品找不到、买不到、加入路径太深。**

## 配套：与「不敢露脸怕被评价」的呼应

胡子哥列的 6 个认知卡点里，**两个直接卡在触达上**：
- **不愿意露脸怕被说三道四** → 认知触达断
- **不愿意线下见客户铺货** → 物理触达断

**这说明「触达」之所以难，不是方法难，是心理难** —— **两个都是「怕被评价」的反应。**

**配套 [[真实表达不是表演技巧]]（09-23）**：**面对镜头不自然的根因是「内容假」** —— **怕被评价 = 怕露馅。**

## 配套：与「短视频商业定位」的合流

**同一份胡子哥重新解读短视频定位**：

> **多数人认为短视频只是做宣传、做流量的工具，这个定位格局太小。**

> **短视频完整覆盖了赚钱闭环的全部环节**：它是**构建自身能力、了解用户需求的渠道**，是**完成触达让更多人看见你的路径**，是**提供价值完成交换的场景**，也是**收集用户反馈调整方向的入口**。

**关键**：**短视频 = 触达的主要载体 + 交换的场景 + 反馈的入口。** —— **不是「宣传工具」那么小。**

---

## 配套：与「载体不等于卖点」的对照

[[载体不等于卖点]]（09-17 王家爵）：**线下活动是载体，真正的核心是「低成本高触达的效率最大化」。**

**本卡是它的通用版** —— **海飞丝类比就是「载体（洗发水）不等于卖点（去头屑）」的正面写法**：
- **卖点** = 去头屑（**认知**）
- **载体** = 海飞丝（**物理**）
- **两者合一** = 有效触达

## 自检清单

- [ ] 目标用户**知道**我在解决什么问题吗？
- [ ] 我能用一句话说清我的价值吗？（像「去头屑用海飞丝」那样）
- [ ] 目标用户**买得到 / 找得到**我吗？路径几步？
- [ ] 我愿意露脸吗？为什么不愿意？
- [ ] 我做过线下见客户 / 铺货吗？
- [ ] 我只做了触达的一半吗？（还是两件都做了）
