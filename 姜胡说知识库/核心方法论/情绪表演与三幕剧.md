# 情绪表演与三幕剧

> **一句话**：情绪不是「有才能拍」，是**「可以提前演」**。而且它是最强的武器。

---

## 原始定义（2026-11-06 Day3 · 第十部分）

> "今天路上的时候很多老伙计说：'我突然发现原来我以前一直处理不好情绪，但是我怎么感觉今天我的情绪是可以融入到作品里面的呢？'我说是的，**事实上我们的情绪是可以融入到作品里的**。"
>
> "你尝试一下，你每次拍视频之前，如果你的这个视频里边有这个情绪，**事实上你完全可以像刚才一样让自己进入这个情绪**。"
>
> "甚至你会发现你在口播的过程中，一边拍视频，一边让自己慢慢集中你的这个情绪。"
>
> "这个时候你会发现**情绪就会成为你的助力，而且情绪是你最强大的武器**。"

---

## 关键翻转

```Plain Text
❌ 有情绪才拍（被动等状态）
        ↓
✅ 拍之前先进入情绪（主动设计）
        ↓
拍的过程中继续集中情绪
        ↓
情绪 = 最强的武器
```

**这与「视频是状态的溢出」不矛盾** —— 区别在于：

| | [[视频是状态的溢出]] | 本卡 |
|---|---|---|
| **对象** | 长期状态（活舒坦不活舒坦）| 单条内容的情绪 |
| **时长** | 天/月级别 | 单条视频级别 |
| **做法** | 先解决卡点，让状态自然好 | **主动进入**特定情绪再开拍 |

---

## 3 幕剧结构（Day3 现场设计）

Day3 下午安排了「讲故事卖货」的情绪表演训练，核心是三幕剧：

```Plain Text
第一幕 · 建立（谁 / 什么场景 / 我在哪）
   ↓
第二幕 · 冲突（卡点 / 反转 / 意外）
   ↓
第三幕 · 落点（变化 / 收获 / 记忆点）
```

**配套原则（来自「记结构不记句子」）**：只记 1-2-4-8 的骨架，台词现场生成。

---

## 落地动作

### 1. 拍前 30 秒：情绪预演

拍之前问自己三个问题：
1. 这条视频我要什么情绪？（愤怒 / 心疼 / 爽 / 好奇 / 羡慕）
2. 什么场景会让我产生这个情绪？（回忆一个具体画面）
3. 身体什么反应？（声音发抖 / 手心出汗 / 语速变快）

**然后：走进那个场景，再开机。**

### 2. 拍的过程中集中情绪

不是一次到位 —— 边拍边把情绪往回收拢（胡子哥原话：「一边拍视频，一边让自己慢慢集中你的这个情绪」）。

### 3. 三幕自检

- [ ] 第一幕能不能 10 秒内建立场景？
- [ ] 第二幕有没有真实冲突？（不是硬编的）
- [ ] 第三幕有没有落点 + 记忆点？

---

## 与「真诚是地基」的关系

**情绪表演 ≠ 表演欲。**

| | 表演欲（杂质）| 情绪表演（武器）|
|---|---|---|
| **动机** | 我要显得厉害 / 要流量 | 我要传递一个真实情绪 |
| **结果** | 观众能闻到「他在演」| 观众被打动 |
| **判据** | 去掉后内容更好 | 去掉后内容空掉 |
