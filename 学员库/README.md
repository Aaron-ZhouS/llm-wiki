## 学员库写作约定（写文章前的 SOP）

### Step 1：调素材
1. 打开对应学员目录的 `README.md`，看学员画像和写作风格
2. 看 `知识卡片/` 找跟主题相关的卡片
3. 如果卡片不够用，去 `日记原文/` 用 `Ctrl+F` 搜关键词（学员名/行业/场景词）

### Step 2：选脱敏级别

按发布渠道选脱敏级别（详见每人的 `脱敏清单.md`）：

| 渠道 | 级别 | 改什么 |
|---|---|---|
| 自己公众号内部分享（学员社群） | L1 | 学员姓名改化名 + 移除具体金额 |
| 公众号对外公开发表 | L2 | + 移除学员客户/合作方真实信息 |
| 多平台分发（小红书/视频号） | L3 | + 替换所有可识别场景 |

### Step 3：写提示词

**写公众号文章的通用模板：**

```
以下素材来自学员「<学员化名>」（<行业>）的每日记录。

【素材原文】
<粘贴日记原文相关段落>

【写作要求】
- 用学员的第一人称口吻（「我」「我的」「今天」）
- 保留她的具体场景和真实数字（已按 L2 脱敏）
- 5 段结构：3秒钩子 → 30秒情绪积累 → 认知转折 → 高潮 → 收尾
- 公众号风格，2500-3200 字
```

## 学员知识库更新流程

1. 学员在飞书继续写
2. 把新链接发我
3. 我跑脚本拉最新飞书原文 → 覆盖 `日记原文/`
4. 检查新增内容是否值得拆卡片 → 增量更新 `知识卡片/`
5. 学员画像或写作风格变了 → 更新 `README.md`

> 自动化脚本模板在 `/tmp/fetch_qimeng.py`，新学员复制改 wiki_token 即可
