# 琪萌 - 脱敏清单

> 写琪萌相关文章前的脱敏 SOP
> 三级分级：**L1**（学员社群内）→ **L2**（公众号对外）→ **L3**（多平台分发）

## 必须脱敏的字段

### L1 - 学员社群内分享（最低脱敏）

| 字段 | 原值 | 脱敏后 | 备注 |
|---|---|---|---|
| 学员姓名 | 琪萌 | 保留「琪萌」 | 学员社群内已知身份 |
| 学员化名（备用） | — | 小琪 / 萌姐 | 文章里偶尔用化名增强代入感 |

### L2 - 公众号对外公开发表（标准脱敏）

| 字段 | 原值 | 脱敏后 | 理由 |
|---|---|---|---|
| 学员姓名 | 琪萌 | **「琪姐」**或**「小琪」** | 学员本人公开身份保护 |
| 学员真实身份 | 母婴店主 | **「实体店主」**或**「实体创业者」** | 不暴露行业可识别性 |
| 学员性别特征 | 二胎宝妈 | 保留「宝妈」可，去掉具体几个孩子 | 「40岁」保留，「二胎」改为「妈妈」 |
| 学员具体年龄 | 40岁 | 保留（如学员许可）或「四十多岁」 | 真实数字更有说服力，需学员同意 |
| 具体成交金额 | 6000 / 69 / 199 / 399 / 599 | 改区间：「6000+」 / 「百元以内」 / 「千元级」 | 学员产品价格不公开 |
| 学员社群/小报童定价 | 69元小报童 | 「我的知识付费产品」 | 不暴露定价 |
| 学员真实播放量 | 1695 / 5000 | 改区间或保留具体数字 | 看学员意愿 |
| 具体城市/小区 | 无（琪萌没写） | — | — |
| 学员真实姓名拼写 | 琪萌的拼音/微信名 | — | 不在原文出现 |

### L3 - 多平台分发（最高脱敏）

| 字段 | 原值 | 脱敏后 | 理由 |
|---|---|---|---|
| 学员姓名 | 琪萌 | **「小琪」** | 视频号/小红书陌生人可见 |
| 学员身份 | 二胎宝妈 / 母婴店主 | **「一位正在转型的实体店主」** | 完全去行业化 |
| 具体年龄 | 40岁 | 「不惑之年」「40+」 | 模糊化 |
| 具体成交金额 | 6000 | **「几千块的客单」** | 完全模糊 |
| 小报童定价 | 69元 | **「一杯咖啡的价格」** | 完全模糊 |
| 学员合作的工具名 | workbuddy / WorkBuddy | **「我的 AI 工具」** | 隐藏具体工具 |
| 学员对标账号 | 瓜瓜 / 石头 / 汝禾 / 周佩佩 / 张璐 / 赵哈哈 | **「做得不错的同行」** | 不点名 |
| 学员客户真实反馈 | "2000 学员"、"60 后不会电脑" | **「我有个学员」「有位客户」** | 学员客户身份完全模糊 |
| 学员家庭情况 | 二胎 / 妈妈 / 孩子 | **「家人」「孩子」** | 保留情感但去识别度 |
| 学员直播平台 | 视频号 / 抖音 | **「短视频平台」** | 不点名平台 |

## 脱敏工作流

### 写文章前
1. 打开琪萌原文 → 复制相关段落
2. 对照上表，标出所有需要脱敏的字段
3. 用替换/改写方式处理

### 文章写完后
1. 通读一遍，搜真实数字（6000 / 1695 / 199 等）
2. 搜学员姓名（琪萌 / 琪姐 / 小琪）
3. 搜客户/学员称呼（学员 / 客户 / 粉丝）
4. 搜具体工具名（workbuddy / Codex）
5. 搜对标账号（瓜瓜 / 石头 / 汝禾 / 赵哈哈）

### 自动化建议
写一个 grep 脚本自动检查（见末尾"附：脱敏检查脚本"）。
