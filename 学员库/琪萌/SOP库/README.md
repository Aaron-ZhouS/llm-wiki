# SOP库

> 周盛老师的一人公司赛道 **Skill 使用 SOP 手册库**
> 用途：每个 Skill 一份"学员拿来就能用"的操作手册
> 原则：**学员打开就能照着做**，不解释为什么，不讲理论，只讲"我该按什么步骤操作"

## 一份 SOP 手册的标准 8 段

每篇 SOP 手册统一格式，学员不用适应不同风格：

```
1. 一句话定位（这张卡讲什么）
2. 什么时候用（触发信号 3 条）
3. 什么时候不用（避坑 3 条）
4. 调用方法（触发词 + 3 步流程）
5. 输入模板（学员复制粘贴即可）
6. 输出物（拿到什么）
7. 与其他 Skill 的联动（什么时候接给下一个）
8. 实战示例（琪萌已用过的真实例子）
```

## 写新 SOP 的流程

**触发**：周盛说"给 X Skill 写 SOP" / 周盛新装一个 Skill 需要 SOP

**步骤**：
1. 读 `/mnt/d/Obsidian/llm-wiki/concepts/<skill-name>.md`（Skill 原文）
2. 按上面 8 段格式写 `SOP-<skill-name>.md`
3. 在本 README 学员清单追加一行
4. 同步到学员库（每个学员目录都复制一份）

---

## 学员库同步约定

每写一份新 SOP，需要**同步给每位学员**：

```
/mnt/d/Obsidian/llm-wiki/SOP库/SOP-<skill>.md   ← 总库（唯一来源）
/mnt/d/Obsidian/llm-wiki/学员库/<学员名>/SOP库/  ← 学员本地副本
   ├── SOP-口播炼金.md
   ├── SOP-知识卡片.md
   ├── SOP-灵感对撞.md
   ├── SOP-挖矿压缩机.md
   └── SOP-可运行性检查.md
```

> **改 SOP 流程**：改总库 → 同步到每位学员 → 不直接改学员本地（避免版本漂移）
