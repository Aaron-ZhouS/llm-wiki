# SOP · 灵感炼金炉 Skill

> **一句话定位**：你脑子里有个模糊想法，憋不出 1 句话？灵感炼金炉用 7 把刃把它切成锋利洞见。
> **核心心法**：模糊想法不是洞见，是石头；矿不炼就是石头。

---

## 一、先看清卡点：为什么想法很多却说不清

**场景痛点**：

你脑子里天天有想法——"想自律""想赚钱""想学 AI"。但每次想跟人讲、写下来、发出去，**总是讲不清楚**。说两句就散了，别人听完也不知道你到底想表达什么。

**认知卡点**：

你以为"想清楚了 = 表达出来了"。其实**模糊想法没经过切割 = 没经过大脑**，只是脑子里飘过的杂音。

**解决方案**：

灵感炼金炉的解法是 **7 刃快速切割 + 4 段输出**（破局点/展开/金句/边界）。**至少 4 把刃切一个主题**，从不同角度攻击同一个想法，留下"既真又锋利"的洞见。

**原话**：

> 胡子哥原话："你有想法讲不出来，不是你不会讲，是你没有切。一个想法从 7 个角度看下去，至少有一个角度会亮。"

---

## 二、什么时候用 / 什么时候不用

### ✅ 满足任意 1 条就用

- 你有一个模糊想法/灵感，想锻造成洞见
- 你想要反常识/反本能的洞见（不只是"听起来有道理"）
- 你想快速输出一个可用的洞察（破局点+金句）
- 你想让一个观点更锋利

### ❌ 触发这些就别用

- **已经有完整素材要变成口播稿** → 换 `口播炼金`
- **要做知识卡（沉淀经验）** → 换 `知识卡片`
- **要压缩观点（200 字金句）** → 换 `挖矿压缩机`
- **只需要事实总结** → 直接 AI 总结，不需要 7 刃

---

## 三、3 步调用流程

```
Step 1：7 刃快速切割（至少 4 把刃，每刃 1 个洞见）
       ↓
Step 2：碰撞筛选（AI 内部进行：排除正确但无用 / 有趣但不真）
       ↓
Step 3：4 段输出（破局点+展开+金句+边界）
       ↓
学员说"更深/换角度/更毒舌" → AI 迭代
```

### 触发词（任意一个）

```
灵感炼金
/inspiration
/alchemy
炼金
7刃切割
快速档
```

### 3 个迭代指令

| 指令 | 效果 |
|------|------|
| `更深` | 在当前洞见上再挖一层，追问背后还有什么 |
| `换角度` | 换一把刃重新切割同一主题 |
| `更毒舌` | 提升犀利度，加入讽刺和反讽 |

2. 有模糊想法（能让 AI 帮忙想清楚）✅
3. 有立场/观点（要更锋利）✅

## 五、7 刃速查（学员必背）

> 至少用 4 把刃，每刃 1 个清晰洞见（1-2 句话）。

| 刃 | 切法 | 示例（"自律"主题）|
|---|------|---------------------|
| 🔴 **悖论刃** | 找被广泛接受但自相矛盾的共识 | "追求自律本身就是最大的不自律——它暗示你在对抗自己" |
| 🟠 **杠杆刃** | 找撬动全局的 20% 支点 | "改变环境比改变自己容易 10 倍" |
| 🟡 **溯源刃** | 追问到第一因，剥掉中间层 | "你不是不自律，你是不知道自己要什么" |
| 🟢 **反转刃** | 把前提翻转 180° 看能否成立 | "最成功的人其实都不自律——他们只是找到了不需要自律的赛道" |
| 🔵 **类比刃** | 从完全不同领域借结构 | "像减肥——靠饿的人最终都会暴食，靠做好吃健康餐的人才能持续" |
| 🟣 **笨拙刃** | 剥掉包装还原朴素真相 | "自律就是重复，重复就是无聊，问题不是能不能忍受无聊，而是你愿不愿意" |
| ⚪ **尺度刃** | 拉大或缩小时间/空间尺度看变化 | "把时间拉到 10 年：差距不在成就，在可选项数量" |

**4 把刃组合策略**：
- 想要**反常识** → 悖论刃 + 反转刃
- 想要**找抓手** → 杠杆刃 + 笨拙刃
- 想要**穿透本质** → 溯源刃 + 尺度刃
- 想要**易懂有画面** → 类比刃 + 笨拙刃

## 六、4 段输出（拿到什么）

```
🔥 破局点
→ [1 句话，直击要害，造成认知落差]

🗡️ 展开（3 层逻辑）
→ 第一层：打破旧认知（大多数人怎么想的，为什么错）
→ 第二层：建立新认知（真相是什么，背后机制）
→ 第三层：给出抓手（1 个可以立刻做的最小行动）

💬 金句
→ [1 句话，≤25 字，有冲突感，可直接当标题/口播开头]

⚠️ 边界
→ [这个洞见在什么情况下失效？1 句话]
```

### 质量清单（5 项全过）

```
□ 破局点有没有"认知落差"？
□ 展开部分能不能念给出租车司机听他也觉得有道理？
□ 金句有没有画面感或冲突感？
□ 行动建议足不足够小？（5 分钟内能开始做）
□ 边界够不够诚实？（不吹万能药）
```

**少于 4 项 → 用迭代指令重新锻造。**

## 七、与其他 Skill 的联动（核心）

灵感炼金炉是 **5 个 Skill 的核心上游**——几乎所有下游 Skill 都需要它。

| Skill | 关系 | 怎么用 |
|-------|------|--------|
| **挖矿压缩机** | 平行 | 都做"压缩"，但炼金是"找洞见"，挖矿是"压成 200 字金句" |
| **可运行性检查** | → 下游 | 洞见出来后过三问，判断值不值得深挖 |
| **知识卡片** | → 下游 | 把洞见沉淀成 L1 卡片 |
| **灵感对撞** | → 下游 | 多个洞见喂给对撞产生新洞见 |
| **口播炼金** | → 下游 | 洞见+故事扩成 5 分钟长稿 |

**完整闭环（最常用）**：
```
灵感炼金炉（7 刃切出洞见 + 金句）
       ↓
可运行性检查（三问 → Runnable-A）
       ↓
知识卡片（沉淀成 L1 卡）
       ↓
口播炼金（洞见扩成视频）
```

**重要区分：灵感炼金 vs 挖矿压缩机**

| 维度 | 灵感炼金炉 | 挖矿压缩机 |
|------|-----------|-----------|
| 输入 | 模糊想法/主题 | 模糊想法（更模糊也行）|
| 输出 | 洞见+4 段输出 | 200 字金句 |
| 切割 | 7 刃（≥4 把）| 5 条规则压缩 |
| 时间 | 慢但深 | 快但浅 |
| 顺序 | **上游**（先有洞见）| **下游**（洞见→压成金句）|

**示例串联**：学员想写"AI 时代如何学习"主题
```
灵感炼金（7 刃切出洞见："学 AI 的杠杆不是学技术，是学怎么喂 AI"）
       ↓
挖矿压缩机（把洞见压成 200 字金句："学 AI 的杠杆不是学技术，是学怎么喂 AI"）
       ↓
知识卡片（沉淀成 L1 卡）
       ↓
口播炼金（扩成 5 分钟视频）
```

## 八、实战示例（琪萌用例）

**学员**：琪萌

**场景痛点**：琪萌想发视频号短稿讲"为什么我总是发不出去"，但憋了一下午，写出来的全是"坚持就是胜利"这种废话。

**触发**：「灵感炼金：为什么我总是发不出去」

**AI 跑了什么**：

1. **悖论刃**：发不出去的真相是"你以为你想发，其实你不想发——你只是觉得应该发"
2. **杠杆刃**：发不出去的杠杆不是内容质量，是"今天就发"这个动作本身——每多拖一天就多 10 倍阻力
3. **溯源刃**：你不是发不出去，你是不敢被人看见——发出去意味着被评判，比不发的痛苦更大
4. **反转刃**：最会发的人都"敢发烂"——他们不怕丑，发的第一条永远是垃圾
5. **碰撞筛选**：留下 #1（悖论）+ #2（杠杆）组合，洞见最锋利

**4 段输出**：
- 🔥 破局点："你不是发不出去，你是不敢被人看见——发出去意味着被评判，比不发的痛苦更大"
- 🗡️ 展开：① 大多数人觉得"发不出去=内容差"（错）；② 真相是"发不出去=不敢被评判"；③ 今天就发 1 条垃圾内容，把"被评判"的痛苦提前消耗掉
- 💬 金句："发出去是药，越怕越要吃"
- ⚠️ 边界：这个洞见不适用于"内容是公司业务"的场景——发公司内容需要质量

**琪萌迭代**：「更深」 → AI 再挖一层："为什么不敢被评判？因为你把'自我价值'绑在了'内容反馈'上"

**学员拿到**：1 个锋利洞见 + 1 句可当标题的金句 + 1 个边界

## 九、6 条红线（学员最容易踩）

🚫 **主题太宽泛**（"AI"/"赚钱"）— 必须收窄到具体场景
🚫 **只要鸡汤不要求真** — 直接拒绝，回到 7 刃规矩
🚫 **7 刃只用 1-3 把（不够）** — 至少 4 把
🚫 **金句 >25 字** — 必须重写
🚫 **行动建议太大**（"努力""坚持"）— 必须缩到 5 分钟能做完
🚫 **边界不诚实**（吹万能药）— 必须重写

**拒绝话术**：

> AI 会说："这个主题不够具体，7 刃下不去刀。你能再说细一点吗？比如'AI 绘画能不能赚钱'而不是'AI'。"

## 十、为什么必须有这个 Skill（学员必看）

没有灵感炼金 = 想法永远是杂音 = 讲不清楚
有了灵感炼金 = 模糊想法 → 锋利洞见 → 一次表达就让人记住你

> 胡子哥原话：**"输出产生价值，输入不产生价值。输入再多，那个东西叫库存。"**

灵感炼金 = 把库存强制逼成可发布的洞见。
