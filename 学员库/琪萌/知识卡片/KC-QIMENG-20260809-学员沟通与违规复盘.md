# 学员沟通 2 小时 vs 一听就会一做就废

## 当天发生的事

跟 2000 的学员沟通将近 2 小时：
- 学员一个视频违规了（按我的视频拍的，视频号正常，抖音违规）
- 违规原因：上面有网址，涉及到引导去其他网站下载
- **她不会复盘了** → 给了复盘模板和提示词
- 她觉得会用了 → 其实没有领悟到精髓
- **每天没短视频选题，不知道拍什么内容**

## 核心洞察：一听就会一做就废的根源

> **「讲得很详细时她根本不愿意听，觉得会了。可是用的时候还是一知半解，最后还会觉得你的方法不对。」**

学员的认知闭环：**听了 ≠ 会了 ≠ 用了 ≠ 通了**

破解方法（萌想出来的）：
- **公开直播时跟学员连麦**
- 演示给她怎么用智能体复盘
- 直播内容 + 主题互动 + 数据都会比自己直播强

## 另一个关键认知

> **做自媒体就是把每天做的事拍出来。**

例：
- 今天用 AI 工作做了什么
- 过程中肯定有成功的也有失败的
- 成功的是怎么做的？失败了是什么原因？下次怎么做避免？
- **把这个过程记录下来就是一个短视频的主题**

短视频选题公式：

```
每天写的过程 = 记录的过程
短视频选题 = 每天做的事里挑一个特别想拍的
按爆款结构变成口播文案
不是"为了选题而选题"
```

## 写作素材点

琪萌提到赵哈哈的开头钩子值得模仿：
- **模仿分不够好** → 开头铺垫太多
- **没有给人随意的感觉**
- 需要多找感觉

## 对写文章的价值

这是**教练视角方法论**的金矿：
- 学员沟通的具体困境（详细讲了不爱听、不讲又不会）
- 公开直播连麦这个解法（既解决学员问题、又变成内容）
- 「执行即选题」的反常识认知

可以直接写成《我花了 2 小时才发现：学员根本不会用我给的方法》类文章。
