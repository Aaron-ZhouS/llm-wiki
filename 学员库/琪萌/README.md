## 调用方法

### 场景 1：给琪萌写公众号文章（按主题调取）

**步骤：**
1. 在 Obsidian 中打开 `日记原文/2026-每天写点什么-飞书原文.md`
2. 用 `Ctrl+F` 搜关键词（例："公众号"、"直播"、"学员"、"变现"、"复盘"）
3. 把当天 `# 8月xx日` 整段复制到 AI 写作上下文
4. 在提示词里加：「以下素材来自学员琪萌的每日记录，请用她的第一人称口吻和她提到的具体场景重写为公众号文章」

### 场景 2：写口播文案（直接复用她写的 AI 文案）

她的"拍点什么"下面已经存了 AI 生成的口播文案（开篇钩子 / 情绪积累 / 认知转折 / 高潮 / 收尾 5段式）。
- 直接挑一天用现成的
- 或挑出 3-5 天同一主题的素材做合集

### 场景 3：提取她的方法论（学员/产品认知）

她记录了大量"对学员沟通的复盘"，比如：
- 学员"一听就会一做就废"的破解方法（直播连线演示）

这些是写"一人公司教练视角"文章的天然素材。
