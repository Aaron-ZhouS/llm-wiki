# 餐品反馈机制 SOP 作业指导书（V01 · 2026-09-09）

> 编制：刘院长 · 大盛代笔
> 适用范围：__________ 养老院食堂
> 核心心法：**大厨亲自下基层 +录音笔全记录 + 周会复盘 = 服务意识倒逼提升**

---

## 一、为什么这件事必做

| 问题 | 影响 |
|------|------|
| **菜品反馈滞后** | 老人不爱吃 → 大厨不知情 → 下次还做同样的菜 |
| **大厨脱离一线** | 厨师在厨房做菜，看不到老人吃饭的表情 |
| **反馈失真** | 护理主任代传 → 大厨觉得"你不懂我菜" |
| **服务意识弱** | 大厨只管做菜，不管好不好吃 |

> **关键心法**（大盛老师）：**"大厨一定要亲自下基层，不能跟老人脱离"**

---

## 二、机制总览（V01 闭环）

```
大厨送餐 → 录音笔全记录 → 周会播放录音 → 团队复盘 → 菜谱优化
   ↑                                              ↓
   └──────────────── 老人满意度 ↑ ────────────────┘
```

## 三、🆕 大厨亲自送餐机制（核心）

### 3.1 送餐频次

| 频次 | 时段 | 时长 |
|------|------|------|
| 🟢 **每周至少 2 次** | 中餐（11:30-12:30）| 1-1.5 小时/次 |
| 🟢 老人反馈时段 | 边送边问 | 全程录音 |

> ⚠️ **送餐 = 大厨身份转变的关键** —— 从"做菜的"变成"送菜的+听反馈的"

### 3.2 送餐 5 步法

| 步骤 | 时长 | 动作 |
|------|------|------|
| 1 | 5 min | 大厨换装（围裙+口罩）→ 准备录音笔 |
| 2 | 20 min | 逐床送餐 + 主动问"阿姨/叔叔，菜够咸吗？" |
| 3 | 15 min | 重点关注：剩菜多的 / 不爱吃的 / 不说话的 |
| 4 | 10 min | 单独陪卧床老人 5-10 分钟（不能漏） |
| 5 | 5 min | 收餐时再问一次"还要什么？" |

### 3.3 送餐话术标准库

| 场景 | 标准话术 |
|------|----------|
| 主动开场 | "阿姨（叔叔），今天这道菜合不合您口味？" |
| 老人说"好吃" | "太好了，下次我再给您做！"（录音笔重点录） |
| 老人说"咸了" | "咸了多少？下次我减点盐"（具体询问）|
| 老人说"不爱吃" | "是不爱吃这个菜，还是这道做法不对？" |
| 老人不说话 | "您要是不爱说话就点点头/摇摇头就行" |
| 老人剩菜多 | "剩了不少，是不合口味吗？"（单独记录）|
| 老人卧床 | 护理员协助 + 大厨亲自喂 2-3 口 |

## 四、🆕 录音笔使用规范

### 4.1 设备配置

| 项目 | 规格 |
|------|------|
| 录音笔 | 爱国者/索尼等品牌，8G+ |
| 备用电池 | 2 节 7 号电池（每周换） |
| 充电线 | USB 线 1 根 |
| 编号 | **每个大厨固定一台，编号标记** |

### 4.2 使用流程

| 步骤 | 动作 | 责任人 |
|------|------|--------|
| 1 | 送餐前开机 + 录音笔放围裙口袋 | 大厨 |
| 2 | 全程录音（不开静音）| 大厨 |
| 3 | 送餐结束关机 + 交给院长 | 大厨 |
| 4 | 院长导入电脑 + 转写文字 | 院长 |
| 5 | 周会上播放录音 | 院长 |

### 4.3 录音内容分类标记

> 每段录音按以下标签分类：

| 标签 | 含义 | 后续动作 |
|------|------|----------|
| 🟢 **好评** | 老人明确说好吃 | 保持 |
| 🟡 **改进** | 老人说咸/淡/软/硬 | 调整菜谱 |
| 🔴 **剩菜多** | 老人不爱这道菜 | 替换或调整做法 |
| 🔴 **投诉** | 老人不满 | 立即处理 + 道歉 |

### 4.4 录音存档

| 项目 | 标准 |
|------|------|
| 存放 | 院长电脑 D 盘 / 食堂文件夹 / 年月日 |
| 转写 | AI 转写 + 关键句标注 |
| 保留期 | 3 个月（用于对比分析） |

## 五、🆕 周会复盘机制（核心）

### 5.1 周会安排

| 项目 | 标准 |
|------|------|
| 时间 | 每周一 14:00-15:00 |
| 参与人 | 院长 + 大厨 + 早餐岗 + 护理主任 |
| 地点 | 院长办公室 |

### 5.2 周会议程（60 分钟）

| # | 议程 | 时长 | 责任人 |
|---|------|------|--------|
| 1 | 上周菜品满意度回顾 | 5 min | 院长 |
| 2 | **🆕 录音笔播放与讨论** | 20 min | 院长主持 |
| 3 | 老人重点反馈（好评+投诉） | 10 min | 大厨回应 |
| 4 | 本周菜谱确认 | 5 min | 大厨 |
| 5 | 本周协作优化点 | 10 min | 🟢🔴 双方 |
| 6 | 院长总结 + 下周重点 | 10 min | 院长 |

### 5.3 🆕 录音播放 5 步法（核心会议环节）

| 步骤 | 时长 | 动作 |
|------|------|------|
| 1 | 2 min | 院长播放上周某段录音（**老人原声**）|
| 2 | 3 min | 大厨回应："老人说 X，我的理解是..." |
| 3 | 5 min | 团队讨论：怎么改进？ |
| 4 | 5 min | 决定行动项（菜谱调整/做法改进）|
| 5 | 5 min | 写入《下周菜谱优化表》 |

### 5.4 录音播放纪律

> **核心纪律**：**只放老人原声 + 团队讨论，不让大厨回避**

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 大厨不想听，直接跳 | 必须听，让老人原声说话 |
| 大厨为自己辩解 | 先听完整段，再让大厨回应 |
| 老人说"咸了"，大厨说"我故意咸的" | 必须承认 + 调整 |
| 录音有隐私内容 | 提前跟老人和家属说明 |

## 六、🆕 老人重点反馈分类处理

### 6.1 5 类反馈处理路径

| 反馈类型 | 处理路径 | 时限 |
|----------|----------|------|
| 🟢 **好评** | 大厨记录 + 保持 + 下周再做 | 周会 |
| 🟡 **咸淡软硬** | 当周调整 + 录音笔复盘 | 24h |
| 🔴 **不爱吃 / 剩菜** | 替换菜 + 找原因 | 3 天 |
| 🔴 **投诉（态度/卫生）** | 大厨当面道歉 + 院长跟进 | 立即 |
| 🔴 **特殊需求（糖尿病餐等）** | 单独做 + 标记档案 | 1 周 |

### 6.2 🆕 卧床老人专项反馈

> 卧床老人不会主动说 → 必须大厨**亲自喂 2-3 口**观察反应

| 步骤 | 动作 |
|------|------|
| 1 | 护理员协助翻身 |
| 2 | 大厨亲自喂 2-3 口 |
| 3 | 观察表情 + 录音笔录 |
| 4 | 喂完后看"剩了多少" |
| 5 | 反馈给护理员 + 院长 |

| 反馈 | 优化动作 |
|------|----------|

| 老人点赞某道菜 | **纳入"招牌菜"每周固定** |
| 卧床老人反馈 | **单独定制软烂版本** |

## 八、🆕 大厨与老人的"亲密感"建设

> **核心心法**："不是跟老人脱离，**下去别人再跟他说都不好使**"

### 8.1 大厨亲自送餐的 3 重价值

| 价值 | 说明 |
|------|------|
| 🟢 **获得直接反馈** | 老人原话 vs 护理员转述 |
| 🟢 **建立情感连接** | 老人认识"做饭的厨师" |
| 🟢 **倒逼服务意识** | 大厨看到剩菜=看到结果 |

### 8.2 🆕 大厨与老人的"小互动"

| 场景 | 互动 |
|------|------|
| 老人夸菜好吃 | 大厨："**谢谢阿姨**！这是我专门给您做的" |
| 老人不爱吃 | 大厨："**您喜欢什么口味？** 下次我给您做" |
| 老人过生日 | 大厨亲自做长寿面 |
| 节日 | 大厨端菜 + 跟老人合影 |

> **目标**：让老人知道"做饭的厨师"是个**有温度的人**，而不只是"厨房的陌生人"

## 九、🆕 与护理员的协作机制

### 9.1 护理员在反馈中的角色

| 角色 | 作用 |
|------|------|
| **日常反馈员** | 大厨不送餐时，护理员记录老人反馈 |
| **录音笔协助** | 大厨送餐时，护理员在旁边补充记录 |
| **周会参与者** | 提供本周老人反馈汇总 |

### 9.2 护理员反馈话术

| 场景 | 护理员话术 |
|------|------------|
| 老人不爱吃 | "阿姨，您今天菜没吃完，是不合口味吗？" |
| 老人有特殊需求 | "阿姨，您有什么想吃的吗？我跟大厨说" |
| 老人投诉 | "阿姨您别急，我马上跟院长反馈" |

## 十、🆕 录音笔会议机制的 3 大优势

| 优势 | 说明 |
|------|------|
| 🟢 **数据真实** | 老人原声，避免大厨"自我辩解" |
| 🟢 **团队共担** | 院长+大厨+早餐岗一起听，一起改进 |
| 🟢 **持续优化** | 每周都有录音 → 每周都有数据 → 每周改进 |

### 10.1 vs 传统反馈机制

| 维度 | 传统 | 🆕 录音笔机制 |
|------|------|--------------|
| 反馈渠道 | 护理员转述 | 老人原声 |
| 大厨参与 | 只听护理员转述 | **亲自送餐 + 录音笔全记录** |
| 复盘方式 | 口头说"老人说..." | **录音笔播放** |
| 服务意识提升 | 慢 | **🆕 倒逼快速提升** |
| 老人参与感 | 低 | 高（被尊重）|
