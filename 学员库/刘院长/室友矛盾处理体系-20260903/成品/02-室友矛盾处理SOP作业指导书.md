# 室友矛盾处理 SOP 作业指导书（V01 · 2026-09-03）

> 编制：刘院长 · 大盛代笔
> 适用范围：__________ 养老院全体老人 + 家属 + 护理员
> 核心心法：**老人间矛盾不是性格冲突，是"未被满足的需求"在不同人格上的投射**

---

## 一、为什么这件事难

| 难点 | 说明 |
|------|------|
| **满床无法调房** | 12 张床满，调房方案完全失效 |
| **30% 已能解决** | 现有疏导方式只能解决 30%，70% 尚无有效解 |
| **70% 核心** | 70%-80% 矛盾 = 争夺房间自主权（开灯/关电扇/电视音量）|
| **个性差异大** | 每个老人都是独特故事，统一方案行不通 |
| **家属联动难** | 老人情绪背后往往是家属关系 |

> **核心解法**：**先把老人按人格分类 → 再做精准匹配 + 精准疏导**

## 二、5 大老人人格分类体系

> 来源：刘院长 4 位真实案例 + 500 强企业性格互补组班模式

| 类型 | 代号 | 核心特征 | 行为表现 |
|------|------|----------|----------|
| 🟥 **强势控制型**（老虎）| 我说了算 | 控制欲强、爱挑剔、动不动"换掉你" | 跟护理员、老人吵架；频繁要求换房 |
| 🟧 **委屈索取型**（孔雀）| 你们都欠我 | 反复提"我付出了这么多"、对儿子/护理员"作" | 一旦被关爱就平静，否则就挑剔 |
| 🟦 **高傲孤立型**（老鹰）| 我比你们强 | 冷漠、拉拢护理员、看不起任何人 | 换 4-5 个室友都失败 |
| 🟩 **委屈失能型**（绵羊）| 我这么惨 | 失能 + 痛苦 + 看谁都不顺眼 | 反复"看不惯"他人、强依赖护理员 |
| 🟪 **平和顺从型**（兔子）| 配合型 | 温和、不挑剔、不抢资源 | 万能搭配（基准型）|

> **人格分类不是定性，而是为了精准匹配 + 精准疏导**。所有老人在不同时期可能呈现不同类型，需要动态评估。

## 三、入院评估 5 步法

### 第 1 步：入院前调研（家属 + 老人本人）

| 调查维度 | 内容 |
|----------|------|
| 职业背景 | 早年职业（如工会主席/教师/工人等）|
| 家庭角色 | "家里谁说了算？" |
| 性格自评 | "您觉得自己性格如何？" |
| 家属来访 | 哪些家属会来、频率、关系质量 |
| 特殊偏好 | 作息、饮食、社交、隐私 |
| **🆕 历史矛盾** | "之前是否跟同住的老人/护理员有过矛盾？为什么？" |

### 第 2 步：入院第一周观察（不打扰原则）

| 观察项 | 记录要点 |
|--------|----------|
| 作息规律 | 起床 / 就寝 / 用餐 / 活动 |
| 社交倾向 | 主动找人 / 喜欢独处 / 看电视 |
| 情绪波动 | 何时高兴 / 何时低落 / 触发点 |
| 跟护理员 | 配合 / 挑剔 / 依赖 |
| 跟同屋 | 互动频率 / 主动话题 / 摩擦点 |
| **🆕 房间自主权倾向** | 是否爱控制开关灯 / 电视 / 风扇 |

### 第 3 步：人格分类判定

| 判定信号 | 对应类型 |
|----------|----------|
| "我说了算"、"换掉你"、"我爱挑剔" | 🟥 强势控制型 |
| "我付出了这么多"、"你们都欠我" | 🟧 委屈索取型 |
| "我比你们强"、"你们啥也不会" | 🟦 高傲孤立型 |
| "我这么惨"、"这不对那不对" | 🟩 委屈失能型 |
| 温和、配合、不挑剔 | 🟪 平和顺从型 |

> ⚠️ **一个人可能有 2-3 种类型并存**，取**主导类型**。

### 第 4 步：精准匹配室友

#### 4.1 匹配铁律

| 优先级 | 规则 |
|--------|------|
| ⭐⭐⭐ | **绝对不把"两只要说话的"放一间** |
| ⭐⭐⭐ | **失能/失智老人优先配任何类型**（最安全）|
| ⭐⭐ | **强势 + 委屈 = 必炸** |
| ⭐⭐ | **高傲 + 委屈 = 必炸** |
| ⭐ | **平和顺从型 = 万能配** |

#### 4.2 匹配矩阵

| 当前老人 | ✅ 适合配 | ❌ 不能配 |
|----------|----------|----------|
| 🟥 强势控制型 | 🟪 平和顺从 / 卧床失能失智 | 🟥🟧🟦🟩 任何"会回应"的 |
| 🟧 委屈索取型 | 🟩 同样失能型 / 🟨  失智卧床 | 🟥 强势 / 🟦 高傲 |
| 🟦 高傲孤立型 | 🟨 失智卧床 / 安静卧床 | 🟧 委屈 / 🟥 强势 |
| 🟩 委屈失能型 | 🟪 安静温和 / 🟩 同样失能 | 🟦 高傲 / 🟥 强势 |
| 🟪 平和顺从型 | **任何类型都能配**（基准型）| — |

#### 4.3 满床状态下的"跨床互调"

> 刘院长院是 12 床小型院，满床后无法调房 → 用"跨床互调"方式

| 操作 | 适用情况 |
|------|----------|
| **A → B → C 三床循环** | A 跟 B 矛盾，B 跟 C 矛盾，C 跟 A 矛盾 → 互调后都和谐 |
| **失能老人做"缓冲床"** | 把失能老人放在两个强势老人中间（他们会"护"失能老人）|
| **半自理老人做"翻译"** | 半自理温和型老人配两个强矛盾型老人，做"润滑剂" |

### 第 5 步：1 个月试住期验证

|------|------|

| 第 2 周 | 每 3 天观察 + 主管评估 1 次 |

## 五、心理疏导 5 维技法

> **核心原则**：**不否定、不讲道理、不正面冲突**

### 5.1 5 大类型对应疏导策略

#### 🟥 强势控制型（老虎）

| 策略 | 具体动作 |
|------|----------|
| **不正面冲突** | 不批评、不讲道理，让她"掌控无关紧要的事" |
| **额外关爱补偿** | 比其他人多关注 10 分钟，让她感受"被独宠" |
| **替代控制源** | 给她"小管家"角色（管花草/餐厅窗台/卫生检查）|
| **家属沟通介入** | 院长跟儿子谈"每周至少来 1 次 30 分钟" |

**标准话术**：
- "李奶奶，您看这个窗台放什么花合适？您来定"
- "您是我们院的'老前辈'，新人还要靠您指点呢"
- "您儿子说很想您，每周都问您情况"

#### 🟧 委屈索取型（孔雀）

| 策略 | 具体动作 |
|------|----------|
| **不否定她的"委屈"** | "你付出了很多，我理解你" |
| **替代关注源** | 给她"专属时间"（不是区别对待，是固定时段）|
| **引导换位** | "他压力大，需要您的支持"（跟儿子沟通时）|
| **替代被关爱感** | 让她帮"美妆小组"管其他老人发型、穿着 |

**标准话术**：
- "张奶奶，您年轻时候一定很美吧"
- "您看您儿子虽然忙，但每月准时给您打钱，这是孝顺啊"
- "今天您跟孙子视频了没？我帮您安排"

#### 🟦 高傲孤立型（老鹰）

| 策略 | 具体动作 |
|------|----------|
| **承认他的"优秀"** | "南开大学的，确实了不起" |
| **给他"导师"角色** | 让他教其他老人念诗、读报 |
| **不正面反驳** | 不说"你错了"，说"您说的有道理" |
| **保持距离** | 不强行社交，让他"独处"也能舒适 |

**标准话术**：
- "孔老师（用尊称），您帮我们看看这篇报道怎么理解"
- "您有学问，帮我写一首诗贴在走廊"
- "您休息好，有事叫我"（保持距离的关心）

#### 🟩 委屈失能型（绵羊）

| 策略 | 具体动作 |
|------|----------|
| **承认她的痛苦** | "我知道你很疼，我听着都难受" |
| **听她倾诉** | 不打断、不建议、只是听 |
| **给她"被需要"感** | 让她分享"当年怎么养大孩子" |
| **不评价同屋** | "我理解你的感受"（不替任何人做裁判）|

**标准话术**：
- "赵奶奶，今天哪里最疼？我让护理员多帮您揉一下"
- "您年轻时真不容易，把孩子养这么大"
- "您跟儿子打个电话吧，我帮您拨"

#### 🟪 平和顺从型（兔子）

| 策略 | 具体动作 |
|------|----------|
| **保持温和** | 不特别干预，让她继续"平和" |
| **避免刺激** | 不把"强势型"放她隔壁 |
| **适当关爱** | 让她感受到"被关心"（基础关怀即可）|

## 六、满床状态下的 5 大应对策略（核心创新）

> **传统思路**：调房 → 但满床调不开
> **新思路**：**调"角色" + 调"心理预期" + 用"润滑剂老人"**

### 策略 1：跨床互调（A↔B↔C 三方循环）

| 场景 | 操作 |
|------|------|
| A 跟 B 矛盾，B 跟 C 矛盾，C 跟 A 矛盾 | 互调床位后**三方都和谐** |
| 例：A 嫌 B 吵、B 嫌 C 作、C 嫌 A 挑剔 | → A↔C、B 不动 → 全部重新评估 |

### 策略 2：失能老人做"缓冲床"

| 原理 | 操作 |
|------|------|
| 失能老人无法回应/评价/争吵 | 放在两个强势老人**中间**床位 |
| 两个强势老人面对"失能老人"会"护"他 | 形成"共同保护者" → 减少内耗 |

### 策略 3：温和半自理老人做"润滑剂"

| 原理 | 操作 |
|------|------|
| 平和顺从型（🟪）是万能配 | 放在任何"强矛盾"组合中间 |
| 充当"翻译 + 缓冲"角色 | 化解日常摩擦（如开灯/关电视）|

### 策略 4：活动分隔法（错峰使用公共空间）

| 原理 | 操作 |
|------|------|
| 矛盾老人不愿同处一室 | 错峰安排活动时间（如 A 上午活动、B 下午活动）|
| 不增加床位 | 用"时间错位"代替"空间错位" |

### 策略 5：心理疏导代偿（不调房调情绪）

| 场景 | 操作 |
|------|------|
| 完全无法调房 | 每周 2 次院长/主任专属谈心（30 分钟）|
| 用"深度理解"化解矛盾 | 把矛盾从"客观事实"转为"情绪发泄"出口 |

## 七、家属联动机制

### 7.1 家属沟通 4 个时点

| 时点 | 动作 |
|------|------|
| **🆕 入院第 1 周** | 院长 + 家属首次深度沟通（1 小时），了解老人历史 |
| **🆕 试住期满** | 反馈试住情况，邀请家属参与评估 |
| **🆕 矛盾升级时** | 24 小时内联系家属，告知情况 + 寻求配合 |
| **🆕 季度复盘** | 季度家属满意度调查 + 老人状态报告 |

### 7.2 家属分类与应对

| 家属类型 | 特征 | 应对策略 |
|----------|------|----------|
| 🟢 **高频关爱型** | 每周都来 | 配合护理、做老人"外援" |
| 🟡 **偶尔型** | 每月 1-2 次 | 主动邀请参与活动、加深联系 |
| 🟠 **低频型** | 每季度才来 | 每月电话汇报 + 紧急时主动联系 |
| 🔴 **缺席型** | 半年以上不来 | **院长亲自沟通**（找原因 + 谈责任）|
| 🟥 **挑剔型** | 频繁投诉/挑刺 | 院长定时定量沟通 + 公开处理 |

### 7.3 🆕 老人诉求传递机制

> **老人不愿说真话，但诉求需要被传递**——通过家属沟通传递

| 老人类型 | 家属沟通重点 |
|----------|--------------|
| 🟥 强势控制型 | "你儿子很想你，每周来看你 1 次" |
| 🟧 委屈索取型 | "你儿子虽然忙，但每月给你打钱是孝顺" |
| 🟦 高傲孤立型 | "你儿子很关心你，问我你最近怎么样" |
| 🟩 委屈失能型 | "你儿子重病也惦记你，让你安心住" |
| 🟪 平和顺从型 | 常规沟通即可 |

## 十一、30%-70% 矛盾解决路径

> **现有 30% 能解决**：轻度矛盾、口头调解
> **70% 难解决**：人格冲突、价值观对立、争夺自主权

### 70% 解决方案（按优先级）
