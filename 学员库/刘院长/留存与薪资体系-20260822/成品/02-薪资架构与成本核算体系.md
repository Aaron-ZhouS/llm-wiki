> 版本：V01 · 即日生效
> 适用：__________ 养老院全院

---

## 一、目的

**打破薪资大锅饭**，让员工收入与付出直接挂钩；
**控制人力成本占比**在合理区间，平衡盈利与人才吸引力；
**全维度核算**单床位成本，得出**最低收住定价规则**，避免"满床不盈利"的恶性循环。

---

## 二、薪资架构细化（打破大锅饭）

### 2.1 现状问题

| 问题 | 后果 |
|------|------|
| 高薪 + 福利体系 = 干好干坏差距不大 | 表现优秀的护理员产生不满 |
| 缺乏数据化评判 | 收入与努力脱钩 |
| 调薪靠院长感觉 | 员工争风吃醋 |

### 2.2 新薪资结构（基本 + 岗位 + 绩效 + 工龄 + 福利）

| 构成 | 占比 | 说明 |
|------|------|------|
| 基本工资 | 50% | 保底，7000-8000 元/月 |
| 岗位工资 | 15% | 白班 / 24h 班差异、护理师 / 培训师差异 |
| 绩效工资 | 20% | 基于月度评分（A+ 500 / A 300 / B 0 / C -200 / D -500）|
| 工龄奖 | 5% | 每年 +100 元/月 |
| 福利 | 10% | 带薪年假 / 节日福利 / 工龄奖升级 |

### 2.3 薪酬区间（7000-8000 元的拆解）

| 等级 | 基本 | 岗位 | 绩效 | 工龄 | 福利 | 合计 |
|------|------|------|------|------|------|------|
| A+ | 5000 | 800 | 500 | 视工龄 | 800 | 7100+ |
| A | 5000 | 800 | 300 | 视工龄 | 800 | 6900+ |
| B | 5000 | 800 | 0 | 视工龄 | 800 | 6600+ |
| C | 5000 | 800 | -200 | 视工龄 | 800 | 6400 |
| D | 5000 | 800 | -500 | 视工龄 | 800 | 6100 |

> 说明：实际到手 = 上述 + 加班费 + 节假日福利。**最低保障 6100，最高可达 7100+**，差距 1000 元，**干好干坏直接体现在工资条上**。

### 2.4 调薪规则

| 触发条件 | 调薪幅度 |
|----------|----------|
| 连续 3 个月 A+ | 基本 +200 / 岗位 +100 |
| 连续 6 个月 A+ | 晋升培训师 / 主管储备 |
| 连续 3 个月 C | 培训 + 调岗 |
| 连续 6 个月 C | 淘汰 |

## 三、人力成本占比控制

### 3.1 行业基准

| 机构类型 | 人力成本占比 |
|----------|--------------|
| 高端养老院 | 35-40% |
| 中端养老院 | 45-55% |
| 经济型养老院 | 55-65% |

> **刘院长目标**：**控制在 50-55%**（中端 + 高于周边薪资的平衡点）。

### 3.2 人力成本测算公式

```
人力成本占比 = 月度人力总成本 ÷ 月度总收入 × 100%
月度人力总成本 = 基本 + 岗位 + 绩效 + 工龄 + 福利 + 五险一金（机构部分）+ 加班 + 培训
```

### 3.3 控制策略

| 情况 | 应对 |
|------|------|
| 人力占比 > 55% | **暂停招聘** + 优先消化现有人员 + 提高入住率 |
| 人力占比 50-55% | **平衡态**，可小幅扩招 |
| 人力占比 < 50% | **可适度加薪 / 招储备人才** |

## 四、全维度成本核算（核心公式）

### 4.1 单床位月度成本

```
单床位月度成本 = （人力成本 + 伙食费 + 房租 + 水电费 + 设备折旧 + 物资消耗 + 管理费）÷ 总床位数
```

### 4.2 各项成本拆解

| 成本项 | 计算方式 | 备注 |
|--------|----------|------|
| **人力成本** | 全员薪资 + 五险一金（机构部分）+ 加班费 | 占总收入 50-55% |
| **伙食费** | 食材成本 + 人工 + 水电气 | 老人实际消耗 |
| **房租** | 月租金 ÷ 床位数 | 自有房产按折旧算 |
| **水电费** | 月水电费账单 | |
| **设备折旧** | （设备原值 - 残值）÷ 使用年限 ÷ 12 | 床位、医疗设备、康复器材 |
| **物资消耗** | 月度耗材 + 清洁用品 + 办公用品 | |
| **管理费** | 院长薪资 + 行政开支 | |

### 4.3 成本核算 Excel 模板（5 张表）

| 表 | 内容 |
|----|------|
| 表 1 | 全员月度人力成本明细 |
| 表 2 | 单床位成本拆解（按老人类型） |
| 表 3 | 月度总成本 vs 总收入对比 |
| 表 4 | 最低定价测算（按老人类型）|
| 表 5 | 季度复盘 + 调价建议 |

## 五、最低收住定价规则

### 5.1 定价公式

```
最低收住定价 = 单床位月度成本 × （1 + 目标利润率）÷ 入住率系数
```

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 单床位月度成本 | 实测 | Excel 表 2 自动算 |
| 目标利润率 | ≥ 15% | 低于 15% 容易亏损 |
| 入住率系数 | 0.85-0.95 | 满床 100% 不现实，留 5-15% 缓冲 |

### 5.2 三种老人类型的最低定价（示例）

> 假设：单床位月度成本 = 4500 元，目标利润率 20%，入住率系数 0.9

| 老人类型 | 照护难度系数 | 最低定价 | 建议定价 |
|----------|--------------|----------|----------|
| **自理老人** | 1.0 | 4500 × 1.2 ÷ 0.9 = **6000** 元/月 | 6000-7000 元 |
| **半自理老人** | 1.3 | 4500 × 1.3 × 1.2 ÷ 0.9 = **7800** 元/月 | 8000-10000 元 |
| **失能 / 失智老人** | 1.6 | 4500 × 1.6 × 1.2 ÷ 0.9 = **9600** 元/月 | 10000-15000 元 |

### 5.3 定价规则红线

- ❌ **禁止**低于"最低定价 90%"收住 = 亏损
- ❌ **禁止**为追求入住率压低自理老人价格（参考东北 2000 元案例）
- ✅ 严格按照护难度系数定价
- ✅ 划清"引流床位"和"盈利床位"比例（建议 3:7）

## 六、引流床位 vs 盈利床位

### 6.1 床位划分

| 类型 | 占比 | 定价 | 作用 |
|------|------|------|------|
| **引流床位** | 30% | 接近最低定价 | 拉新入住、引流 |
| **盈利床位** | 70% | 中高定价 | 覆盖成本 + 利润 |

### 6.2 配比原则

- 引流床位：**仅限自理老人**，价格压低到 6000-7000 元
- 盈利床位：**半自理 / 失能 / 失智老人**，价格 8000-15000 元
- **避免 100% 收住低价自理老人 = 满床不盈利**

---

## 七、东北养老院案例警示

> 某东北养老院数千平米，为提升入住率把老人收费压到 **2000 元/月**，完全没有盈利空间。
> 后果：
> ① 无法给护理员高薪 → 优质护理员流失
> ② 没有剩余床位接收高付费失智失能老人
> ③ 陷入"满床不盈利"的恶性循环
>
> **每家养老院都要制定专属运营策略，明确自身定位。**
