# 方案 1 · 员工离职真实原因挖掘系统（V02 · 2026-08-25 · 升级版）

> 编制：刘院长 · 大盛代笔
> 用途：先在刘院长自己院做试点 → 形成方法论 → 为其他养老院赋能
> 核心心法：**员工不会主动告诉你真话，要靠体系设计让真话自己浮出来**

## 🆕 V02 升级要点（vs V01）

| # | 升级点 | 原因 |
|---|--------|------|
| 1 | 离职原因从 4 类扩展到 5 类 | 新增"晋升通道不明确" |

## 一、为什么这件事难

| 难点 | 说明 |
|------|------|
| **员工不愿说真话** | 怕得罪领导 / 怕被报复 / 怕麻烦 |
| **离职面谈太官方** | 员工会说"家里有事"等套话 |
| **在职调查失真** | 在职员工不敢说，怕被针对 |
| **单点信息不完整** | 一个员工的话不等于真相 |

> 真相藏在：**多个渠道 + 多个时点 + 多个角色**的交叉印证里。

## 二、5 大离职原因分类（V02 升级）

> 在 V01 的 4 类基础上新增 E 类，并拆分 C 类。

| 类别 | 表现 | 根源 |
|------|------|------|
| 🟥 **A. 工资低** | 横向对比 300-500 元差距、福利差 | 薪资架构不合理 |
| 🟧 **B. 团队合作差** | 互相装听不见、推诿、补位不及时 | 三色规则 / 沟通机制缺失 |
| 🟨 **C1. 领导不公平** | 偏心、奖惩不一、晋升看关系 | 评判标准主观 |
| 🟨 **C2. 家属给压力/不尊重**（🆕）| 家属投诉/换人委屈、被家属辱骂、被家属针对 | **家属关系处理机制缺位** |
| 🟩 **D. 院长情绪专权** | 骂街、暴躁、唯我独尊 | 管理层培训缺位 |
| 🟦 **E. 晋升通道不明确**（🆕）| 看不到上升空间（护理员→组长→护理主任）| **职业发展路径缺失** |

### 🆕 C2 类详解：家属给员工的压力与不尊重

| 具体场景 | 员工感受 |
|----------|----------|
| 家属要求"换人"（无理由） | 委屈、被打标签 |
| 家属投诉员工（哪怕是合理诉求）| 委屈、被否定 |
| 家属辱骂员工 | 屈辱、心寒 |
| 家属给员工脸色、甩脸子 | 不被尊重 |
| 家属对老人态度差，员工夹中间 | 内耗、双面受气 |

> **C2 的特殊破坏性**：不像 C1（领导不公平）可以投诉 / 调岗，**家属是外部关系，员工只能忍**。多次累积后，员工最常见的离职念头就是"**我不想再受这个气了**"。

### 🆕 E 类详解：晋升通道不明确

| 现状 | 问题 |
|------|------|
| 只有"护理员"一个身份 | 没有成长感 |
| 没有组长 / 护理主任储备 | 优秀员工看不到未来 |
| 做得好与做得差工资差距小 | 干好没盼头 |
| 晋升标准不透明 | 努力不知道朝哪个方向 |

> **E 类的特殊破坏性**：员工**不是因为"现在不好"而离职，而是因为"看不到未来"而离职**。这是最容易被院长忽视的一类。

## 三、4 大维度挖掘方法（数据化三角验证）

### 维度 1：离职面谈（90% 都是套话）

**问题设计**：避免直接问"为什么离职"，改用**间接探针**：

| 问题类型 | 示例 | 目的 |
|----------|------|------|
| 回忆探针 | "回想一下，您刚入职第一天，最让您印象深刻的场景是什么？" | 暴露入职体验问题 |
| 对比探针 | "如果让您用一句话向朋友推荐这份工作，您会怎么说？" | 暴露不满点 |
| 反向探针 | "您觉得院里需要改进的一件事是什么？" | 引导提建议 |
| 假设探针 | "如果院长给你加 500 元工资，您还走吗？" | 试探金钱权重 |
| **🆕 家属探针** | "工作中有哪个瞬间让您觉得'不想再忍了'？" | **挖掘 C2 类（家属压力）** |
| **🆕 未来探针** | "您希望 3 年后自己是什么样的？" | **挖掘 E 类（晋升期待）** |
| 离开探针 | "您离开后，希望我们做哪一件事，让留下来的人更幸福？" | 引导真心话 |

### 维度 2：影子观察（员工不知情时的真实行为）

| 观察点 | 工具 | 时机 | 重点关注 |
|--------|------|------|----------|
| 三色响应执行 | 视频回放 + 巡查记录 | 每周 | B 类 |
| 互助/推诿次数 | 值班日志 + 互助响应表 | 每天 | B 类 |
| 同事评价 | 360 度匿名互评表（**核心工具**）| 季度 | C1 类 |
| **🆕 家属沟通记录** | 家属事件台账 | 每次发生 | **C2 类** |
| 跨班沟通频次 | 钉钉 / 微信沟通记录抽样 | 每月 | B 类 |
| **🆕 晋升话题主动询问** | 1v1 谈心记录 | 每月 | **E 类** |

### 维度 3：数据画像（用数字替代感觉）

| 指标 | 公式 | 含义 | 关联类别 |
|------|------|------|----------|
| 月度评分 | 5 维量化分数 | 是否感受到公平 | C1 类 |
| 奖金差异 | A+ 与 D 员工收入差 | 大锅饭程度 | C1 类 |
| 工龄奖发放 | 实际发放人数 | 长期认可度 | C1 类 |
| 排班公平度 | 夜班天数 / 周末天数方差 | 排班是否偏心 | C1 类 |
| 投诉次数 | 月度投诉数 | 家属关系紧张度 | C2 类 |
| **🆕 家属投诉后员工流失率** | 投诉后 90 天内离职 / 投诉总数 | **家属事件对员工的影响** | **C2 类** |
| **🆕 晋升储备覆盖率** | 已培养储备人数 / 关键岗位数 | **晋升通道健康度** | **E 类** |
| **🆕 培训师留存率** | 在岗培训师 / 任命培训师 | **晋升通道吸引力** | **E 类** |

### 维度 4：离职后 1 个月回访（真相窗口）

> **离职后 30 天回访** = 员工卸下防备后，最愿意说真话

| 问题 | 目的 | 关联类别 |
|------|------|----------|
| "现在的工作对比上一家，您最大的感受差异是什么？" | 对比暴露真相 | 全 |
| "如果上一家能改一件事，您愿意回去吗？" | 离职意愿度 | 全 |
| **🆕 "您印象最深的一次家属冲突是什么？怎么处理的？"** | **C2 类深挖** | **C2 类** |
| **🆕 "如果院里给护理员加了组长晋升通道，您会留下吗？"** | **E 类意愿测试** | **E 类** |
| "您推荐朋友来上一家吗？为什么？" | 推荐意愿（NPS）| 全 |

## 四、3 类访谈角色（三角验证）

| 角色 | 数量 | 用途 |
|------|------|------|
| **离职员工本人** | 1 人 | 直陈原因（多套话）|
| **同岗位同事** | 2-3 人 | 印证推诿 / 团队合作 |
| **跨岗位同事** | 1-2 人 | 印证沟通 / 领导风格 |

> **同一件事，至少 2 个角色互相印证**才采信。

## 五、C2 类（家属压力）专项应对机制（🆕）

### 5.1 3 条铁律

| # | 铁律 | 目的 |
|---|------|------|
| 1 | **院长必须为员工撑腰**（哪怕家属是对的）| 员工需要"有人给我撑腰"的安全感 |
| 2 | **公开处理 + 私下安抚** | 既不让员工寒心，也不让家属觉得不受重视 |
| 3 | **家属投诉员工时，院长先跟员工单独谈**（不直接当着家属面批评员工）| 避免员工当场下不来台 |

### 5.2 家属事件处理 SOP（5 步）

| 步骤 | 动作 | 责任人 |
|------|------|--------|
| 1 | 家属提出投诉/换人/辱骂 | 当事员工 → 立即通知院长 |
| 2 | **院长单独安抚员工**（不当面批评）| 院长 |
| 3 | 院长与家属沟通，处理诉求 | 院长 |
| 4 | 院长事后复盘事件，写入《家属事件台账》| 院长 + 主管 |
| 5 | **持续观察当事员工状态 30 天** | 主管 |

### 5.3 家属事件分级

| 级别 | 情形 | 处理 |
|------|------|------|
| 🟢 轻 | 家属提建议、不满但理性 | 主管接待，员工旁听 |
| 🟡 中 | 家属要求换人、投诉员工 | 院长接待，员工不直接参与 |
| 🔴 重 | 家属辱骂员工、人身攻击 | **院长当场制止 + 报警（如需要）+ 员工心理疏导** |

## 六、E 类（晋升通道）专项建设（🆕）

### 6.1 双通道晋升体系

> **护理员** 不是"一辈子只做护理"，而是**有两条成长路径**：

| 通道 | 路径 | 适用人群 |
|------|------|----------|
| **🟦 管理通道** | 护理员 → 组长 → 护理主任 → 院长储备 | 想带人、有管理意愿 |
| **🟩 专业通道** | 初级护理员 → 中级 → 高级 → 培训师 | 想深耕技术、不想管人 |

### 6.2 晋升标准（透明化）

| 级别 | 月度评分要求 | 必备条件 | 配套权益 |
|------|--------------|----------|----------|
| **初级护理员**（入职 0-3 月）| B 以上 | 通过试岗 | 基础薪资 |
| **中级护理员** | A 连续 3 月 | 通过中级考核 + 带教过 1 名新人 | +200 元 + 月度奖金 |
| **高级护理员** | A 连续 6 月 | 通过高级考核 + 输出 ≥ 3 条 SOP | +500 元 + 培训师津贴 |
| **🟦 组长** | A 连续 3 月 | 通过组长培训 + 主管评价 ≥ 4.5 | +800 元 + 月度管理津贴 |
| **🟦 护理主任** | A 连续 6 月 | 通过主任培训 + 院长评价 ≥ 4.5 | +1500 元 + 绩效分成 |
| **🟩 培训师**（专业通道）| A+ 连续 3 月 | 通过培训师考核 + 带出 3 名达标学员 | +500 元/月 + 学员达标奖金 |

### 6.3 晋升通道公示与沟通

| 时点 | 动作 |
|------|------|
| **入职培训时** | 院长亲自讲"两条路都能走" |
| **每月发工资日** | 1v1 谈心问"你的下一步是什么？" |
| **每季度** | 公布"晋升候选人名单"（透明化）|
| **晋升发生时** | 公开仪式 + 月度明星墙 |

## 七、流失率预警模型（V02 升级）

### 7.1 6 类预警信号

| 信号 | 监测方法 | 预警阈值 | 关联类别 |
|------|----------|----------|----------|
| 月度评分持续下滑 | 评分表 | 连续 2 月 < 75 | C1 类 |
| 投诉次数上升 | 投诉记录 | 月环比 +50% | C1 类 |
| 请假 /迟到增加 | 考勤 | 月环比 +30% | 多类 |
| 同事互评低分 | 360 表 | < 3.5/5 | B 类 |
| **🆕 家属事件后 7 天异常** | 家属事件台账 | 当事员工评分/出勤下滑 | **C2 类** |
| **🆕 主动询问晋升次数** | 1v1 谈心记录 | 月内 ≥ 3 次 | **E 类** |

### 7.2 立即介入动作

| 信号 | 介入动作 |
|------|----------|
| 月度评分 < 75 | 院长 1v1 谈话（不超过 7 天）|
| 投诉上升 | 主管即时访谈 + 改进计划 |
| 请假异常 | 关注是否家事 / 心理问题 |
| 同事评价低 | 排查团队氛围 + 个人问题 |
| **家属事件后 7 天异常** | **院长 1v1 谈心 + 必要时调岗** |
| **主动询问晋升 ≥ 3 次** | **正式纳入储备 + 安排专项培训** |

## 八、离职原因分析报告模板（V02 升级）

每月出一份《离职原因分析报告》，结构如下：

```
1. 本月离职概况（人数 / 占比 / 工龄分布 / 5 类原因占比）
2. 5 类原因 TOP 占比（含 🆕 C2、E 子项）
3. 重点案例（C2 家属投诉导致离职、E 看不到未来离职）
4. 三角验证结论（哪些原因被 ≥ 2 个角色印证）
5. 已落地改进措施（本月已做了什么）
6. 下月重点改进（针对 TOP 1 原因）
7. 🆕 晋升储备进度（候选人名单 + 培训计划）
8. 预警名单（下月可能离职的 3-5 人 + 介入计划）
```
