# 我把自己这两年的总结读了三遍，把"打造个人 IP"拆成 4 件事

上周我把自己两篇文章反复读了三遍。

第一篇讲"打造个人 IP"——做 IP 的底层认知，三色、内容四层、必须学会说不。

第二篇讲"降低创作门槛"——从录音到短视频，从 flomo 到 Notion，从完美主义到先做后做。

这两篇如果分开读，是两个独立的命题。

但合在一起——**它们其实是同一件事的两面**：

> 上篇告诉你 IP 是什么。
>
> 下篇告诉你 IP 怎么开始。

这周陪跑营又有人在群里问：

> 老师，我学了一堆方法论，知道底色、本色、专业色了。
>
> 知道内容分四层了。
>
> 知道得学会说不。
>
> **但我还是没开始拍第一条。**

这才是真问题。

**知道和做到之间，隔着一道"还没开始"的鸿沟——这一道鸿沟比 10 套方法论加起来都重。**

> **你收藏这篇文章，** 不代表你能不能做到。
>
> **你看完这篇文章，** 不代表你能不能做到。
>
> **你今晚拍一条 30 秒视频发出去，**——这才代表你做到了。

**这次我提"4 件事"，不是"4 个知识点"——而是 4 件你今天能做的小事。**

每件事配：
- 大我怎么说的（原文要点）
- 我怎么理解的（我的解读）
- 我自己这一年怎么做的（真实案例）
- 你今天能做的一个小动作

**学完你立刻能开始。**

## 第 1 件事：搞清楚你的三色

我去年写过的一篇：

> "很多人老伙计都想打造个人 IP，但不要对标我。以我为对标？很可能连第一步都迈不出去。每个人都必须找到独属于自己的起点和成长轨迹。"
>
> "打造个人 IP，首先你要知道自己是谁。不是说你表演个什么样的人给人看，那样会非常累；而且早晚会露馅。最好从你自身出发。哪一部分通过互联网去放大。"
>
> "你可以从自己的三色：底色、本色和专业色开始。"

### 三色是什么

我给的三色框架——我按我自己的理解重写一遍：

| 色 | 是什么 | 决定了什么 | 比喻 |
|---|-------|-----------|------|
| **底色** | 三观：世界观、人生观、价值观 | **吸引谁** | 你的"人格重力"，跟你同频的人会被你吸引 |
| **本色** | 经历 + 个性 | **谁会跟你** | 你的"人味"，决定了别人愿不愿意继续跟你 |
| **专业色** | 专业知识和技能 | **入口在哪** | 你的"敲门砖"，决定了别人通过什么认识你 |

### 三色的关系

我之前写过的话里给得很清楚：

> "专业色是吸引人的入口，本色让人留下，底色让人围绕在你身边。"

这句话是核心——

> 三色不是平行关系，是**漏斗关系**。

也就是说：

> 你以为只要"专业色够强"就能做 IP？
>
> **错。**
>
> 入口是专业色没错，但人家来了之后是看本色的（你这个人有没有意思），最后是看底色的（你这人能不能跟）。

### 我给的"启动信号"

我那篇文章最后给了一段话：

> "**真正的定位不是说"我是干什么的"**。定位要明确：自己的底色、本色、专业是什么，通过什么与受众建立长期连接，别人为什么被你吸引。"
>
> "你必须思考自己能提供什么类型的内容——信息、知识还是洞见。这又和你的世界观、人生观和价值观有关。你是谁？你要成为什么样的人？你要去哪儿？怎么去？"
>
> "从自己当下正好可以做的事开始，养成习惯；然后每天进步一小步，才是长久之道。"

### 我自己的三色（一年前）

我一年前开始做"周盛说"的时候，**也不知道自己三色是什么**。

后来我按这个方法反推：

| 色 | 我的答案 |
|---|---------|
| **底色** | 45 岁 / 通勤 5h / 一人公司 / 反对"打工逻辑" |
| **本色** | 工程师老兵 / 喜简洁 / 反对阿谄 / 喜欢拆掉花哨方案 |
| **专业色** | AI 副业 + 一人公司 + 视频号 + 知识管理 |

为什么这三色有力量？

因为**它们是一套的**——

> 45 岁想搞一人公司（底色），所以需要 AI 副业工具（专业色）。
>
> 工程师喜简洁（本色），所以喜欢"每天写点什么"类的工作流（专业色）。
>
> 通勤 5h（底色），所以坚持用手机录音+地铁上写（本色）。
>
> 反对阿谄（本色），所以反对"AI 一夜暴富"的方案）。）

**三色相互递归，互相加固——这就是"真实 IP"的样子。**

### 你今天能做的小动作

**拿出一张纸，写 3 个答案**：

| 问题 | 我的答案（至少 30 字）|
|------|---------------------|
| 底色：我是谁？什么世界观？|
| 本色：我经历过什么？我这人有什么特点？|
| 我的专业色：我有什么技能？我帮别人解决什么问题？|

**然后自查**：

- 三个答案能互相递归吗？
- 还是三个独立的？
- 如果是独立的 → 重写选一个，因为真正的 IP 是"三色递归"

> 三色**独立** = 你在演 IP。
>
> 三色**递归** = 你是 IP。

## 第 2 件事：搞清楚你的内容在哪一层

我之前写过的话：

> "内容可以分四层，它决定你能走多远。"
>
> "**第一层是信息**。比如某部门的最新通知、财经资讯。这类内容流量大但粉丝粘性低。"
>
> "**第二层是知识**。教人如何做事——读书方法、拍摄技巧、知识库建立。知识类内容更容易留住粉丝。"
>
> "**第三层是洞见**。帮助人们思维的。比如世界观、人生观和价值观。不容易让人理解是必然的，尤其在娱乐平台更是如此。但这一类视频的用户黏度极高。"
>
> "**第四层是"我是谁"——你想成为什么样的人。** 这个层次极其深刻，能达到这水平的创作者凤毛麟角。"
>
> "不同层次的内容会带来不同结果：信息类创作者，流量大，但留存差；知识类创作者更容易变现，但很难产生长期连接；洞见类创作者最容易成为 IP。"

### 一张图看清四层

```
   ↑
        ┌──────────────────────────────────────┐
   I    │ 我是谁                            │ 真正稀缺的层
        │ ─────────────────── │
   I    │ 洞见（世界观 / 价值观）│ │
        │ ─────────────────── │
   I    │ 知识（方法 / 教程）│ │
        │ ─────────────────── │
   I    │ 信息（消息 / 资讯）│ 99% 的人在这 │
        └──────────────────────────────────────┘
```

### 三层最关键的动作

| 层 | 关键动作 |
|---|---------|
| 信息类 | 不要做"最快知道"型频道（财经新闻、AI 资讯速递）——你拼不过 RSS |
| 知识类 | 把方法论固化成 SOP、清单 —— 学员能拿走能复用 |
| 洞见类 | 不需要追热点 —— 你的洞见就是热点 |

### 我说过为什么洞见类强

我之前写过的话里给了一句特别扎心的话：

> "洞见类创作者最容易成为 IP。他们能跨领域分享内容——无论是产品、营销还是育儿都能吸引用户，因为他们分享的是思考方式而非单纯信息或者技巧。"

这句话我读了 5 遍——

> 也就是说，**洞见类创作者不是"一个赛道的专家"，是"一种思考方式的传播者"**。

### 我自己的内容层定位

我做"周盛说"一年了，现在我的内容层定位是：

| 层 | 我的占比 |
|---|---------|
| 信息类 | 5%（不做日常资讯） |
| 知识类 | 30%（SOP 类、AI 工具类） |
| 洞见类 | **60%**（一人公司逻辑、AI 副业思考、抗失败知识） |
| 我是谁 | 5%（偶尔的"我这一年最深的认知"） |

**这两年我的视频号爆款，几乎全是"洞见类 + 我是谁"的混合**。

为什么？

因为**洞见稀缺 + 我是谁稀缺 → 没人能复制**。

### 我复盘这一年爆款最多的内容

| 主题 | 播放量 | 属于哪一层 |
|------|--------|----------|
| 多开一个号三个都死 | 高 | 洞见 |
| 赚钱的四步 | 高 | 洞见+知识 |
| 普通人赚钱地图 | 高 | 洞见 |
| AI 上下文配置工程 | 中 | 知识 |
| 黄金三秒+干货+金句 | 高 | 知识+洞见 |

**爆款都是洞见+知识的组合**。纯信息类几乎没爆过。

**拿出一张纸，列出你最近 10 条内容**：

每条对应到四层中的哪一层？

|---|---------|---------|
| 1 | | |
| 2 | | |
| ... | | |
| 10 | | |

**统计每层占比**——

- 信息 > 50% → 转型
- 知识 > 70% → 加洞见比例

- 我是谁 > 10% → 顶级

## 第 3 件事：必须学会说不

我之前写过的话：

> "**要学会说"不"**。不要总是顺从别人。顺从的人怎么做 IP？"
>
> "**你不可能因为比别人更具有服从性而获得成功。**"
>
> "一旦有一天你不满足他们，你就完蛋了。拒绝会让一些人取关你，也因此会让另外一些人关注你，要敢于表明自己的立场。从这一点上，**很多人是做不了 IP 的**。他们顺从惯了。"

### 这段话为什么重要

这段话是给我拍醒的。

我一年前刚开始做的时候——

> 学员问我"老师能不能教我剪映"——我说"行"。
>
> 学员问我"老师能不能讲讲小红书"——我说"行"。
>
> 学员问我"老师能不能做付费课"——我说"行"。
>
> 结果——**啥都没做起来**。

为什么？

因为**我是个顺从的 IP**——

> 谁问我就做啥。
>
> 谁不喜欢我我就改。
>
> 谁退群我就焦虑。

**这不是 IP，这是客服**。

### 我说的"必须学会说不"

我说得很清楚——

> 你敢说"不"，**一部分人会离开你**。
>
> 你敢说"不"，**一部分人会因为你**——

**留下来看人不是因为喜欢你，是因为认同你**。

这是为什么我现在的学员库——

> 留下来的，几乎都是"喜欢我反对阿谄、喜欢真实、喜欢反对花哨方案"的那些人。

**他们不是因为喜欢我，是因为他们**。

### 我后来怎么学的说不

我有 3 条原则：

| 原则 | 怎么做 |
|------|------|
| **不做的清单**| 我列出"不做的事"——小红书不做、矩阵号不做、付费课程不做、剪映教程不做 |
| **拒绝话术** | "这个我不擅长，你找别人"或"这不是我的赛道" |
| **不解释** | "不能被接受就走人，不挽留" |

**这三条原则让我从"客服"变成了"真的做一人公司的人"**。

- 哪个朋友的合作你不想做？
- 哪个付费课程你不想买？

**今天拒绝 1 件**——就算"拒聊"也可以。

## 第 4 件事：先做，再做好

我之前写过的话（"降低门槛"那篇）：

> "用手机随时记录想法。看到好文案、有灵感时立即录下来。好的留下，不好的删掉。通过 AI 整理成文字，建立素材库。"
>
> "**但这不是重点。**"
>
> "我写《价值心法》时，有一章改了 4、5 稿。"
>
> "**降低门槛**：原标题"如何写作"→ 改后"每天写点什么"。差别在哪？写作门槛高，让人望而却步。写点什么降低门槛，写了就算。更多人愿意尝试，反而写出好东西。"
>
> "我们生活在短视频时代。应该养成更好的习惯：**不是录音，而是直接拍短视频**。"
>
> "**这是记录方法，不是为了发表。**"
>
> "**只要没"发出去"，你就是极度放松的。**"
>
> "为什么很多人拍不了短视频？画画都会画，画个圆、画个房子。但说"开始画画"，他就不会了。为什么？因为他觉得必须画得特别好。画不好就不敢画，不敢画就永远不会画。"
>
> "**最好的方法：画个方、画个圆，能表达清楚就行。先画，画多了自然就好了。**"
>
> "**真实才有力量。**"

### 这段话是我这一年最拍醒我的

我说"如何写作"改成"每天写点什么"——

**一字之差，门槛减半**。

我以前写小报童，每次想"标题写多高大上"、"开头写多勾人"。

**结果就是每次想半小时、一小时还开不了头**。

直到有一天我改了一个目标：

> "今天写 500 字，不发出去。"

**结果 30 分钟就写完了 800 字**。

为什么？

因为**不发出去 = 不怕写错**。

### 我给的完整工作流

我给的从"录音"到"成片"的工作流：

```

↓ 转入 Notion

↓ AI 加工（提示词 1）

↓ AI 加工（提示词 2）

```

这套工作流的要点：

| 阶段 | 用什么 |
|------|-------|
| 灵感 | iPhone 功能键 → flomo 语音 |
| 整理 | Notion 加工（消化过的知识）|
| AI 辅助 | 两个 AI 提示词（下面列）|
| 拍摄 | 手机开拍 |

### 两个 AI 提示词（我原文）

**提示词 1：语音转文字加工**

> "我将提供一份语音转录的文字稿，请你对其进行润色，使其更易于阅读。我提供的格式是：`<文字稿开始>{文字稿}<文字稿结束>` 你只需返回润色后的文字稿，无需包含以上的标记。
>
> 请遵守以下要求：
>
> 1. **修正口语中可能的错误**。因为是人说的话，会比较随意，可能会有语法错误，你需要进行修正。
>
> 2. **修正转录错误**。发音相近的词，如果你认为语音转文字可能转录错误，不符合语境，替换为使整体逻辑更正确的词。
>
> 3. **保留语言风格**。保留说话人的语言风格，不要大幅改动。使用口语化的短句，降低阅读负担。
>
> 4. **保留所有要点**。用短小和简洁的句子重述，并去掉所有轻量的语气词或过渡词汇。在句子级别重述，不对整体内容进行总结或简化。如果有多个要点，用 markdown 列表来排列，不要使用加粗。
>
> 5. **保持语种一致**。输出时，不要变更文字稿的原始语言。
>
> 6. **结构清晰，易于阅读**。每个段落最多包含 4 句话。超过 4 句时，使用换行另起一段，以增强可读性。
>
> 7. **不需要润色的情况**。如过于简短，或已经符合全部要求，就返回原文。"

**提示词 2：口播初稿生成**

> "你是一位擅长提升脚本参与度的短视频内容创作专家。根据我提供的内容，帮我将其转化为一篇引人入胜的短视频口播脚本，并遵循已被验证的爆款内容心理学原则。"
>
> **您的流程**：
>
> **首先，分析原始内容以识别**：
> - 目标受众的核心痛点
> - 提供的独特解决方案
> - 关键数据点或令人意外的事实
> - 能与观众共鸣的情绪触发点
>
> **接着，基于以下心理学原则来打造脚本**：
>
