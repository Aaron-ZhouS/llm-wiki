# 知识库不是仓库，是弹药库

这周陪跑营，一个学员问我三个问题。

**连着问的。**

> 老师，我的公众号文章和短视频的解决方案，从哪里来？
>
> 我的经验怎么总结？
>
> 我做实体business，怎么收集客户的信息和痛点？

**这三个问题，我一句一句回答他。**

但答完之后，我意识到——**他问的不是三个问题，是一个问题。**

> **"我的弹药库是空的，我拿什么上战场？"**

---

## 先说一个我自己的体会

我是干了十几年程序员出身。

**做系统的时候有一条铁律：**

> **再好的架构，喂进去的是垃圾，出来的还是垃圾。**

**这就是我今天要讲的第一件事：**

> **你的知识库不是仓库，是弹药库。**
>
> **仓库只管存，弹药库只管一件事——让你打准。**

**打个比方。**

**你的 AI 工具 = 武器。**
**你的知识库 = 弹药。**
**你的自媒体平台和实体门店 = 战场。**

**结果 = 你能不能打中。**

**现在大部分老伙计的处境是：**

> **枪是好枪——AI 工具你玩得比谁都溜。**
>
> **但弹药库是空的。**
>
> **所以每次扣扳机，打出来的都是空气。**

**这不是你的错。是没人告诉你弹药从哪来。**

---

## 一、先回答学员那三个问题

我们回到刚才那三个问题。一个一个拆。

### 问题 1：我的公众号文章和短视频的解决方案，从哪里来？

**答案：从你每天真实处理的问题里来。**

不是从"AI 给我推荐 10 个选题"里来。

**我陪跑营有个学员叫文姐。**

她做个人 IP，化疗掉光了头发，一个人孤孤单单去治疗，那时候整个人没自信。

学完 AI 助手和 Obsidian 知识库之后，她做了一件事：

> **建了一个痛点清单素材库。**
>
> **然后"每天有拍不完的素材"。**

**注意这 8 个字——"拍不完"。**

**她不是更努力了，她是弹药库满了。**

**所以选题不是"想"出来的，是"挑"出来的。**

> **她从"每天重新想选题"，换成了"每天从表里挑一个"。**
>
> **开放题变成封闭题，人就敢动手了。**

### 问题 2：我的经验怎么总结？

**答案：把经验变成"卡片"，别让它烂在脑子里。**

我自己的知识库有 4 条铁律，一张卡片必须过这 4 条：

| 铁律 | 意思 | 不通过的例子 |
|------|------|-------------|
| **原子性** | 一张卡只讲一件事 | "如何做好销售+管理+招聘" |
| **可行动** | 读完能直接指导行为 | "销售要用心" |
| **可证伪** | 能说出"这卡什么时候失效" | 红灯写"看情况" |
| **诚实性** | 绿灯必须来自真实经历 | 绿灯写"任何场景" |

**第二条最关键。**

**"销售要用心"不是知识，是废话。**

**"客户说太贵的时候，先问他在跟谁比"——这才是知识。**

因为它能直接指导你下一次跟客户怎么聊。

### 问题 3：我的实体业务怎么收集客户信息和痛点？

**答案：建"痛点清单"，从客户嘴里挖。**

**这一步是实体老板最容易忽略的，也是最值钱的。**

我陪跑营有个学员叫芳姐。

**她做了一份高质量的痛点清单。**

这份清单她迭代过很多次——**她自己都记不清是几次了。**

后来她的 AI 智能体帮她把过程翻了出来：**一共迭代了 6 次还是 7 次。**

现在她说，**她完全可以把这份痛点清单当成一个产品来做了。**

而且她已经开始拍视频了。

**为什么痛点清单这么关键？**

> **因为痛点清单是"客户的原话"，不是"你的猜想"。**
>
> **客户原话 = 天然的内容选题 + 天然的产品需求 + 天然的成交话术。**

**一份痛点清单，能同时喂饱：**

| 用途 | 怎么用 |
|------|--------|
| **短视频选题** | 客户最痛的那一条，就是最扎人的钩子 |
| **公众号文章** | 一个痛点 = 一篇文章的结构 |
| **产品设计** | 客户反复提的 = 你该做的东西 |
| **成交话术** | 客户自己的话，说服力最强 |

**这就是"一份弹药，四种射击"。**

## 二、弹药库长什么样：三层结构

很多老伙计一听"知识库"就以为是个大工程。

**不是。**

**弹药库只需要三层。**

```
┌─────────────────────────────────────────┐
│  第一层 · 灵感库（弹药原料）              │
│  = 让你不舒服的那个问题                   │
│  → 入口触发                            │
├─────────────────────────────────────────┤
│  第二层 · 痛点清单 + 经验卡（成品弹药）    │
│  = 客户原话 + 你的真实案例                │
│  → 验证加工                            │
├─────────────────────────────────────────┤
│  第三层 · 内容输出（发射）               │
│  = 短视频 / 公众号 / 产品                 │
│  → 认知演进                            │
└─────────────────────────────────────────┘
         ↓ 反馈回流
    （新的问题 → 新的灵感）
```

### 第一层 · 灵感库：不是收藏夹，是让你不舒服的那个问题

**这一层的定义很反常识，我一开始也不适应。**

灵感库 = **灵感触发后，还没想透、还没验证的笔记。**

**不是"收藏夹"，不是"待办"，不是"有用的东西先存着"。**

**是：让你不舒服的那个问题。**

**进这个库，必须满足至少一条：**

- 这个观点我不认同，我要说出来
- 这个东西我以为懂了，但讲不清楚
- 这个现象让我困惑，没有简单解释
- 这个旧认知最近被动摇了

**你看出来了吗？**

**这 4 条全是"卡住"的感觉，不是"学到了"的感觉。**

**所以灵感库不是仓库，是"问题池"。**

**然后是出库规则——强制，两周内必须处理：**

> **门禁四问**
>
> 1. 我能在 10 秒内说出这个观点的反例吗？
> 2. 它能同时解释 A 和 B 两个不相干现象吗？
> 3. 讲给一个比我聪明的人听，对方会质疑哪里？
> 4. 我之前有没有讲过类似的？这次新在哪？

**通过 → 提炼成卡 → 输出**
**没通过 → 删掉**

**这一条我要特别强调：**

> **超过两周没处理的笔记 = 直接删，不可惜。**

**为什么？**

**因为灵感库一旦变成"收藏夹"，它就死了。**

**一个装满旧想法的库，不如一个空的库。**

> **库里干净 = 脑子干净。**

### 第二层 · 痛点清单 + 经验卡：真正的成品弹药

**这一层是弹药库的主体。**

**痛点清单怎么建？** 我给一个能直接用的模板：

**第一步：把客户最常问你的问题全部列出来（至少 20 条）**

不要修饰，不要总结，**就写客户原话**。

比如养老院院长会问：

- 护理员之间老有矛盾，怎么管？
- 新人来了三个月还是干不好
- 我该怎么留人
- 这个月流水又掉了

**第二步：按"我能不能解决"分两类**

| 分类 | 处理方式 |
|------|---------|
| **我能解决的** | → 进痛点清单（这就是你的选题库 + 产品库）|
| **我解决不了的** | → 记下来，等你有能力了再处理 |

**第三步：给每一条标上"我解决过吗"**

- 解决过的 → 写上你的具体做法（**这就是经验卡**）
- 没解决过的 → 留着，这就是你下一个要学的东西

**痛点清单的杀伤力在哪？**

> **它是"别人的需求"，不是"你的表达欲"。**
>
> **用别人的需求做内容，转化率比用自己想说的话高一个量级。**

我陪跑营另一个学员叫云姐，公众号作者。

原来发一篇要 3 小时，搭了工作流之后 30 分钟搞定一周 7 篇，单篇浏览几千到一两万。

**但她说了一句很扎心的话：**

> **"流量不错，但没变现。"**

**为什么？**

**因为她只有"知识弹药"，没有"痛点弹药"。**

**她知道很多方法，但不知道"她的读者现在最痛的是哪一条"。**

**所以她要补的就是痛点清单这一层。**

### 第三层 · 内容输出：发射

有了前两层，第三层就顺了。

**短视频**：从痛点清单挑最痛的一条 + 你的真实经历
**公众号**：3-5 张经验卡 + 1 个完整方法
**产品**：痛点清单里反复出现的那一条

**——这跟上一篇讲的"洞见卡三条路径"是一回事。**

**上一篇讲的是"知识怎么变成内容"。**

**这一篇讲的是"弹药怎么进库"。**

## 三、AI 工具怎么接进来：不是替代你，是当你的副手

**先纠正一个误解：**

> **AI 不是你的思考者。AI 是能读你文件夹的助手。**

**一句话说清三者关系：**

```
知识库 = 目录（里面是 Markdown 文件）
Obsidian = 看这个目录的软件
AI = 能直接读这个目录的助手
```

**为什么必须是 Markdown？**

**因为它是纯文本——任何软件都能打开，不会像 Word 或 Notion 那样把你锁死。**

**更重要的是，AI 读纯文本不需要转换，打开就能理解。**

**这是"你的知识库属于你"的底层保障。**

### 两条连接路线

**路线 A（命令行，推荐）：用 Claude Code / Hermes Agent / Codex**

**它们直接操作你电脑上的文件夹。**

你把每个目录的用途告诉它一次，它就记住了。

以后你说"帮我找一下去年那个项目里关于 XX 的内容"，它自己去目录里翻，不用你手动找文件。

**为什么推荐这条？**

> **因为它不是一个独立的聊天窗口，而是能连到你文件的助手。**
>
> **图形界面工具往往只能把你粘贴进去的信息存在它自己的数据库里——那和你的本地目录是两套东西。**
>
> **命令行工具直接操作你的文件本身，没有中间层。**

**路线 B（图形界面）：用 WorkBuddy / QClaw / QoderWork CN**

**装好就能用，不用敲命令，门槛更低。**

**选一个就行，不影响后面的步骤。**

### 用起来是什么感觉

```
① 读到啥直接扔给 AI，说一句"帮我放到知识库里"
      ↓
② AI 读你的目录，知道每个文件夹是干啥的
      ↓
③ AI 自动把内容放进最合适的目录，你只管生产
```

**你的工作流变成：**

> **只管生产（想法 / 链接 / 经验），归档交给 AI。**

**这就是我在陪跑营里说的"只管生产"四个字。**

## 四、4 步把弹药库建起来

### 第 1 步 · 装 AI 工具（5 分钟）

任选一个。

**我个人的建议是 Claude Code / Hermes Agent / Codex**——功能强，能直接操作目录。

**但如果你不习惯命令行，先用 WorkBuddy 这类带界面的。**

**别纠结选哪个。选一个，先跑起来。**

### 第 2 步 · 建灵感库入口（10 分钟，让工具帮你建）

**这一步是全篇最关键的落地动作。**

灵感库不是收藏夹，**你得给它写一份"入口规则"**，否则它三个月后就变成垃圾场。

**规则长这样（直接发给 AI 让它建好）：**

> **入盒规则**：进这个库的笔记，必须满足至少一条——
> - 这个观点我不认同，我要说出来
> - 这个东西我以为懂了，但讲不清楚
> - 这个现象让我困惑，没有简单解释
> - 这个旧认知最近被动摇了
>
> **出盒规则（强制，两周内必须完成）**：
> 1. 我能在 10 秒内说出这个观点的反例吗？
> 2. 它能同时解释 A 和 B 两个不相干现象吗？
> 3. 讲给一个比我聪明的人听，对方会质疑哪里？
> 4. 我之前有没有讲过类似的？这次新在哪？
>
> 通过 → 提炼进加工管线 → 输出；没通过 → 删掉。
>
> **管理规则**：
> - 超过两周没处理的笔记 = 直接删，不可惜
> - 定期（每周日）浏览一次灵感库，清一轮
> - 库里干净 = 脑子干净

**为什么这份规则这么重要？**

> **因为它把"我想学什么"换成了"我不舒服什么"。**
>
> **前者让你越学越懒，后者让你越学越有劲。**

### 第 3 步 · 装自己的 Skill（30 分钟）

**Skill 是什么？**

**就是把你的方法论打包成"一句话指令"。**

装好之后你说一句"生成口播文案"，它就按你的标准来。

**4 个核心 Skill（文末附提示词）**：

| Skill | 干什么 |
|-------|--------|
| **灵感** | 帮你产生新灵感（挖矿 7 刃）|
| **知识卡片** | 把灵感变成结构化卡片 |
| **挖矿** | 把灵感压成可传播的判断 |
| **口播** | 把洞见变成口播文案 |

**这 4 个串起来，就是一条完整的流水线：**

```
灵感 → 卡片 → 挖矿 → 口播文案
```

**而且它们可以连在一起用：**

> "我给你一段口述，请你直接完成'灵感-卡片-口播文案'，然后把结果保存在 xxx 目录。"

**一次调用，全流程跑完。**

**提示词在文末，你直接复制。**

### 第 4 步 · 去公园散步（这一步很重要）

**真的，出去走走。**

**它能降血压。**

**手机上有两种用法**：官网下载页有小程序和 App；或者把它的助理接进微信。

**剩下的事就是，一边散步一边跟它聊：**

> "我有一个灵感，xxxxxx"……
>
> "把我们刚刚聊的生成一张知识卡片"……
>
> "把这条洞见生成一条口播文案"……

**就这样，很简单。**

**为什么我要把"散步"写进流程里？**

**因为灵感是在走路的时候冒出来的，不是在盯着屏幕的时候。**

> **你不需要"想出内容"。你需要在有内容的时候，把它抓住。**
>
> **散步是最低成本的灵感触发器。**

## 五、让系统活下去：3 句话

跑起来之后，记住 3 句话就行。

### 1. 进库有门槛

**不认同的、讲不清的、让你困惑的、认知被动摇的**，才配进灵感库。

**两周没处理的，直接删。**

### 2. 输出前过四问

**能说出反例吗？能解释两件不相干的事吗？聪明人会质疑哪？比以前新在哪？**

**过不了就删。**

### 3. 每篇接上篇

**写的时候带一句"上期我说 X，这次发现……"**

**——读者看着你长，你也知道自己一直在长。**

**这 3 句话，我放在我自己的系统首页。**

**不是因为复杂，是因为有效。**

## 六、弹药库和赚钱飞轮的关系

**最后我要把这件事接回你说的那句话：知识库是赚钱飞轮的动力源。**

**看这张图：**

```
        弹药库（知识库）
        ├─ 灵感库：问题池
        ├─ 痛点清单：客户原话
        └─ 经验卡：我的真实做法
              ↓
        AI 工具（武器）
              ↓
   ┌──────────┼──────────┐
   ↓          ↓          ↓
 短视频     公众号      产品
```
